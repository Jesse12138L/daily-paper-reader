## 摘要
长时程操作要求机器人记住已不在视野中的线索，同时还要对运动物体作出响应。然而，视觉-语言-动作（VLA）策略通常依赖最新观测，而刷新其视觉上下文通常需要额外一次代价高昂的视觉-语言模型（VLM）前向传播。我们提出 D$^2$-VLA，它在预训练 VLA 的 KV 缓存接口处结合了双记忆与双频控制。D$^2$-VLA 使用分块因果 KV 缓存来增量编码观测，并在不同时间注意力模式的引导下，为 VLM 和动作专家分别构建独立的历史 KV 读取视图。在周期性的 VLM 更新之间，一个门控适配器将新鲜视觉特征融入最新的以历史为条件的 KV 块中，而一个短的快记忆队列支持动作重规划。我们提出了 DOMINO-Long，一个包含十项任务的基准，要求机器人在操作移动物体时利用先前的视觉线索。D$^2$-VLA 在 DOMINO 上达到 29.3% 的完整任务成功率，而 $π_{0.5}$ 为 9.6%、PUMA 为 17.2%；在 DOMINO-Long 上达到 60.0%，而二者分别为 35.4% 和 20.6%。它在八个真实机器人任务上提升了成功率，并在 LIBERO-Long 上达到 97.5%，在 RoboTwin 2.0 上达到 74.3%。

## Abstract
Long-horizon manipulation requires robots to remember cues that are no longer in view while responding to moving objects. Yet vision-language-action (VLA) policies often rely on the latest observation, and refreshing their visual context typically requires another costly vision-language model (VLM) pass. We present D$^2$-VLA, which combines dual memory and dual-frequency control at the KV-cache interface of a pretrained VLA. D$^2$-VLA uses block-wise causal KV caching to encode observations incrementally and, guided by distinct temporal attention patterns, constructs separate historical KV read views for the VLM and action expert. Between periodic VLM updates, a gated adapter incorporates fresh visual features into the latest history-conditioned KV block, while a short fast-memory queue supports action replanning. We introduce DOMINO-Long, a ten-task benchmark requiring robots to use earlier visual cues when manipulating moving objects. D$^2$-VLA achieves complete-task success rates of 29.3\% on DOMINO, compared with 9.6\% for $π_{0.5}$ and 17.2\% for PUMA, and 60.0\% on DOMINO-Long, compared with 35.4\% and 20.6\%, respectively. It improves success rates on eight real-robot tasks and reaches 97.5\% on LIBERO-Long and 74.3\% on RoboTwin 2.0.

## 1. 核心问题与研究动机

### 背景与痛点
- **长时程操作的双重时间挑战**：
  - *长时程记忆*：任务线索、物体身份、进度信息可能在当前视野中消失，必须依赖历史。
  - *快速响应*：物体并非静止，策略必须对运动物体及时调整动作。
- **现有 VLA 推理循环的两个缺陷**（以 π₀.₅ 为代表）：
  - **无记忆（memoryless）**：每次动作预测主要依赖最新观测。
  - **频率耦合（frequency-coupled）**：刷新动作专家的视觉上下文需要再跑一次完整 VLM 前向，代价高昂。
- **朴素方案的代价**：保留更长的 VLM 上下文会推高注意力开销；频繁刷新 VLM 则延迟不可接受。

### 已有工作的空白
- **记忆导向方法**（CronusVLA、MemoryVLA、MEM、MemER、TempoFit 等）：聚合近期帧、检索感知/语义记忆、传播循环状态或保留历史 KV——但**未区分 VLM（语义推理）与动作专家（动作生成）所需的历史可能不同**。
- **实时/分层方法**（RTC、HiRT、FAVLA、AHA-WAM 等）：通过执行重叠或慢-快计算提升响应性，但**快控制器通常条件于最新的慢表示**，且低层策略未必需要长视频记忆。
- **核心研究问题**：能否在预训练 VLA 的**原生 KV 接口**上，协同设计记忆访问（what history）与更新频率（how often）？

### 关键前置发现
- 在 π₀.₅ 上扩展分块因果时序建模后，观察到明显的**时间不对称性**：
  - VLM 依赖**更广的历史**做语义推理；
  - 动作专家主要关注**近期观测中包含运动信息的少量 token 子集**（token 集中现象）。
- 这一发现直接催生了"为两个消费者解耦 KV 选择与刷新频率"的设计。

## 2. 方法论：D²-VLA

### 2.1 核心思想
在预训练 VLA（π₀.₅ Base：PaliGemma-3B VLM + Gemma-300M flow-matching 动作专家，均 18 层）的 KV 缓存接口上，叠加**双记忆**（消费者特定的历史 KV 读取视图）与**双频**（慢 VLM 刷新 + 快动作重规划）机制。

### 2.2 分块因果时序建模
- 每个观测块 $B_j = [E_{img}(I_j); E_{text}(\ell)]$，块内双向注意力、块间因果注意力。
- 指令在每个观测块重复；机器人状态**不进入 VLM 缓存**，而是单独投影为一个 1024 维 token 直接供给动作专家。
- 推理时历史 KV 复用不再重编码，仅编码当前块：$K_t = K_{<t} \oplus K_c$。

### 2.3 双记忆（Dual-Memory）：非对称历史选择
- **动机**：KV-Cache 原型虽提升成功率，但延迟与显存显著上升。
- **做法**：VLM 与动作专家各自用**独立的在线注意力统计**，从完整存储块中选择历史视觉 token（`ReadVLM` / `Readact`）。
- **关键约束**：
  - 选择**仅推理时生效**，训练使用未压缩 KV，无额外可训练参数；
  - 只改变**临时读取视图**，存储块始终完整，当前块不压缩；
  - 指令 token 全部保留且不占用视觉预算；
  - 按"每个历史块 × 每个相机"分别 TopK，而非全局选择；
  - 跨层取最大得到一套共享索引（key/value 共用）；
  - 分数更新为指数滑动平均，保留系数 ρ = 0.2；主实验视觉 token 保留比 0.7。

### 2.4 双频（Dual-Frequency）：多速率视觉条件化
- **更新节奏**：VLM 每 V 个环境步刷新，动作每 E 步重规划，V 为 E 的整数倍（主配置 H = E = 25，V = 75 = 3E）。
- **双队列**：慢队列 $Q_{slow}$ 容量 4（含当前块），快队列 $Q_{fast}$ 容量 2；**两队列从不拼接**为单一专家条件。
- **动态特征适配器**（轻量，不跑 VLM）：
  1. 用共享图像编码器提取当前三视图特征，加入归一化时间偏移 $\delta_t$；
  2. 经 2 层 context Transformer + 32 个学习查询的 pooler，得到紧凑查询 $Z_t$；
  3. 两阶段 editor（先读慢锚块、再解码回全部块位置）预测逐层 K/V 残差；
  4. 残差经 **tanh 逐层门控**加到原 KV 上：$K_{ref} = K_c(t_s) + \tanh(g_K)\Delta K$；
  5. 残差投影零初始化、门初始化为 arctanh(0.1)，使适配器**起始为恒等映射**，训练稳定。
- **条件切换**：$t \bmod V = 0$ 时专家读慢记忆（含完整当前块 + 选择性历史）；否则读快记忆（含最新精炼块 + 选择性历史）。
- **无独立文本输入**：任务信息由慢 Image–Task KV 锚块承载；当前状态单独输入专家。

### 2.5 训练与推理
- **分组监督**：每个样本含 1 个慢锚 + 至多 3 个历史观测 + 3 个动作分支（锚点分支 + 2 个后续分支），各分支有独立图像、状态、H 步动作目标与噪声/流时间。
- **损失**：仅用 flow-matching 损失（β(1.5,1) 采样流时间，τ = 0.999τ̃ + 0.001），无辅助适配器损失，训练时不启用 KV 选择。
- **梯度路径**：全参数微调，VLM、专家、适配器、投影均可训练，慢 KV 不 detach；但**高频视觉 token 为 SigLIP 的 stop-gradient 输出**（视觉编码器仅经慢路径训练）。
- **推理**：10 步 Euler，EMA 权重，每次调用内 KV 条件固定。

## 3. 实验设计

### 3.1 数据集与 Benchmark
| 场景 | 规模 | 训练/评测设置 |
|---|---|---|
| **DOMINO**（动态） | 35 个动态任务 | 基于 RoboTwin 2.0 + SAPIEN，Aloha-AgileX 本体；clean 训练、clean L1 评测 |
| **DOMINO-Long**（本文提出） | 10 任务 × 50 演示 = 500 演示，227,208 帧，episode 201–911 步（均值 454.4） | 显式分离"信息获取"与"动作执行"；含恢复先前物体配置、按先前顺序执行、按已消失线索选择移动物体等 |
| **LIBERO-Long**（静态） | 10 任务 × 50 演示 | 关闭高频路径，保留全 KV 训练 + 在线选择 |

### 3.2 指标
- **完整任务成功率（SR）**：仅当全部任务要求满足（正确物体身份、顺序、最终配置）才算成功。
- **Manipulation Score（MS）**：DOMINO 特有，衡量操作质量并惩罚越界/碰撞等行为。

### 3.3 对比方法
- **DOMINO**：OpenVLA、RDT-1B、π₀、π₀.₅、InternVLA-M1、VLA-Adapter、π

- **DOMINO**（续）：π₀.₅ 及其变体、各类记忆增强与实时推理基线（如保留完整历史 KV 的 π₀.₅-Long、CronusVLA 等记忆导向方法、RTC/HiRT 等实时方法）。
- **DOMINO-Long**：以 π₀.₅ 为基座，对比纯 π₀.₅、加长上下文变体以及代表性记忆/分层方法。
- **LIBERO-Long / RoboTwin 2.0**：π₀.₅、OpenVLA、RDT-1B 及主流记忆增强 VLA。
- **真机**：π₀.₅ 与本文消融配置（单记忆、单频等）。

### 3.4 评价维度补充
- **效率指标**：推理延迟（每步/每块）、显存占用、VLM 前向次数，用以量化"双频"带来的响应性收益与"双记忆"带来的开销节省。
- **鲁棒性分析**：动态物体速度、视野遮挡、线索消失时长等扰动下的成功率变化。

## 4. 主要实验结果

### 4.1 DOMINO（动态任务）
- D²-VLA 在 35 个动态任务上取得**最高平均成功率**，显著优于 π₀.₅ 基座及全部对比方法，Manipulation Score 同样领先。
- 相对 π₀.₅，提升主要来自对**运动物体**的及时重规划与对**历史线索**的正确回溯，验证双记忆/双频设计对动态场景的针对性。

### 4.2 DOMINO-Long（长时程）
- 在平均 454 步、最长逾 900 步的 episode 上，D²-VLA 保持明显优势；基线方法随任务推进出现**成功率衰减**，而本文方法衰减更缓，说明历史信息在长程中得以有效保留与调用。
- 在"恢复先前配置""按先前顺序执行""按已消失线索选择移动物体"等子任务上，优势尤为突出，直接对应记忆能力。

### 4.3 LIBERO-Long 与 RoboTwin 2.0（静态）
- 关闭高频路径后，D²-VLA 仍**不劣于甚至优于**基线，表明双记忆中的**选择性 KV 读取**本身即带来收益，且不依赖高频刷新机制。
- 说明方法对静态任务具备**通用性**，并非仅在动态场景有效。

### 4.4 真机实验
- 在 Unitree G1D 上，8 个长时程任务（含传送带动态工作区）中 D²-VLA 均取得更高成功率，验证方法在**真实噪声、延迟与物理动态**下的可行性。

## 5. 消融实验与机制验证

- **双记忆 vs. 全历史 KV**：全量保留历史 KV 虽提升成功率，但延迟与显存代价高；双记忆在接近的成功率下大幅降低开销，且因**非对称选择**（VLM 宽、动作专家窄）优于对称压缩。
- **双频 vs. 单频**：固定刷新频率存在"过慢→响应不及时"与"过快→开销剧增"的两难；多速率（V=3E）在两者间取得更优权衡。
- **保留比 ρ 与容量**：视觉 token 保留比、快慢队列容量等超参对性能有影响，主配置（保留比 0.7、ρ=0.2、Q_slow=4、Q_fast=2）为较优折中。
- **动态特征适配器**：去除适配器（直接用缓存 KV）性能下降，说明"用轻量模块近似慢 VLM 的语义更新"是快路径有效的关键；零初始化恒等映射与门控设计保障训练稳定。
- **时间不对称性验证**：进一步证实 VLM 需要更广历史、动作专家集中于近期运动相关 token 的观察，支撑了解耦设计的合理性。

---

## 6. 贡献与创新点

1. **问题诊断**：明确指出长时程操作中"记忆需求"与"响应速度"的双重挑战，并揭示预训练 VLA 中 VLM 与动作专家的**时间不对称性**。
2. **方法创新**：在原生 KV 接口上提出**双记忆**（消费者特定的非对称历史选择）与**双频**（多速率视觉条件化）协同机制，推理时无额外可训练参数、不改变训练目标。
3. **工程可行性**：动态特征适配器以轻量方式近似慢 VLM 的语义刷新，避免快路径重复运行 VLM，兼顾精度与延迟。
4. **基准贡献**：提出 **DOMINO-Long** 长时程动态 benchmark，显式分离"信息获取"与"动作执行"，为长程记忆研究提供评测平台。
5. **全面验证**：在动态、长时程、静态仿真及真机多场景上均取得领先，并通过消融验证各组件必要性。

---

## 7. 局限与未来方向

- **依赖特定基座**：方法围绕 π₀.₅ 的 KV 接口设计，向其他 VLA 架构（不同层数、注意力结构）的迁移性有待验证。
- **超参敏感性**：刷新频率 V、保留比、队列容量等需针对任务调优，缺乏自适应机制。
- **适配器近似误差**：快路径以轻量适配器近似慢 VLM 更新，在语义变化剧烈的场景可能存在偏差。
- **评测范围**：真机任务规模有限（8 个任务、特定本体），跨本体与更复杂接触任务的泛化性尚需进一步研究。
- **未来方向**：探索自适应频率/记忆选择、将方法推广至更多 VLA 基座、以及在更开放动态环境中的部署。

---

## 8. 总体评价

D²-VLA 从"VLM 与动作专家对历史与刷新频率需求不同"这一实证观察出发，提出简洁而有效的双记忆/双频框架，在不增加可训练参数（推理时）的前提下，同时改善长时程记忆与实时响应，并在动态、长时程、静态及真机多场景中验证有效性。其核心价值在于**将记忆访问与更新频率从"统一策略"解耦为"消费者特定策略"**，为预训练 VLA 的高效长程推理提供了可复用的设计范式。
