## 摘要
视觉-语言-动作策略能够从几何监督中获益，但仅凭当前帧的几何信息并不能显式描述与操作相关的变化。该设计的动机在于学习一种与具体实体无关的视觉接口，使其能够在机器人特定动作对齐之前，跨机器人视频与第一人称视频进行预训练。我们提出几何变化 VLA（Geometry-Change VLA，GC-VLA），它学习从当前观测中预测多视角的“未来—当前”几何变化 token。离线帧对定义了标称 0.5 秒的预测时域；未来观测仅用于构建训练目标。第 1 阶段训练几何变化视觉-语言模型（GC-VLM）。第 2 阶段引入连续型 ActionExpert，并将其与机器人动作对齐，同时在 VLM 接口处阻断动作流的梯度。第 3 阶段允许这些梯度与 ActionExpert 联合更新 VLM 中可训练的部分。第 4 阶段冻结 GC-VLA 并应用几何条件残差流（Geometry-Conditioned Residual Flow，GCRF），使用二值干预路由器以及从闭环反馈中学习得到的单一有界残差速度策略。GC-VLA 在 LIBERO 上取得 95.20% 的成功率，而结合 GCRF 的 GC-VLA 达到 99.55%。推理时使用当前观测与学习到的 GC 表示，而无需运行离线的目标编码器。

## Abstract
Vision-language-action policies benefit from geometric supervision, but current-frame geometry alone does not explicitly describe the changes associated with manipulation. This design is motivated by the goal of learning an embodiment-agnostic visual interface that can be pretrained across robot and egocentric video before robot-specific action alignment. We introduce Geometry-Change VLA (GC-VLA), which learns to predict multiview future-current geometry-change tokens from current observations. Offline frame pairs define a nominal 0.5-second prediction horizon; future observations are used only to construct training targets. Stage 1 trains a geometry-change vision-language model (GC-VLM). Stage 2 introduces a continuous ActionExpert and aligns it with robot actions while stopping action-flow gradients at the VLM interface. Stage 3 enables these gradients to update the trainable VLM components jointly with the ActionExpert. Stage 4 freezes GC-VLA and applies Geometry-Conditioned Residual Flow (GCRF), using a binary intervention router and a single bounded residual velocity policy learned from closed-loop feedback. GC-VLA achieves 95.20% success on LIBERO, and GC-VLA with GCRF achieves 99.55%. Inference uses current observations and the learned GC representation without executing the offline target encoders.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略能从几何监督中受益，但现有做法多使用**当前帧几何**（如当前深度），它只描述"现在长什么样"，无法显式表达操作过程中"应该发生什么变化"。
- **操作中的关键变化**包括：夹爪接近物体、抽屉沿约束移动、接触建立、物体朝任务目标改变位姿——这些都是**时域上的几何转移**，而非单帧静态结构。
- **已有未来预测类工作**（VideoVLA、FLARE、AHEAD 等）通过预测未来观测、未来隐状态或演化的场景表示来引入时序推理，但"未来信息应该表示成什么"仍未解决。
- **作者的核心动机**：构建一个**具身无关（embodiment-agnostic）的视觉接口**。因为机器人动作监督在人类视频中不存在、且跨本体/动作空间/数据源不一致，而**成对的时序视觉观测却广泛可得**。因此先在"几何变化"这一通用目标上预训练，再推迟到后续阶段做具身特定的动作对齐。
- **关键定义**：预测当前与未来空间表示之间的**差**，而非重建未来观测或完整未来隐状态：
  ΔE_{t,H} = E_{t+H} − E_t。未来观测**只用于构造训练目标**，部署时不使用未来帧、不滚动世界模型。

### 2.2 架构
- **GC-VLM**：以 36 层 **Molmo2-ER** 为骨干，**追加 12 个 transformer 块**（由前 12 个预训练块复制初始化），构成"上层几何变化扩展"，用于预测多视角几何变化 token。
- **GeometryReader**：用可学习 query 池化 GC 隐状态，并通过**交叉注意力残差**注入 ActionExpert 的指定层：h̃ = h + Reader(h, h_GC, m_GC)。输出投影**零初始化**，使初始化时该路径为 no-op，不破坏预训练动作通路。
- **ActionExpert**：以流匹配预测流速度 v_base = A_Ψ(z_k, τ_k, q_t; h_t, h̃)，条件于几何感知隐状态。

### 2.4 GCRF（几何条件残差流）
- 上下文 c_t = [v̄_base; g_GC; h_flow] ∈ R^96（各 32 维），其中 GC 分量来自模型**中间表示**，而非在线运行离线编码器。

## 7. 论文的主要贡献

1. **问题重定义**：把"未来信息该表示成什么"从"预测未来观测/隐状态"转向**预测几何变化 ΔE**，目标更紧凑、更贴近操作语义，且天然具身无关。
2. **接口设计**：提出 ΔE 作为**具身无关的视觉接口**，使人类视频与机器人数据可在无动作标注的情况下共同预训练，缓解动作监督稀缺与跨本体不一致。
3. **架构方案**：GC-VLM（复制初始化的几何扩展块）+ GeometryReader（零初始化交叉注意力残差）实现"几何能力增量扩展而不破坏预训练动作通路"。
4. **训练配方**：四阶段流程（几何预训练 → 解耦动作对齐 → 耦合适配 → GCRF 残差后训练）提供了可复用的分阶段对齐范式。
5. **闭环安全机制**：GCRF 的**二值路由 + 有界残差 + no-op margin + 零隐变量回退**，为"冻结大模型 + 轻量闭环修正"提供了保守而有效的工程模板。
6. **泄漏防护的显式化**：明确区分"未来帧作为标签"与"未来帧作为输入"，并给出评测不变量 ŷ_GC = g_GC(F_Θ(x_t))，这是该方向值得推广的规范做法。

- **零初始化残差注入**是安全扩展预训练主干的有效手段，可推广到其他模态（触觉、力、音频）。
- **分阶段解耦 + 梯度阻断**为"无动作数据的预训练 → 有动作数据的对齐"提供了通用配方，尤其适合动作空间异构的多源数据。
- **冻结基座 + 有界残差 + 路由**的闭环范式，比全量微调或朴素 RL 微调更易控制风险，适合安全敏感场景。
- **评测规范**：显式声明"未来帧只作标签"并给出评测不变量，应成为未来预测类 VLA 工作的标准披露项。

## 10. 总体评价

本文的核心价值在于**把"未来"重新表述为一种紧凑、具身无关、可量化的几何变化信号**，并围绕它构建了从数据配方、网络架构到闭环修正的完整方案。其方法学贡献（ΔE 目标、零初始化残差接口、四阶段解耦训练、GCRF 安全残差）具有较强的可迁移性，统计严谨性也高于同类工作。

但作为一篇宣称"具身无关"的工作，**实验证据与主张之间存在明显落差**：评测局限于单一仿真基准、缺真机验证、缺算力披露、横向对比非严格复现。因此其结论应被理解为"在 LIBERO 上、特定协议下成立"，而非对跨本体泛化能力的普遍性证明。后续工作若能补齐真机跨本体实验、公开训练成本与数据配比，并做预测时域/量化粒度的敏感性分析，将显著增强该路线的说服力。
