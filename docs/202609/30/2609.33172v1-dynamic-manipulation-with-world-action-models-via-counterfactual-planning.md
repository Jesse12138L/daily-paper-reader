## 摘要
在静态示范上训练的世界-动作模型（WAM）即使具备所需的操作技能，也常常无法操作移动目标。我们将这一失败归因于目标-响应崩塌：随着执行推进，策略越来越偏向于其当前行为的学习延续，而对目标位置变化响应减弱。为弥合模型所学内容与其可从当前上下文生成内容之间的差距，我们将动态操作形式化为反事实规划，通过将用于规划生成的上下文与用于执行的物理状态解耦。我们的框架——动态预测规划（DPP）——首先利用 WAM 的预测推演来估计预期发生交互的时间，并将该时间估计与观测到的目标运动相结合，以预测目标未来的交互位置。随后，DPP 构建一个反事实观测，将预测的目标位置置于熟悉的机器人上下文中，使模型能够调用已有的操作技能，而不是从不熟悉的机器人-目标构型中生成恢复行为。在执行过程中，所得规划与机器人实际状态相连接。DPP 无需在动态数据上额外训练，即可在单张消费级 GPU 上实现实时动态操作。仿真和真实机器人实验表明，在不同目标运动下均有一致提升，仿真性能超过所有评估基线，包括额外在动态数据上训练的方法。项目页面：https://methoder00.github.io/DPP/

## Abstract
World-Action models (WAMs) trained on static demonstrations often fail to manipulate moving targets even when they possess the required manipulation skills. We attribute this failure to target-response collapse: as execution advances, the policy becomes increasingly biased toward the learned continuation of its ongoing behavior and less responsive to target relocation.   To bridge the gap between what the model has learned and what it can generate from the current context, we formulate dynamic manipulation as counterfactual planning by decoupling the context used for plan generation from the physical state used for execution. Our framework, Dynamic Predictive Planning (DPP), first uses the WAM's predictive rollout to estimate when an interaction is expected to occur, and combines this timing estimate with observed target motion to predict the target's future interaction position. DPP then constructs a counterfactual observation that places this predicted target position in a familiar robot context, allowing the model to invoke an existing manipulation skill rather than generate a recovery behavior from an unfamiliar robot-target configuration. The resulting plan is connected to the robot's actual state during execution.   DPP enables real-time dynamic manipulation on a single consumer GPU without additional training on dynamic data. Experiments in simulation and on a real robot demonstrate consistent improvements across diverse target motions, with simulation performance surpassing all evaluated baselines, including methods additionally trained on dynamic data. # 论文总结：Dynamic Manipulation with World-Action Models via Counterfactual Planning

## 1. 核心问题与研究背景

- **背景**：Vision-Language-Action（VLA）与世界-动作模型（WAM）已在多种操作任务上取得良好表现，WAM 还能额外预测未来视觉状态，刻画动作如何改变场景。但真实部署中机器人常需操作**移动目标**，而绝大多数操作技能仍来自**静态目标 + 规范机器人构型**的示教数据。
- **核心问题**：预训练的操作技能能否在**不采集动态数据、不重新训练模型**的前提下被复用于动态环境？直觉方案是"随目标移动不断重规划"，但这会把策略置于静态示教**支持之外**的机器人-目标构型（机器人已推进到后段状态，目标却移动到从未与该状态共同出现过的位置）。
- **关键发现——目标-响应崩塌（target-response collapse）**：随执行推进，策略越来越偏向"延续已学到的当前行为"，对目标位置变化的响应能力急剧下降，继续奔向熟悉的旧子目标。作者用**定向响应增益** G(S;x,x′)（预测抓取点位移对目标位移的投影增益，接近 1 表示跟随目标、接近 0 表示几乎不响应）量化该现象。
- **整体含义**：动态操作失败可能不是"能力缺失"，而是**已学技能在当前观测语境下不可调用**（skill access 问题）。因此论文把动态操作形式化为**反事实规划**：解耦"用于生成计划的上下文"与"用于执行的物理状态"。

## 2. 方法论：Dynamic Predictive Planning (DPP)

### 核心思想
- 用**熟悉的规范（canonical）机器人上下文 + 预测的未来交互位置**构造反事实观测，让冻结的 WAM 直接"唤起"已有技能，而不是从陌生的机器人-目标构型中生成恢复行为；得到的规范计划再通过**激活桥（activation bridge）**接到机器人真实执行状态上。
- 关键理念："**Predict, don't chase**"——不是追当前可见位置，而是"在机器人到达时目标将在的位置"与目标会合。DPP 只改变调用技能的上下文，执行仍从实时状态出发。

### 三阶段流程（对应 Fig. 3）
- **Step 1 初始规划与执行预付**：
  - 由初始观测生成 ζ_init = ζ(C(S0, x0))；WAM 自回归推演（预测图像 + 预测本体感觉作为下一段输入）以估计**交互时机**：取首个满足任务谓词 φ_q 的预测动作 j，映射到执行时钟 τ = t_exec + Δt·min{j : φ_q(a_j)=1}。
  - **运动 bootstrap**：SAM 2 分割目标 + FoundationPose 跟踪时间戳观测，用最小二乘拟合目标运动假设 x̂(s)=b+v·s（静态场景经 RGB-D 稳定性门控判定后令 v=0），得到交互位置 x̂(τ)。
  - **motion prepayment**：在规划继续的同时，对初始动作块按有界斜坡 α_i 施加目标位移补偿（i<15 不变，i=31 达到完整位移），并附 10 步末端续接以维持动作队列。
- **Step 2 规范规划与激活**：
  - 构造反事实观测：Ĉ(S_k,x′) = (Edit(O_k,x′), R_k, I)，即通过 RGB-D 编辑（原目标区域修复/背景深度回填、按 z-buffer 重投影到 x̂(τ)）把目标放到预测交互位置，同时**保留选定机器人构型与场景**。
  - 生成规范轨迹 ζ_can = ζ(Ĉ(S0, x̂(τ)))；按**纯时间对齐**选取入口 j* = g − (K − k_a)，再用 IK 构造激活桥（smoothstep 交叉淡化 + 关节速度/加速度与笛卡尔约束检查，含放宽笛卡尔约束的回退尝试），与规范后缀一起替换剩余动作队列。
- **Step 3 当前状态重规划**：桥完成后机器人已接近规范轨迹，用新鲜观测与实测状态生成 ζ_cur_k = ζ(Ĉ(S_k, x̂(τ)))，同一预测交互位置、但机器人上下文更新，以抑制推演漂移；仅对交互段之前的关节轨迹做**时间重采样**，交互段（末段接近与夹爪开合）保持不变。
- **跨子任务**：延续型阶段复用当前状态推演的续接作为下一阶段初始计划；新周期边界则重新取参考观测。每个阶段有各自的交互谓词（夹爪闭合/张开、TCP 高度触发等）与交互时间。

### 关键公式/机制要点
- 上下文定义 C(S,x) = (O, R, I)；响应增益 G(S;x,x′) 及其随机器人前缀的变化 ΔG_k = G_k − G_0 用于诊断崩塌。
- 入口点按剩余时间对齐、不做时间重采样；激活桥的提前量 L = max(2, ⌈T_bridge/Δt⌉+2)，并预测激活时刻状态 k_a = k + L。
- 对复杂运动提供**可选非线性扩展**：按声明的运动族（恒加速、恒转弯率、含位置跳变的恒速）因果更新运动假设，启用"延迟规范规划"与当前状态输出的**空间扭曲**（小修正归零、过大修正拒绝）。

## 7. 局限性与潜在风险

- **依赖目标运动模型的可预测性**：DPP 的 bootstrap 采用最小二乘拟合的运动假设（恒速为主，可选恒加速/恒转弯率/跳变扩展）。对突然变向、遮挡导致跟踪丢失、非刚体或人机交互驱动的目标，预测交互位置可能失准；论文虽设置"空间扭曲拒绝"与非线性扩展作为缓解，但未系统评估高不确定性与对抗性运动。
- **对感知与分割质量的敏感性**：反事实观测由 RGB-D 编辑（目标区域修复、z-buffer 重投影）构造，依赖 SAM 2 分割与 FoundationPose 位姿跟踪。分割泄漏、深度缺失或位姿抖动会污染规范上下文，而论文主要在受控速度（仿真 1–5 mm/策略步、真机约 5.2–7.3 cm/s）与相对干净的场景中评估。
- **计算与延迟约束**：DPP 需要多次骨干推理（初始规划、规范规划、当前状态重规划）与自回归推演，虽然通过 ImageWAM 降去噪步数缓解，但延迟-质量权衡仅在有限配置上验证；更高频或更高速目标可能超出该预算。
- **入口对齐与激活桥的工程性假设**：纯时间对齐选取入口 j*、smoothstep 交叉淡化与 IK 回退机制包含较多手工超参与安全检查（如提前量 L、动作块 15/31 步斜坡）。这些在文中作为统一设置使用，但其跨平台、跨机器人形态的鲁棒性尚未充分检验。
- **评估偏差面**：如前所述，部分基线为代理实现（Future-Conditioned 固定前瞻）、真机样本量小（每任务 30 次）、Task A 的 Reactive/Future-Conditioned 为 0% 使对比偏极端、T2 存在少量种子重试。这些不改变主要趋势，但意味着绝对数值应谨慎外推。
- **未报告训练成本**：由于骨干冻结、无需再训练，论文没有训练时长/算力数据；这既是方法优势，也使得与"动态训练"方法的成本对比不完整（PUMA、DynamicWAM 的训练开销未被量化）。
- **任务覆盖的边界**：评估集中在抓取、放置、敲击、交接、堆叠等桌面级操作，目标运动多为刚体恒速直线运动；对长时程、多目标并发、需要力控/柔性物体或移动基座的动态操作尚缺证据。

## 8. 启示与未来方向

- **范式层面**：论文把动态操作从"数据/能力缺口"重构为"技能访问问题"，提示后续工作可沿"上下文工程"路线扩展——例如自动发现规范上下文、学习上下文检索策略，而非一味扩充动态示教数据。
- **方法组合**：反事实规划与显式运动预测是互补的。将 DPP 与更强的运动预测器（学习式轨迹预测、交互感知预测）、在线系统辨识结合，可能提升高不确定性下的表现。
- **可迁移性**：核心机制（构造熟悉的机器人上下文 + 预测交互位置 + 激活桥）不依赖特定骨干，理论上可迁移到其他 VLA/WAM、不同机器人构型与移动基座场景，但需验证跨形态的入口对齐与桥接约束。
- **评估建议**：后续基准应把"静态支持区域"标定、响应增益诊断、接触诊断（Contact/RC）作为标准组件，以区分"可达性失败"与"动态执行误差"；同时报告目标运动模型、速度分布与感知质量，便于横向比较。

## 9. 总体评价

- **贡献定位**：论文的核心贡献是**现象诊断 + 机制性解法**。它先用定向响应增益与匹配前缀探针，干净地量化了"目标-响应崩塌"这一被忽视的失效模式，并证明其发生在接触之前；随后提出 DPP，用反事实规范上下文与激活桥把冻结 WAM 的技能重新"调起来"，在仿真与真机上均大幅超越刷新式、前瞻式、VLA 式与动态训练式基线。
- **说服力**：实验矩阵较广（多任务、多速度、同向/反向、仿真+真机），诊断实验规模大（945 次探针 + 多次标定），消融覆盖了三个关键组件与多个诊断上界，整体证据链完整；主要短板在基线实现的代理性、真机样本量与感知/运动假设的受控性。
- **实践意义**：对工程落地而言，"Predict, don't chase"与"冻结骨干 + 推理时上下文重构"提供了一条低训练成本、可叠加在现有 WAM 上的动态操作路径；其代价是推理延迟与对感知/预测质量的依赖，需按场景权衡。
- **一句话总结**：动态操作的关键或许不在于让模型"学会新动作"，而在于让它在正确的上下文里**想起旧动作**；DPP 用反事实规划实现了这种"技能唤醒"，并以目标-响应崩塌的定量诊断支撑了这一论点。
