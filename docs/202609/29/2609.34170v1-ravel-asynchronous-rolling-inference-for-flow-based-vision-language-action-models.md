## 摘要
基于流的视觉-语言-动作（VLA）模型在通用机器人操作中非常有效，但它们依赖计算开销高昂的VLM编码和多步迭代动作生成，这带来了显著的延迟瓶颈。由此产生的推理延迟使机器人难以快速响应，尤其是在动态环境中。我们通过RAVEL（Rolling Asynchronous VLA Enabling Low-Latency Control，滚动异步VLA实现低延迟控制）来应对这一限制，这是一个异步推理框架，旨在解决VLM主干网络和动作专家二者的计算瓶颈。为减少多步动作去噪带来的延迟，RAVEL通过滚动缓冲区将部分去噪的未来动作向前传递，使近期动作在单步去噪后即可执行。为避免因缓慢的VLM编码而阻塞，RAVEL将VLM编码与滚动动作生成解耦，使动作专家能够利用最新可用的VLM上下文连续运行，同时轻量级快速观测通路（Fast Observation Pathway, FOP）直接以当前观测为动作专家提供条件。在仿真和真实世界操作任务中，RAVEL在保持底层VLA任务能力的同时，始终实现显著更低的响应延迟，从而支持高频且响应迅速的闭环控制。

## Abstract
Flow-based vision-language-action (VLA) models are highly effective for generalist robot manipulation, yet their reliance on computationally expensive VLM encoding and multi-step iterative action generation imposes a significant latency bottleneck. The resulting inference latency makes it difficult for robots to respond quickly, especially in dynamic environments. We address this limitation with RAVEL (Rolling Asynchronous VLA Enabling Low-Latency Control), an asynchronous inference framework that addresses the computational bottlenecks of both the VLM backbone and the action expert. To reduce the delay from multi-step action denoising, RAVEL allows near-term actions to be executed after a single denoising step by carrying partially denoised future actions forward in a rolling buffer. To avoid blocking on slow VLM encoding, RAVEL decouples VLM encoding from rolling action generation, allowing the action expert to operate continuously using the latest available VLM context, while a lightweight Fast Observation Pathway (FOP) directly conditions the action expert on current observations. Across simulated and real-world manipulation tasks, RAVEL consistently achieves substantially lower response latency while maintaining the task capability of the underlying VLA, enabling high-frequency and responsive closed-loop control.

# RAVEL 论文深度总结

## 1. 核心问题与研究动机

- **背景**：基于流的视觉-语言-动作（VLA）模型（如 π0.5、X-VLA）已成为通用机器人操作的主流范式，其典型流程为：先用 VLM 编码观测，再由动作专家通过 flow matching 多步迭代去噪生成动作块（action chunk）。
- **核心瓶颈**：该流程存在**双重延迟来源**——(1) VLM 前向编码计算昂贵；(2) 动作需要多步迭代去噪。二者串行执行导致推理延迟高。
- **后果**：
  - 同步推理下，机器人必须等待整个推理完成才能执行动作，出现"停顿-执行"的间歇性控制；
  - 异步推理虽可重叠推理与执行，但新生成的块在开始执行时可能已与机器人状态不匹配，产生块间不连续；
  - 已有方法（RTC、滚动去噪、horizon-aware 噪声调度等）缓解了去噪延迟，但 **VLM 编码延迟仍阻塞连续动作生成**，动态环境中响应迟缓。
- **目标**：同时缓解 VLM 主干与动作专家两端的计算瓶颈，实现低延迟、高频、响应迅速的闭环控制，同时不牺牲底层 VLA 的操作能力。

## 2. 方法论

### 2.1 核心思想
以**异步滚动推理**替代"整块生成-整块执行"范式：动作在滚动缓冲区中跨控制步逐步去噪，每个控制步只需一次动作专家前向即可释放一个可执行动作；VLM 编码与动作生成完全解耦，异步更新上下文。

### 2.2 关键技术一：偏移感知的滚动流去噪（Offset-aware Rolling Flow Denoising）
- 维护长度为 K 的滚动缓冲区 $A_{t_a} = [a^{\tau_1}_{t_a+1}; \dots; a^{\tau_K}_{t_a+K}]$，第 k 个槽对应 $t_a+k$ 时刻执行的动作，其流时间步 $\tau_k = 1 - k/K$（越靠后噪声越大）。
- 每个控制步，动作专家对全缓冲做**一次**前向，将所有槽推进 $\Delta\tau = 1/K$：$a^{\tau_{k-1}}_{t_a+k} = a^{\tau_k}_{t_a+k} + \Delta\tau [v_\theta(A_{t_a}, \tau, c_{t_o}, \delta_p)]_{[k]}$。
- 推进后第一个槽达到 $\tau_0$（干净端点）被释放执行，其余 K−1 个保留，尾部追加一个从高斯噪声初始化的新动作。
- **效果**：每个动作在被执行前经历 K 次连续细化，但每步仅需一次前向；首个动作仅需单步去噪即可执行。
- **时间偏移条件**：由于 VLM 上下文 $c_{t_o}$ 来自较早观测 $t_o$，引入归一化偏移 $\delta_p = p/K$（$p = t_a - t_o$）作为动作专家的额外条件信号，使其能针对"实际执行时刻"预测动作。

### 2.3 关键技术二：异步上下文更新与快速观测通路（FOP）
- **解耦**：VLM 编码在独立 worker 中异步运行，动作专家持续复用最新可用上下文，不因 VLM 前向而阻塞。
- **FOP**：轻量图像编码器 + 本体感觉投影 $z_{t_a} = F(o_{t_a}, s_{t_a})$，通过**门控交叉注意力适配器**注入动作专家选定层，使即将执行的动作能直接响应最新观测，而无需等待 VLM 更新。VLM 上下文提供指令与语义信息，FOP 补充当前时刻的视觉/本体反馈。

### 2.4 关键技术三：流式对齐训练（Streaming-Aligned Training）
- 采样观测时刻 $t_o$ 与偏移 $p$（$t_a = t_o + p$），以 $c_{t_o}$ 为条件、以 K 步动作视界 $\hat{A}_{t_a}$ 为目标。
- 按与推理一致的噪声剖面构造训练缓冲：$a^{\tau_k}_{t_a+k} = (1-\tau_k)\epsilon_{t_a+k} + \tau_k \hat{a}_{t_a+k}$。
- 损失为逐槽速度预测的流匹配误差：
  $L_{train} = \mathbb{E}_{t_o,p,k}[\|[v_\theta(A_{t_a}, \tau, c_{t_o}, \delta_p)]_{[k]} - (\hat{a}_{t_a+k} - \epsilon_{t_a+k})\|_2^2]$。
- 启用 FOP 时额外提供 $z_{t_a}$。训练时 VLM 主干冻结，仅训练动作专家及新增模块。
- **相对动作处理**：对 π0.5（RoboTwin）与 DynamicVLA 等预测相对动作的模型，在干净缓冲中存储归一化绝对目标，每次更新前再转换为相对当前状态的相对动作，保证跨观测复用时不改变目标语义。

## 6. 主要结论与发现

- **能力保持**：在 LIBERO 与 RoboTwin 2.0 上，RAVEL 在相同生成预算下维持甚至略微提升基线 VLA 成功率（LIBERO：π0.5 96.5→95.9、X-VLA 97.8→95.8；RoboTwin：44.3→65.1、46.8→66.8 等），说明滚动推理不损害操作能力。
- **延迟显著降低**：首次动作延迟 X-VLA 142.58→54.97 ms（2.59×）、π0.5 272.86→93.45 ms（2.92×）。
- **动态任务提升**：DOM 上 RAVEL 平均成功率 44.06%，较最强基线 CI & LAAS（35.50%）高 8.56 个百分点；加 FOP 后达 46.94%，闭环反应性达 62.5%；平均完成时间 6.04 s，较 DynamicVLA 减少 23.0%。
- **真实世界有效性**：乒乓球回球成功率 90%（FASTER/VLASH 仅 25%，Sync/Naive Async/RTC 为 0），观测年龄 P50/P95 最低（121.76/132.20 ms）；网球抓取成功率相当（45%），但轨迹高频振荡 $E_{HF}$（7.01）与 TCP jerk（1800 mm/s³）最低，运动最平滑。
- **消融结论**：
  - 仅把滚动推理套用到预训练 checkpoint 会严重掉点；必须同时做**移位视界训练 + 时间偏移条件**（LIBERO 78.00%→97.85%，RoboTwin 31.54%→46.82%）。
  - 时间偏移条件使模型在 0–15 步观测延迟下保持 95.00–97.25% 成功率，而基线从 98.25% 降至 92.50%。
  - DOM 上若在新上下文到来时把偏移置零，成功率从 44.89% 骤降至 16.67%，说明必须计入 VLM 计算耗时。
  - 真实机器人存在动作-状态延迟，$\delta_0 = 0.3$（约 3 控制步/100 ms 提前量）时成功率峰值 90%，过小或过大均下降。

## 7. 优点

- **问题定位精准**：明确区分"去噪延迟"与"VLM 编码延迟"两个瓶颈，并分别给出对应机制，而非只解决其中之一。
- **方法设计巧妙且自洽**：
  - 滚动缓冲让每个动作获得 K 次细化但每步仅一次前向，兼顾精度与延迟；
  - 时间偏移条件使复用旧上下文仍能预测正确执行时刻的动作，理论上可推广至任意延迟；
  - FOP 用轻量路径补足感知新鲜度，避免 VLM 成为高频控制的强制同步点。
- **训练与推理一致性**：流式对齐训练严格复现推理时的噪声剖面与偏移分布，消融证明该对齐是性能关键。
- **工程细节扎实**：针对相对动作模型的坐标系转换方案、真实机器人执行延迟的显式补偿（$\delta_0$）均体现实用性。
- **评测全面**：覆盖同步/异步仿真与真实硬件，既有成功率也有延迟、观测年龄、轨迹平滑度等多维指标；消融链条完整。
- **实用性证据强**：乒乓球回球从 0–25% 提升至 90%，是较有说服力的动态响应能力展示。

## 8. 不足与局限

- **方法适用面受限**：
  - 目前仅针对**基于流的 VLA**，且延迟下界为单次动作专家前向，无法进一步压缩；
  - **必须进行流式对齐训练**，无法直接零样本套用到已有预训练模型（消融显示直接套用会崩溃）；
  - 时间偏移条件与 FOP 均需**针对动作专家做架构特定修改**，因现有 VLA 缺乏统一动作专家设计，跨模型迁移成本较高。
- **物理执行延迟未解决**：FOP 只改善观测新鲜度，动作预测到物理执行之间的延迟仍存在，可能削弱收益；真实机器人需手工调 $\delta_0$（经验值而非测量常量）。
- **实验覆盖与偏差风险**：
  - 真实世界每任务仅 20 次试验，样本量小，统计显著性未报告；
  - DOM 本地复现的基线成功率普遍低于原论文，作者归因于本地推理更慢，这可能使基线被低估、RAVEL 的相对优势被放大；
  - 同步仿真中 RAVEL 使用"无 FOP"版本评估，与异步版本能力不完全等价。
- **算力与可复现性信息不足**：未报告总训练时长、GPU 小时数、VLM 预训练成本；部分 checkpoint 依赖第三方（Motus Robotics 发布的 π0.5 RoboTwin 权重），复现链路较长。
- **评测指标依赖**：$E_{HF}$ 与 TCP jerk 受运动速度与幅度影响，作者也提示需与成功率联合解读。
- **未来方向**（作者自述）：探索跨 VLA 架构的通用流式推理、降低动作生成计算成本、以及将流式动作生成与运动规划、执行反馈更紧耦合。
