## 摘要
世界动作模型（WAM）已成为机器人操作中一种颇具前景的范式。其工作方式是先预测任务应如何执行，再从该未来中解码出动作。然而，一旦执行偏离预测，剩余动作便会失效。仅从已处于分布外的状态重新规划，很少能恢复任务仍然所需的内容；现有的执行监控器只决定何时停止，而不决定应恢复什么。我们观察到，答案其实已在手中：WAM 在行动前预测的未来，恰好描绘了它意图经历的状态。我们提出 FAVOR（未来锚定验证与在线恢复），一个轻量级框架，将这些预测帧保留为锚点，并用于验证与恢复。锚点验证器将每个观测与其锚点以及已执行动作进行比较，以标记导致任务失败的偏差。锚点引导恢复利用视觉-语言模型，将标记出的锚点转化为简短的纠正指令。在强化指令引导下，WAM 执行该指令以回到预期的未来，随后继续执行任务。在不修改策略的情况下，FAVOR 将基础 WAM 在 LIBERO 上的任务成功率从 97.85% 提升至 98.10%，在 LIBERO-Plus 上从 72.60% 提升至 72.98%。

## Abstract
World action models (WAMs) have emerged as a promising paradigm for robotic manipulation. They act by first predicting how a task should be performed and then decoding the actions from that future. However, the remaining actions are invalid once execution drifts from the prediction. Simply replanning from the already out of distribution state rarely restores what the task still requires; existing execution monitors decide when to stop, but not what to restore. We observe that the answer is already in hand: the future the WAM predicted before acting depicts exactly the states it intended to pass through. We introduce FAVOR (Future Anchored Verification and Online Recovery), a lightweight framework that keeps these predicted frames as anchors and uses them for verification and recovery. An Anchor Verifier compares each observation with its anchor, together with the executed actions, to flag deviations that break the task. Anchor-Guided Recovery uses a vision-language model to turn the flagged anchor into a short corrective instruction. Under strengthened instruction guidance, the WAM executes this instruction to return to the intended future. It then resumes the task. FAVOR raises the task success of the base WAM from 97.85% to 98.10% on LIBERO and from 72.60% to 72.98% on LIBERO-Plus without modifying the policy.

## 1. 核心问题与研究动机

- **背景范式**：世界动作模型（World Action Models, WAM）先预测任务应当经历的视觉未来，再从该未来中反解出动作（inverse dynamics），使每个动作都锚定在一个显式的未来场景之上，成为机器人操作中颇具前景的范式。
- **核心痛点**：
  - 预测的未来只是一个**计划**。动作不精确或外部扰动会使场景偏离预测路径，导致**剩余动作全部失效**。
  - 从已偏离（out-of-distribution, OOD）的状态**直接重规划几乎没有帮助**：WAM 只在成功示范上训练，从陌生状态预测的未来和由此解码的动作都不可信。
  - 现有**执行监控器**（execution monitor）只能判断"何时该停"，**无法回答"该恢复到什么状态"**。
  - 现有**恢复方法**的目标来自策略之外（人类指令、额外动力学模型、额外预测模块），需要额外训练或第二个模型。
- **关键观察（论文的出发点）**：恢复目标其实**已在策略手中**——WAM 行动前预测的未来，恰好描绘了它意图经历的状态；动作是在该未来指导下生成的，因此只要场景跟随该未来，动作就仍然有效。偏差发生时，预测帧仍展示了**丢失的条件**（例如"杯子应在夹爪中"），而这正落在策略被训练过的区域内。
- **核心原则**：把策略自己预测的未来当作**锚点（anchor）**——偏差使剩余动作失效，但不会使这些动作本想达成的状态失效。
- **两个技术挑战**：
  1. **并非所有不匹配都是偏差**：锚点由生成模型产生，可能含视觉伪影，像素级差异不等于语义不匹配。
  2. **如何把锚点传达给策略**：锚点是图像，而 WAM 只接受"观测 + 指令"；且该 WAM 对指令**几乎不敏感**（图 1 显示：固定观测与随机种子，原始指令与空指令的注意力图几乎一致）。因此锚点必须通过**纠正指令**传达，且必须**强化该指令的影响**。

## 2. 方法论

### 2.1 整体框架（FAVOR）

- **输入**：任务指令 ℓ、当前观测 o_t；**冻结**的 WAM + IDM，**不做任何策略修改或微调**。
- **流程（Algorithm 1）**：
  1. WAM 预测未来帧并解码动作块 A_c（H=16 个动作）；
  2. 保留预测帧作为**锚点**；
  3. 每 Δ=4 步执行后，用**锚点验证器**比较观测与其锚点；通过则继续执行；
  4. 告警则**丢弃该块剩余未执行动作**，保留被告警的锚点 I_anc，触发恢复；
  5. **锚点引导恢复**：VLM 生成纠正指令，WAM 在**强化指令引导**下执行该指令最多 B=64 步，返回偏差前的预期未来；
  6. 恢复窗口结束时 VLM 再次比对，若锚定条件已恢复则交回原策略继续原任务。

### 2.2 预备知识（WAM 形式化）

- **因子分解**：p(A_c | o_tc, ℓ) = ∫ p(Z_c | o_tc, ℓ) · p(A_c | o_tc, Z_c, ℓ) dZ_c，即"未来预测"×"逆动力学"。
- **未来预测**：视频模型为扩散 Transformer，用 flow matching 训练；采用 rectified flow 直线路径，目标速度为 Z(1) − Z_c；推理时从噪声反向积分 ODE 得到干净 latent Ẑ_c，解码为 H/Δ 个未来帧（间隔 Δ 个控制步）。
- **逆动力学（IDM）**：以当前 latent、预测未来和任务指令为条件，用同样的 flow matching 去噪动作 token。
- **严格时序对应**：每组 Δ 个连续动作 a_c,j 用于实现相邻两个预测帧之间的转移 Î_{c,j−1} → Î_{c,j}，因此第 t_c + jΔ 步的观测可与 Î_{c,j} 直接比较。

### 2.3 锚点验证器（Anchor Verifier）

- **动机**：图像距离既不能捕捉语义，也不能捕捉时序演化。
- **架构**：
  - 冻结 DINOv2 编码观测 I 与锚点 Î，得到 token O 与 Ô；
  - 输入为 X = [O, Ô, a（已执行动作）, p_j = jΔ/H（锚点水平位置）]；
  - 观测与锚点 token **逐位置配对**，经空间 Transformer 融合为视觉摘要；
  - 加入动作嵌入与位置嵌入得到锚点特征 x_{c,j}；
  - 用 **因果 GRU** 跨锚点传递特征，线性头 g 输出 logit u_{c,j}，分数 s = σ(u)；
  - s > τ 时告警（τ 在评估前固定）。
- **训练数据（两级监督）**：
  - **局部标注集**：同一仿真器状态下执行"干净版"与"扰动版"计划动作，逐锚点标注是否偏离。扰动包括：块后半段对机械臂命令加入晚期高斯噪声、对尾部命令做固定倍率缩放（夹爪命令不动）。
  - **回合标注集**：仅含终端成功/失败标签的自然 rollout，加上策略训练集中的示范（均视为成功）。
- **训练策略**：先用局部监督初始化，再用终端结果适配。因失败回合中许多锚点其实是正确到达的，采用**多示例学习（MIL）**：
  - 失败项：L_F = (1/|F|) Σ sp(−m_i)，只要求至少一个锚点高分；
  - 成功项：L_S = (1/|S|) Σ [½ sp(m_i) + (1/2|V_i|) Σ sp(u_{i,c,j})]，同时压制最大分与平均分，使告警稀少；
  - 总损失：L_ep = ½(L_F + L_S)，其中 sp(x) = log(1 + e^x)。
  - **可选局部监督精炼**：L_local = (λL_F + L_S)/(λ+1) + ηL_ann，L_ann 由正/负锚点 BCE、事件池化项、排序项、硬负例项组成（λ=2, η=0.1）。

### 2.4 锚点引导恢复（Anchor-Guided Recovery）

- 告警后保留锚点 I_anc，用 VLM M 生成纠正指令：ℓ_corr = M(I_anc, I_t*, ℓ)。
- 指令**命名需要恢复的条件**（如"pick up the cup"）而非要复现的像素，从而依赖**物体级状态变化**，而非与预测帧的精确视觉一致；若 VLM 判断无需纠正则返回原指令。
- **强化指令引导**：由于该 WAM 对指令不敏感，在恢复阶段对**视频生成**施加 classifier-free guidance：
  v̂(Z, s | z_t*, ℓ_corr; γ) = v(·|∅) + γ [ v(·|ℓ_corr) − v(·|∅) ]，
  空指令 ∅ 表示空文本条件，γ 为引导尺度（默认 5）。IDM 再把被引导的未来解码为恢复动作。
- 恢复窗口结束时 VLM 再次比较当前观测与锚点，判定锚定条件恢复则交回原策略。

## 6. 主要结论与发现

- FAVOR 在不修改策略的前提下，将基础 WAM 的任务成功率从 **97.85% → 98.10%（LIBERO）**、**72.60% → 72.98%（LIBERO-Plus）**；LIBERO 上失败率相对下降 **11.6%**。
- **两个组件缺一不可**：从相同告警出发，原指令直接重规划仅消除 3.3% 的基座失败（LIBERO-Plus 上为 0）；无锚点的语言纠正在 LIBERO 上消除 7.9% 但在 LIBERO-Plus 上略微有害（72.53%）；**提供锚点**才带来其余增益。
