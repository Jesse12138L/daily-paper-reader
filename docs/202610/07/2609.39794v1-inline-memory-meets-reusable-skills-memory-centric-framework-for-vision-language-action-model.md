## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大潜力，但使其适应新任务和新领域仍然效率低下：现有方法通常依赖参数调优，成本高昂，并存在对先前学习任务发生灾难性遗忘的风险。为解决这一问题，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适应形式化为显式的查询-技能记忆调优。Optimus-R 引入：(i) 用于技能提取的内联记忆接口。它将可学习记忆 token 插入 VLA 前缀流中，使骨干网络能够在原生动作条件化路径中导出控制感知的查询与技能表示。(ii) 用于技能学习的查询-技能记忆库。它将技能外化为用于决定检索什么的查询原型，以及用于指定如何行动的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 用于技能更新的轻量级桥接与适应机制。它通过轻量级适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适应、跨域适应和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 1. 核心问题与整体含义

- **研究背景**：Vision-Language-Action（VLA）模型（如 π0、π0.5、OpenVLA）已在大规模机器人数据上预训练，成为通用机器人操作的重要基础，但在真实部署中仍需适应新任务、新物体、新场景与新域。
- **核心痛点**：主流适应范式是**参数中心（parameter-centric）**的——通过全量微调、LoRA、Adapter 等更新模型权重。这带来三重代价：
  - 每次学新技能都是对模型权重的隐式改写，适应成本高；
  - 新旧技能互相干扰，易发生**灾难性遗忘**；
  - 技能难以显式检索、扩展和复用。
- **关键设问**：能否让 VLA 通过**显式记忆接口**获取、存储与复用技能，而不是反复更新模型参数？
- **三个耦合子问题**：
  1. 技能应**从 VLA 自身派生**，而非作为弱耦合的外部上下文（脱离动作条件化路径的检索记忆难以编码控制相关信息）；
  2. 技能应**显式组织**，而非被吸收进权重；
  3. 技能应在**域偏移下仍可检索**（视觉/动力学变化会使目标域观测偏离源域记忆空间）。
- **整体含义**：论文将机器人适应统一重构为「技能提取 → 技能学习 → 技能更新」三阶段，提出 Optimus-R，为 VLA 高效适配提供一条**无需反复参数微调**的新范式。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
以**查询-技能记忆库（Query-Skill Memory Bank）**为中心，将技能外化为可检索、可扩展、可局部修正的记忆条目，仅更新轻量对齐模块与原型残差，保持预训练 VLA 主干可复用。

### 2.2 内联记忆接口（Inline Memory Interface，技能提取）
- 将可学习记忆 token $E_{mem}$ 拼入 VLA 前缀流：$[H^{vl}_t; M_t] = F_\theta(O_t, L; E_{mem})$，使记忆状态 $M_t$ 在**原生动作条件化路径**内产生。
- 用两个独立的注意力池化算子从共享记忆状态中读出检索分支与技能分支：
  - $\bar{m}^q_t = \text{AttnPool}_q(M_t)$，$\bar{m}^s_t = \text{AttnPool}_s(M_t)$
  - 分别经查询编码器与技能编码器得到 $q_t \in \mathbb{R}^{d_q}$（仅用于检索）、$s_t \in \mathbb{R}^{d_s}$（行为表示，作为技能值）。
- **技能空间锚定**：训练期用轻量 Skill Decoder 以 $s_t$ 重建未来动作块 $\hat{A}^s_t = D_s(s_t)$，用 Huber 损失监督，使技能空间与可执行行为对齐。
- Token Projector $T_\psi$ 将技能嵌入映射为 VLA 兼容的技能 token $S_t$，条件化 Flow Policy 生成动作块。

### 2.3 查询-技能记忆库（技能学习）
- 记忆库条目：$\mathcal{B} = \{(p^q_j, p^s_j, n_j, E_j)\}_{j=1}^{K}$，其中 $p^q_j$ 为查询原型（决定「检索什么」），$p^s_j$ 为技能原型（决定「如何行动」），$n_j$ 为支持计数，$E_j$ 为用于回放的紧凑隐式查询-技能对集合。
- **建库流程**：先做**运动感知下采样**（按动作变化分数 $\nu_i$ 保留高动态样本）与**归一化进度分层采样**；再在查询空间聚类，对技能方差过高的簇在技能空间二次划分（Skill Clustering）。
- **检索**：查询先经对齐 $q'_t = A_{mem} q_t$，在残差修正后的原型上计算相似度，取 top-$K_r$ 做 softmax 加权：$\hat{s}_t = \sum_{j \in N_t} \alpha_{tj}(p^s_j + \Delta p^s_j)$。
- **残差原型**：用 $\Delta p^q_j$、$\Delta p^s_j$ 做局部修正而不覆盖基础原型，实现「可复用技能 + 局部适配」的解耦。

### 2.4 桥接与适应机制（Bridge-and-Adapt，技能更新）
三阶段训练，共用同一记忆适应目标 $L_{life} = L_{fm} + \lambda_{align}\|\tilde{s}_t - \text{sg}(s_t)\|_2^2 + \lambda_{reg}\sum_{j \in A_t}(\|\Delta p^q_j\|^2 + \|\Delta p^s_j\|^2)$：

- **Stage A（接口预训练）**：训练记忆 token、双注意力池化、查询/技能编码器、技能解码器、Token Projector 及主干最后若干层，目标 $L_{pre} = L_{fm} + \lambda_q L^{nce}_q + \lambda_s L_{skill}$；查询对比损失以「同任务 + 邻近归一化进度」及「同轨迹局部邻近状态」为正样本。之后冻结接口并构建初始记忆库。
- **Stage B（桥接适应）**：面向跨域（如 sim-to-real），解冻主干并更新 $A_{mem}$、$\tau_{mem}$ 与活跃原型残差；当技能空间失配较大时启用**低秩残差技能适配器** $\tilde{s}_t = \hat{s}_t + U_s V_s^\top \hat{s}_t$（$r \ll d_s$，零初始化，初始保持 $\hat{s}_t$）。适配器是否启用由新颖率 $\eta_{batch}$ 与对齐误差 $e_{align}$ 连续超阈值触发。
- **Stage C（记忆适应）**：面向域内终身学习，冻结主干与接口，仅更新 $A_{mem}$、$\tau_{mem}$、活跃原型残差与记忆库结构。查询接近已有原型时更新残差与统计；否则进入候选缓冲，仅当簇满足 $|C_{new}| \ge N_{min}$、$Var_q \le \epsilon_q$、$Var_s \le \epsilon_s$ 时才追加新原型。回放使用隐式查询-技能对（不存原始图像/动作），新任务与回放比例约 3:1。

### 2.5 推理路径
推理时不需要 Skill Encoder/Decoder：由 $M_t$ 生成查询 → $A_{mem}$ 对齐 → top-$K_r$ 检索 → 可选适配器修正 → $T_\psi$ 投影为技能 token → 条件化 Flow Policy 输出动作块。默认超参：$m=4$ 记忆 token，$d_q=d_s=256$，$n_s=4$ 技能 token，top-2 检索，$K_0=128$ 初始原型，适配器秩 $r=8$。

## 6. 主要结论与发现

- **域内数据高效**：30% 数据下，LIBERO 平均成功率较 π0.5 提升 **16.5%**（72.1 → 88.6），CALVIN 平均完成长度提升 **0.42**（2.09 → 2.51），RoboTwin 2.0 Hard 提升 **5.0%**（9.8 → 14.8）；100% 数据下 LIBERO 达 97.8%、RoboTwin Hard 达 55.0%，均为对比中最佳。
- **跨域迁移有效**：每任务仅 20 条真实示范即达 **33.3%** 成功率，超 π0.5 **13.9%**；80 条示范下达 72.2%，在长程与顺序任务（S.P.P.、B.Sq.）上增益明显。
- **缓解灾难性遗忘**：20 条示范学新任务时成功率超 π0.5 **11.0%**；80 条示范适应后平均遗忘率从 **15.0% 降至 10.0%**，旧任务保持 77.5%。
- **效率优势**：在同等可训练参数下，以更少 GPU 小时（86 vs 128）取得更高成功率，推理频率更高（14 Hz）。
- **消融结论**：Stage-B 桥接对域内影响小，但去除后 20 示范真实世界成功率从 33.3% 骤降至 12.8%，说明**仅扩展记忆不足以应对显著域偏移，坐标对齐是关键**；技能感知聚类与样例回放各贡献约 2.0% 与 1.5% 成功率。
- **定性发现**：模型可将已学操作结构零样本迁移到新物体-容器组合；检索空间可视化显示语义相近任务（如 bowl→plate 与 soup→basket）在查询空间中形成重叠邻域，与技能共享一致。

## 7. 优点

- **范式创新**：将 VLA 适应从「参数中心」转向「记忆中心」，把技能外化为显式查询-技能键值对，天然支持复用、扩展与检查，缓解灾难性遗忘。
- **接口设计合理**：内联记忆 token 使记忆状态在原生动作条件化路径内生成，配合注意力池化 + 技能解码器辅助监督，保证技能表示与可执行行为对齐，优于脱离式外部检索。
- **解耦彻底**：查询（决定检索什么）与技能值（决定如何行动）分离存储，检索与行为表示各司其职。
- **残差式适配**：原型残差 + 低秩技能适配器 + 零初始化设计，实现「不覆盖基础原型」的局部修正，兼顾稳定性与可塑性。
- **回放无隐私负担**：回放仅存隐式查询-技能对，不存原始图像/动作/轨迹，降低存储与隐私成本。
- **实验体系完整**：同时覆盖域内、跨域与终身学习三类场景，并报告成功率、遗忘率、GPU 小时、推理 Hz、参数量的多维指标，论证较全面。
