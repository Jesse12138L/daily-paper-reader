## 摘要
世界动作模型（WAMs）利用预训练视频模型，通过联合预测未来视觉状态与动作，提升机器人控制中的泛化能力。这种能力带来了显著的推理成本，因为在去噪过程中会反复处理密集的未来帧 token。先前方法通过 token 剪枝来解决该问题，其优先考虑视觉保真度，以降低视频扩散模型中的去噪成本。然而，这些方法在 WAMs 的联合去噪过程中并未利用动作相关性来决定保留哪些未来帧 token。本文提出 Sparse-WAM，一种无需训练的、动作引导的稀疏想象框架，通过选择性处理未来帧 token 来加速 WAM 推理。我们观察到，尽管未来表示持续更新，但在连续去噪步骤之间，动作 token 对未来帧 token 的注意力（动作到未来注意力）的空间分布存在显著重叠。受此启发，我们提出了动作引导的 token 选择（Action-Guided Token Selection），以保留帧特定的动作相关区域以及跨帧上下文。然而，朴素实现会带来注意力评分和 token 打包开销，从而抵消剪枝带来的计算节省。因此，我们引入 Pilot，一种高效引擎，通过轻量级评分和跨步骤复用 token 选择来降低稀疏推理开销。在 LIBERO 上使用 FastWAM-Joint，以及在 RoboLab-120 上使用 Cosmos 3 Edge，Sparse-WAM 在 NVIDIA RTX 4090 上相较于密集 eager 推理分别实现了约 2.0 倍和 1.8 倍的推理加速，同时基本保持了任务性能。

## Abstract
World-action models (WAMs) leverage pretrained video models to improve generalization in robot control by jointly predicting future visual states and actions. This capability comes at a substantial inference cost, as dense future-frame tokens are repeatedly processed during denoising. Prior methods address this by token pruning that prioritizes visual fidelity to reduce denoising costs in video diffusion models. However, these methods do not use action relevance to determine which future-frame tokens to retain during joint denoising in WAMs. In this paper, we propose Sparse-WAM, a training-free framework for action-guided sparse imagination that selectively processes future-frame tokens to accelerate WAM inference. We observe substantial overlap in the spatial distribution of attention from action tokens to future-frame tokens (action-to-future attention) between consecutive denoising steps, despite continued updates to the future representations. Motivated by this, we develop Action-Guided Token Selection to retain frame-specific action-relevant regions together with cross-frame context. However, a naive implementation can incur attention-scoring and token-packing overhead that offsets the computational savings from pruning. We therefore introduce Pilot, an efficient engine that reduces sparse inference overhead through lightweight scoring and cross-step reuse of token selections. On LIBERO with FastWAM-Joint and RoboLab-120 with Cosmos 3 Edge, Sparse-WAM achieves inference speedups of approximately $2.0\times$ and $1.8\times$, respectively, over dense eager inference on an NVIDIA RTX 4090, while largely preserving task performance.

# Sparse-WAM 论文结构化总结

## 1. 核心问题与整体含义

- **背景**：世界动作模型（World Action Models, WAMs）借助预训练视频模型的时空先验，在机器人控制中**联合去噪**未来视觉状态（未来帧 token）与动作块（action chunk），从而提升泛化性与鲁棒性。
- **核心矛盾**：显式生成高分辨率未来帧会把大量视觉 token 引入**每一个去噪步**，而去噪步成本随 token 数显著增长，导致推理延迟高、控制频率受限。
- **现有做法的缺口**：
  - 一类方法在推理时**直接去掉想象**（训练时用、推理时不用），牺牲未来预测能力；
  - 一类方法**压缩未来帧 token**（低分辨率、紧凑潜变量等），但仍会把算力花在与动作弱相关的区域；
  - token 剪枝在 VLA 中依赖**观测输入相关性**，在视频扩散中依赖**视觉保真度**，二者都不能直接回答"哪些正在演化的未来区域真正支撑动作预测"。
- **WAM 特有难点**：未来帧 token 由噪声初始化，与动作 token 一起被联合去噪、持续演化，**动作相关区域无法预先确定**。
- **论文含义**：提出 Sparse-WAM——一个**免训练**的动作引导稀疏想象框架，用"动作 token → 未来帧 token"的注意力来在线分配未来帧 token 的计算，并配合高效执行引擎 Pilot，在不重训模型的前提下加速 WAM 推理。

## 2. 方法论

### 2.1 核心思想

- 用**动作到未来注意力**（action-to-future attention）作为 token 相关性的低成本代理指标，选择性地只对未来帧的一部分空间位置做 Transformer 计算，**保留全部观测 token 与动作 token**。
- 关键洞察（三条经验观察）：
  1. **动作–帧时间对齐**：帧级注意力呈近似对角带，每个未来帧主要被约 `H/F` 个连续动作查询关注，边界查询还会关注邻近帧；且注意力热点在**帧间空间上会移动**。
  2. **跨帧上下文一致性**：剔除热点区域后，跨帧注意力空间重叠反而上升，说明存在稳定共享的上下文区域（如夹爪等非接触区）。
  3. **跨步注意力一致性**：连续去噪步之间空间注意力分布高度重叠（Cosmos 3 Edge 平均 81.11%，FastWAM-Joint 97.97%），而未来表示本身仍在变化——因此可**跨去噪步复用 token 选择**。

### 2.2 关键技术细节

- **注意力定义**：`U^(τ)_ℓ(i,f,j)` 为第 ℓ 层、第 τ 步、动作查询 i 对未来帧 f 的空间位置 j 的注意力权重，在 `Nh` 个头上取平均。

- **层质量评估**：为每层打质量分 `Q_ℓ = R_ℓ(1 − E_ℓ)`，其中 `R_ℓ` 衡量帧对齐注意力质量，`E_ℓ` 为跨帧平均的归一化空间熵。取分数最高的 `K_layer`（默认 6）层构成 `L_core`，据此聚合空间分数 `V(f,j)`。

- **空间打分**：将 H 个动作查询按顺序切成 F 组 `I_f`（每组 H/F 个），帧 f 的空间分数 `S_ℓ(f,j) = Σ_{i∈I_f} α_{f,i} U_ℓ(i,f,j)`；**中心查询权重更大**（Cosmos 归一化权重 (1,2,2,1)/6；FastWAM-Joint 中心 1/12、外围 1/24）。

- **帧特定核心 token（Core）**：先构造公共候选池 `P = TopK_j∈J( max_f V(f,j), Ns−Ks )`，再对每帧取 `C_f = TopK_{j∈P}( V(f,j), Kc )`，使保留位置能跟随帧间移动的热点。

- **共享空间锚点（Anchor）**：从 `E = J \ ∪_f C_f` 中选，评分用跨帧均值与变异系数 `μ_j / (1 + CV_j)`（强度大、跨帧稳定者优先），取前 `Ks` 个。核心与锚点互斥，每帧恰好保留 `Kc + Ks` 个 token；**只有锚点位置共享，其表示仍按帧独立更新**。

- **Pilot 高效引擎**：
  - **轻量注意力剖析**：直接复用原始 log-sum-exp 归一化器，只计算各帧与其对齐查询组之间的 QK 乘积并归约，**不物化完整注意力矩阵、不做 value 加权输出、不增加额外前向**。
  - **跨步复用**：默认只在初始完整步 `τ_d = 0` 做全量计算，构建选择并缓存视觉速度预测，后续稀疏步复用；每个新动作块重新计算。
  - **紧凑执行**：复用原始位置索引与打包元数据，固定每帧 token 预算以保持序列长度恒定，便于编译执行。

- **被省略区域的采样更新**：用掩码 `M_v` 组合当前预测与缓存预测 `ẽv^(τ) = M_v ⊙ v^(τ)_v + (1 − M_v) ⊙ v^(τ_d)_v`，使被剪掉的未来 token 仍参与采样过程；**动作预测每一步都重算**。

## 6. 主要结论与发现

- **核心结论

（承接第 6 节开头）

- **核心结论**：在 WAM 中，**"想象"并非处处等权**——只有少数与动作强相关的未来帧空间区域真正支撑动作预测，其余区域的 Transformer 计算可以安全省略。基于此，Sparse-WAM 在不重训、不改动模型权重的前提下，把未来帧 token 的算力集中到这些区域，从而在成功率基本持平的情况下获得明显加速。
- **性能保持**：在 LIBERO 四套件、LIBERO-Plus 七类扰动、RoboLab-120（Simple / Moderate / Complex）以及真实世界三任务上，Sparse-WAM 的成功率与稠密基线总体相当，且在部分设置下因抑制了与动作无关的视觉噪声而略有提升；相较 ToCa、WorldCache、SpecPrune-VLA、C³ache 等基线，它在"成功率—加速比"的帕累托前沿上整体占优。
- **效率收益**：随剪枝率从 28.89% 提升到 68.89%，FLOPs 与延迟持续下降，成功率呈先稳后降的趋势，说明存在一个"安全剪枝区间"；在匹配执行后端（CUDA Graph + torch.compile）的公平口径下，方法本身的净收益约为 1.5–1.6×，而叠加后端优化后可达到 1.8× 以上。
- **组件有效性（消融）**：
  - **core-only** 已能带来大部分加速，但会丢失跨帧共享的稳定上下文，成功率有可见下降；
  - **stable-only（锚点）** 单独使用保留的信息过于保守，加速有限；
  - **core + stable** 组合最优，说明"帧特定热点 + 跨帧稳定锚点"两者互补；
  - **random** 选择作为对照显著劣于注意力引导选择，证明增益来自**动作相关性**而非单纯的 token 数量减少。
- **注意力统计的支撑作用**：跨步空间注意力重叠高（Cosmos 3 Edge 平均 81.11%、FastWAM-Joint 97.97%）直接支持了"选择可跨去噪步复用"的设计；复用频率分析表明，只在初始完整步做一次选择即可，频繁刷新带来的收益递减而开销上升。
- **鲁棒性**：在 LIBERO-Plus 的背景、相机、语言、光照、布局、机器人初始状态、传感器噪声七类扰动下，稀疏化并未系统性放大性能退化，说明动作引导的选择在分布偏移下仍具一定稳定性。

## 7. 局限性

- **硬件覆盖面窄**：推理评测仅在单张 RTX 4090、batch size 1 下进行，未报告 A100/H100 等数据中心 GPU、多卡或高并发场景的结果；batch size 1 的低占用率可能使加速比与实际部署（批处理/流水线）表现存在偏差。
- **超参数与模型绑定**：层质量打分、`K_layer`、`Kc`、`Ks`、中心查询权重等均为按模型（Cosmos 3 Edge / FastWAM-Joint）分别调定的启发式参数，论文未给出自动选取或跨模型迁移的通用准则，迁移到新 WAM 时可能需要重新标定。
- **依赖注意力可解释性假设**：方法以动作→未来帧注意力作为相关性代理，若某些模型层/头的注意力分布高度弥散或与动作因果性弱相关，代理指标可能失效；论文未系统检验"注意力高 ≠ 动作重要"的反例情形。
- **缓存的误差累积风险**：被省略区域采用"复用初始步速度预测"的策略，在长时程、快速动态或接触频繁的任务中，缓存与真实演化可能偏离，论文未定量刻画这种偏离随去噪步数与任务时长的增长。
- **真实世界证据薄弱**：仅 3 个任务、每任务 rollout 次数少（成功率以 12 次为分母，如 66.67% = 8/12），缺乏置信区间或多种子统计，难以支撑强结论；且未报告真实场景下的实际控制频率与端到端延迟。
- **成本报告不完整**：未报告微调墙钟时间、GPU 小时、显存占用与能耗，难以评估完整部署成本。
- **理论刻画缺失**：没有给出稀疏化引入的误差界或近似保证，方法正确性主要依赖经验验证。

## 8. 启发与可迁移性

- **"动作条件化剪枝"这一范式**具有跨模型可迁移性：凡是把动作 token 与未来/潜在视觉 token 联合去噪的架构（WAM、带想象的 VLA、世界模型式规划器），都可复用"用动作查询的注意力分布定位关键视觉区域"的思路。
- **免训练加速**降低了落地门槛：相较需要蒸馏或重训的加速方案，本方法可直接叠加在已发布权重上，适合作为推理侧的即插即用优化。
- **跨去噪步复用**的观察对扩散类策略普遍有价值：若注意力选择在步间高度稳定，则"选择一次、复用多步"可推广到动作去噪本身（如动作 token 剪枝）或其他迭代式生成策略。
- **工程与算法解耦的报告方式**值得借鉴：把"算法收益"与"执行后端收益"拆开汇报，能更诚实地反映方法贡献，也提示后续工作在比较时应统一后端配置。

## 9. 总体评价

- **贡献定位**：论文把一个具体而真实的效率瓶颈（WAM 联合去噪中未来帧 token 的高昂成本）转化为一个清晰的问题——"哪些正在演化的未来区域真正支撑动作预测"，并给出了低成本、免训练、可落地的答案。
- **优点**：问题定义清晰；三条经验观察（时间对齐、跨帧上下文一致性、跨步一致性）为设计提供了可验证的实证依据，而非纯工程直觉；组件消融与随机对照使因果归因较有说服力；实验覆盖 3 个 WAM、3 个仿真基准与真实机器人，并同时报告 SR、加速比与 FLOPs。
- **主要保留意见**：主表加速比相对 dense eager 汇报，混合了算法与后端收益（附录已部分澄清）；真实世界样本量偏小；关键超参数按模型手工调定，通用性有待验证；缓存误差累积缺乏理论或长时程实证刻画。
- **适用建议**：适合对推理延迟敏感、且使用联合去噪式 WAM/VLA 的部署场景；在采用前建议在自己的模型上重新标定 `K_layer / Kc / Ks` 与剪枝率，并在目标硬件、目标 batch size 下复测延迟，同时监控长时程任务中的缓存偏差。
