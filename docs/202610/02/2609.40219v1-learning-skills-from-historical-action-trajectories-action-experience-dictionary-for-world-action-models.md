## 摘要
世界动作模型（WAMs）将视觉动态预测与动作生成耦合在一起，但并未显式支持跨操作任务的动作经验复用。此外，现有 WAM 难以捕捉可指导目标动作预测的潜在跨任务语义关系，因为冗余背景元素会干扰关键视觉信息的提取。为应对这些挑战，我们提出一种新颖的动作经验字典（AED），它将历史物理动作轨迹编码为共享动作嵌入，以支持技能复用并对跨任务关系进行建模。具体而言，我们首先聚合历史动作以与视觉观测对齐，并使用预训练的动作分词器从 AED 中检索动作嵌入。随后，我们通过交叉注意力对池化嵌入进行视觉条件化，并将其前置到含噪动作 token 之前，为预测提供交互上下文和动作意图。为了对动作相关运动进行建模并减少对无关背景线索的依赖，我们引入运动感知的转移损失，在随机时间区间上监督视觉特征变化预测。在仿真基准和真实世界跨具身设置上的实验验证了我们的 AED 的有效性。匿名项目网站见：https://github.com/JiahuaDong/AED （AED）。

## Abstract
World Action Models (WAMs) couple visual dynamics prediction with action generation, yet they do not explicitly support the reuse of action experience across manipulation tasks. Furthermore, existing WAMs struggle to capture underlying cross-task semantic relationships that could guide target action prediction, as redundant background elements interfere with the extraction of key visual information. To address these challenges, we develop a novel Action Experience Dictionary (AED) that encodes historical physical action trajectories into shared action embeddings to support skill reuse and model cross-task relationships. Specifically, we first aggregate historical actions to align with visual observations and retrieve action embeddings from the AED using a pretrained action tokenizer. Subsequently, we visually condition the pooled embeddings through cross-attention and prepend them to noisy action tokens, providing interaction context and action intent for prediction. To model action-related motion and reduce reliance on irrelevant background cues, we introduce a motion-aware transition loss that supervises visual feature change prediction over random temporal intervals. Experiments on simulation benchmarks and in real-world cross-embodiment settings verify the effectiveness of our AED. The anonymous project website is available at \href{https://github.com/JiahuaDong/AED}{AED}.

## 2. 方法论

- **核心思想**：构建可学习的动作经验字典 AED，将历史动作轨迹 token 化后检索共享动作嵌入；再通过视觉条件化把动作模式与任务视觉上下文结合；最后用运动感知转移损失（MT loss）监督视觉特征变化预测，减少对背景的依赖。
- **AED 构建与动作聚合**：
  - AED 为可学习矩阵 \(D \in \mathbb{R}^{N \times d_a}\)，每个条目表示一种动作模式，多个条目联合刻画操作技能。
  - 历史动作轨迹 \(a_h \in \mathbb{R}^{H \times d_f}\) 先按视觉观测间隔聚合为 \(\bar a_h \in \mathbb{R}^{V \times d_f}\)：对机械臂控制维度累加，对夹爪维度保留最终命令，以对齐 \(V\) 个视觉观测。
  - 使用预训练动作 tokenizer \(\Phi\)（FAST+）将每个聚合动作映射为索引序列，再从 AED 检索对应嵌入并平均，加上时间位置编码，得到 \(f^\star \in \mathbb{R}^{V \times d_a}\)。
- **视觉条件化动作嵌入**：
  - 历史视觉 latent 先用可学习 query 压缩为固定数量视觉 token \(\hat z_v^h\)，减少背景冗余和序列长度。
  - 用单层 Transformer 编码器 \(E\)，以 \(f^\star\) 为 query、压缩视觉 token 为 key/value，生成视觉条件化动作嵌入 \(e_v \in \mathbb{R}^{V \times d_a}\)。
  - 将 \(e_v\) 与含噪动作 token \(a_n\) 拼接为 \(a^\star = [e_v; a_n]\)，送入 action expert 预测动作 chunk。
- **运动感知转移损失（MT loss）**：
  - 随机采样未来时间 \(t'\) 和窗口 \(\Delta\)，用冻结视觉编码器 \(F\) 提取 \(h_{t'} = F(o_{t'})\)。
  - 从 action expert 取 final-layer hidden states \(u^\Delta_{t'}\)，用三层 predictor \(G\) 以 \(h_{t'}\) 为 query、\(u^\Delta_{t'}\) 为 key/value，预测视觉特征变化 \(\widehat{\Delta h}_{t'}\)。
  - 监督目标为真实特征差 \(\Delta h_{t'} = h_{t'+\Delta} - h_{t'}\)，损失为 Frobenius 范数均方误差。
  - **理论**：Theorem 1 表明该采样损失是采样加权风险的无偏估计，组合风险满足 \(C_{MT}(\theta) \le (V-1)(3V-4)R_{MT}(\theta)\)，即期望 MT loss 消失蕴含未来区间均方组合误差消失。
- **训练与推理**：
  - 总损失 \(L = L_{FM} + \lambda_m L_{MT}\)，其中 \(\lambda_m = 0.01\)；\(L_{FM}\) 对视频和动作分支做 flow matching，权重均为 1。
  - 推理时不需要解码视频帧，也不需要 MT predictor；用 flow-matching ODE 的 Euler 步去噪，预测长度为 \(H\) 的动作 chunk，部署时执行前若干动作后重规划。
