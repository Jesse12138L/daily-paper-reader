## 摘要
世界动作模型（WAM）将机器人动作生成与未来状态预测相结合。现有 WAM 通常预测视频或学习到的视觉潜变量，这些表示仅隐式地刻画交互几何，并可能保留与控制无关的外观信息。我们提出 SkeleWAM，一种紧凑的 WAM，将操作场景表示为由机器人关节、物体中心和交互点构成的稀疏 3D 骨架。该骨架根据当前 RGB-D 观测和机器人本体感知在线构建，为动作生成和未来骨架预测提供统一的几何状态。未来骨架预测为动作学习提供额外的几何监督，且无需视觉重建。在推理时，SkeleWAM 直接根据当前骨架和语言指令生成动作，而 Medoid Action Consensus（MAC）作为一种辅助共识策略，用于随机动作样本。在 LIBERO-Plus 上，SkeleWAM 以 57.1M 参数达到 85.9% 的总体成功率，比 Cosmos-Policy 高出 3.7 个百分点。这些结果表明，稀疏的 3D 机器人—物体结构为稳健且参数高效的世界动作学习提供了有效的状态空间。项目见 https://skelewam-project.github.io/。

## Abstract
World action models (WAMs) combine robot action generation with future state prediction. Existing WAMs typically predict videos or learned visual latents, which represent interaction geometry only implicitly and may retain appearance information unrelated to control. We introduce SkeleWAM, a compact WAM that represents a manipulation scene as a sparse 3D skeleton composed of robot joints, object centers, and interaction points. Constructed online from current RGB-D observations and robot proprioception, the skeleton provides a unified geometric state for action generation and future skeleton prediction. Future skeleton prediction provides additional geometric supervision for action learning without requiring visual reconstruction. At inference, SkeleWAM generates actions directly from the current skeleton and language instruction, while Medoid Action Consensus (MAC) serves as an auxiliary consensus strategy for stochastic action samples. On LIBERO-Plus, SkeleWAM achieves an overall success rate of 85.9% with 57.1M parameters, outperforming Cosmos-Policy by 3.7 percentage points. These results demonstrate that sparse 3D robot--object structure provides an effective state space for robust and parameter-efficient world action learning. The project is available at https://skelewam-project.github.io/.

## 1. 核心问题与研究动机

- **背景**：机器人操作学习正从任务专用视觉运动策略（如 ACT、Diffusion Policy、DP3）发展到通用机器人基础模型与 VLA 模型（如 RT-2、Octo、OpenVLA、π0、π0.5）。世界动作模型（WAM）在此基础上进一步联合建模动作生成与未来状态预测，以未来状态作为动作学习的额外监督。
- **核心问题**：现有 WAM 通常将未来状态表示为生成视频或学习到的视觉潜变量。视频预测计算开销大；视觉潜变量虽降低成本，但其保留的信息主要由视觉编码器及其预训练目标决定，**无法显式分离支配机器人—物体交互的几何变量**（空间构型与相对运动），且可能保留与控制无关的外观信息。
- **研究动机**：作者提出一个根本性问题——**能否用机器人—物体结构的稀疏表示支撑有效的世界动作学习，同时大幅降低模型复杂度？**
- **整体含义**：论文主张操作场景中与控制最相关的部分可用稀疏 3D 骨架（机器人关节、物体中心、交互点）显式刻画，从而构建一个紧凑、稳健、参数高效的世界动作模型。

## 2. 方法论

### 2.1 核心思想
- 将操作场景统一表示为**稀疏 3D 骨架** $S_t \in \mathbb{R}^{N\times 3}$，由机器人关节/末端执行器位置、物体中心、物体交互点构成。
- 训练时联合学习**动作生成**与**未来骨架预测**，后者作为共享几何表示的辅助监督；推理时丢弃未来预测分支，仅由当前骨架与语言指令直接生成动作。
- 引入 **Medoid Action Consensus（MAC）** 作为随机动作采样的辅助共识策略，无需奖励模型或轨迹平均。

### 2.2 关键技术细节
- **骨架构建**：
  - 机器人节点 $J_t \in \mathbb{R}^{N_r \times 3}$ 由前向运动学计算。
  - 每个物体 $m$ 表示为 $P_{t,m} = [c_{t,m}; u_{t,m,1}; \dots; u_{t,m,L_m}]$，其中 $c_{t,m}$ 为物体中心，$u_{t,m,j}$ 为交互点。
  - 完整骨架 $S_t = [J_t; P_{t,1}; \dots; P_{t,M}]$，节点总数 $N = N_r + \sum_m (1+L_m)$。
  - 物体标志点由**冻结的预训练感知网络**从 RGB-D 观测估计，所有坐标统一在机器人中心坐标系并归一化。
- **网络结构**：
  - 语言指令编码为 $C_\ell = E_{\text{lang}}(\ell)$。
  - 输入适配器将当前骨架、加噪动作块、加噪未来骨架序列映射为 token：$X^c_t = \phi_c(S_t)$，$X^a_{t,\tau_a} = \phi_a(\tilde{A}_{t,\tau_a})$，$X^s_{t,\tau_s} = \phi_s(\tilde{S}^+_{t,\tau_s})$。
  - 采用 **Mixture-of-Transformers 双专家设计**：世界专家处理当前与未来骨架 token（共享参数），动作专家处理动作 token，两者均以 $C_\ell$ 为条件。
  - 使用块注意力掩码 $M = \begin{bmatrix}1&0&0\\1&1&0\\1&0&1\end{bmatrix}$，当前骨架组内自注意力，各预测组仅关注当前骨架与自身，**动作与未来骨架 token 之间无注意力交互**。
- **训练目标（流匹配）**：
  - 插值路径：$\tilde{A}_{t,\tau_a} = (1-\tau_a)A_t + \tau_a\epsilon_a$，$\tilde{S}^+_{t,\tau_s} = (1-\tau_s)S^+_t + \tau_s\epsilon_s$。
  - 目标向量场：$v_a = \epsilon_a - A_t$，$v_s = \epsilon_s - S^+_t$。
  - 联合损失：$\mathcal{L} = \mathcal{L}_{\text{action}} + \lambda_s \mathcal{L}_{\text{skeleton}}$，两项均为 MSE；两个损失均更新世界专家。
- **推理与 MAC**：
  - 从高斯噪声出发，以 10 步流积分求解 $\frac{d\tilde{A}_{t,\tau}}{d\tau} = \hat{v}^a_\theta(\tilde{A}_{t,\tau}, \tau; S_t, \ell)$，$\tau: 1\to 0$。
  - MAC 对 $K$ 个独立噪声初始化的候选轨迹，在归一化动作空间的前 $h$ 步、$d_m$ 个连续运动维度上计算两两距离 $d_{ij}$，选择平均相异度 $c_i$ 最小的候选作为中位轨迹。
  - 执行前 $H_e \le H_a$ 个动作后重新观测、更新骨架并重复；MAC 无需奖励/价值模型，避免平均不兼容轨迹。

## 6. 主要结论与发现

- **仿真性能**：SkeleWAM 以 **57.1M 参数**达到 **85.9%** 总体成功率，比最强观测基线 Cosmos-Policy（82.2%）高 **3.7 个百分点**；相机扰动下达 93.4%（超 Cosmos-Policy 17.6 点）；语言、背景、噪声扰动下均为观测类最佳。
- **sim-state 参考**：达 87.7%（51.4M 参数），仅比 RGB-D 设定高 1.8 点，说明冻结感知网络提供的骨架估计已相当有效，但仍留改进空间。
- **布局扰动局限**：仅 66.6%（π0.5 为 84.1%），即使 sim-state 也只有 69.0%，说明稀疏几何本身不足以应对大幅空间布局变化，该困难超出视觉定位问题。
- **真实世界**：平均成功率 **89%**，超 Cosmos-Policy、Fast-WAM、π0.5 分别 2、6、13 个百分点，5 个任务中 4 个达最高或并列最高。
- **消融结论**：
  - 物体中心+交互点组合（85.9%）显著优于仅中心（82.3%）和仅交互点（77.7%）。
  - 移除未来骨架监督后降至 80.1%，**5.8 点提升来自未来骨架监督**。
  - 跨分支注意力影响很小（85.6%/84.8%/85.9%），主要收益来自共享世界专家的联合训练而非分支间信息交换。
  - $H_e=16$ 最优（85.9%），短于/长于均下降；$K=3$ 最优（85.9%），$K$ 增大不单调提升；$h=10$ 最优但整体对窗口不敏感（差异 ≤0.6 点）。

## 7. 优点

- **表示创新**：用稀疏 3D 骨架（关节+物体中心+交互点）显式参数化交互几何，剥离外观信息，状态空间紧凑且与控制强相关。
- **参数高效**：57.1M 参数即超越数十亿参数的 VLA 与世界模型基线，推理时丢弃未来预测分支，部署成本低。
- **训练-推理解耦**：未来骨架预测仅作训练期辅助监督，不增加推理开销，也不要求视觉重建。
- **MAC 设计轻量**：无需奖励/价值模型，避免轨迹平均带来的不兼容问题，且与采样数非单调关系被诚实报告。
- **鲁棒性突出**：在相机、背景、噪声等外观/视角扰动下优势明显，验证了机器人中心坐标系几何表示的稳健性。
- **消融系统**：对骨架组成、监督信号、注意力流向、执行时域、采样策略等逐一分析，结论清晰。
