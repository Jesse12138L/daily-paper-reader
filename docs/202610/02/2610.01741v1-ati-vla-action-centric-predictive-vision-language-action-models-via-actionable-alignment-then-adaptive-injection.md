## 摘要
预测式视觉-语言-动作（VLA）模型旨在通过未来观测或世界动态预测来提升机器人操作性能。然而，现有方法往往未能实现这一潜力，且性能不如直接动作预测模型。我们认为，这些局限源于观测与动作之间的模态失配，以及联合优化冲突使学习偏离以动作为中心的目标。为此，我们提出 ATI-VLA，一种通过先可操作对齐后自适应注入实现的以动作为中心的预测式视觉-语言-动作框架。具体而言，它采用两步设计：1）通过共享码本进行可操作表示对齐。它通过统一码本将预测观测和动作表示映射到共享的离散潜空间，从而对齐二者，使预测观测潜变量可直接用于动作生成，并缓解模态失配。2）以动作为中心的自适应预测潜变量注入。在此基础上，它随后通过轻量级自适应侧路径，将预测观测潜变量作为显式预测先验注入动作解码中，从而在单一以动作为中心的目标下实现自适应预测引导。在仿真和真实世界机器人任务上的大量实验表明，ATI-VLA 达到了最先进性能，且收敛更快。

## Abstract
Predictive Vision-Language-Action (VLA) models aim to improve robotic manipulation via future observation or world dynamics forecasting. However, existing approaches often fail to realize this potential and underperform direct action prediction models. We argue that these limitations stem from modality misalignment between observations and actions, together with joint optimization conflicts that drive learning away from an action-centric objective. To this end, we introduce ATI-VLA, an Action-Centric Predictive Vision-Language-Action framework via Actionable Alignment Then Adaptive Injection. Specifically, it follows a two-step design: 1) Actionable Representation Alignment via a Shared Codebook. It aligns predictive observation and action representations by mapping both modalities into a shared discrete latent space via a unified codebook, making predictive observation latents readily usable for action generation and mitigating modality misalignment. 2) Action-Centric Adaptive Injection of Predictive Latents. Building upon this, it then injects predictive observation latents into action decoding as explicit predictive priors via a lightweight adaptive side-path, enabling adaptive predictive guidance under a single action-centric objective. Extensive experiments on both simulation and real-world robotic tasks demonstrate that ATI-VLA achieves state-of-the-art performance with faster convergence.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型已成为机器人操作的主流统一范式，将观测与语言指令直接映射为底层动作。近期出现的**预测式 VLA**（Predictive VLA）进一步显式预测未来观测或世界动态，希望为动作生成提供前瞻性引导。
- **核心矛盾**：作者通过实证分析发现，现有预测式 VLA **普遍不如非预测式的直接动作预测模型**（如图 1(d) 所示）。也就是说，"把未来预测当作辅助任务"并不能可靠地转化为动作生成的提升。
- **两大根因（作者归因）**：
  - **观测与动作之间的模态鸿沟（Modality Gap）**：对近期预测式 VLA 的潜变量分布分析显示，观测预测与动作生成之间存在明显的分布分离（图 1(e)），削弱了预测表征对动作生成的"落地"能力，稀释了以动作为中心的学习焦点。
  - **联合训练导致的优化冲突（Optimization Conflicts）**：现有范式通常直接把预测损失加到动作损失上（`L = L_act + λL_pred`），导致训练动态不稳定、收敛缓慢；预测与动作目标的梯度相互竞争，会把优化方向拉离以动作为中心的目标，极端情况下甚至训练崩溃（图 1(f)）。
- **要解决的核心问题**：如何在**保持以动作为中心的优化**前提下，有效利用预测表征来增强动作生成。

## 2. 方法论：ATI-VLA

### 2.1 核心思想
提出 **Align-Then-Inject（先对齐、后注入）** 的两阶段框架：
- **第一步**：可操作表示对齐（Actionable Representation Alignment），用**共享码本**把预测观测与动作映射到统一离散潜空间；
- **第二步**：以动作为中心的自适应注入（Action-Centric Adaptive Injection），用轻量侧路径把对齐后的预测潜变量注入动作解码，且**只用动作损失优化**。

### 2.2 阶段一：基于共享码本的可操作表示对齐
- **模态专属编码**：用 `f_O(·)` 和 `f_A(·)` 分别编码当前观测 `O_t` 与动作 `A_t`。
- **共享码本量化**：引入共享码本 `C = {c_k}_{k=1}^K ⊂ R^d`，通过最近邻量化 `Quant(z) = c_{k*}`，`k* = argmin ||z - c_k||²`，将两模态映射到同一离散潜空间：`Z_{O_t} = Quant(f_O(O_t))`，`Z_{A_t} = Quant(f_A(A_t))`。
- **统一解码**：把当前观测与动作拼接为 `X_t = [O_t, A_t]`，先做自注意力捕捉模态内/间依赖，再以拼接的离散潜变量 `Z_t = [Z_{O_t}, Z_{A_t}]` 作键值做交叉注意力，得到预测感知、动作感知的隐表示 `H_{t+n}`。
- **双预测头**：`MLP_O` 与 `MLP_A` 分别输出未来观测 `Ô_{t+n}` 与未来动作 `Â_{t+n}`。
- **对齐目标**：`L_align = λ_O L_obs(Ô_{t+n}, O_{t+n}) + λ_A L_act(Â_{t+n}, A_{t+n})`，强制共享潜空间编码**时间一致、因果对齐**的语义。
- **关键设计要点**：采用对称的预测式设计（同时预测未来观测与未来动作），而非重建；训练完成后**冻结对齐模块**。
- **效果证据**：t-SNE 显示观测（主视角/腕部）与动作潜变量从初始的分散、模态分离，逐渐收敛为混合良好的共享结构；定量上跨模态相似度从 0.31 升至 0.83，CKNNA 从 0.2 升至 0.7。

### 2.3 阶段二：以动作为中心的自适应注入
- **设计依据**：理论分析（附录 D.2）与实验（表 6）表明，**逐层密集注入会过度约束解码**，损害控制精度与训练稳定性——早期层更需要粗粒度语义引导，后期层需要细粒度运动控制。因此采用**间隔注入**。
- **自适应侧路径**：
  - LLM 输入序列 `H_0 = [f_O(O_t), f_I(I), T_act]`，逐层前向 `H_l = LLMLayer_l(H_{l-1})`。
  - 预测潜变量在每次注入前通过 FFN 自适应更新：`Z_{O_t}^{(l)} = Z_{O_t}^{(l-1)} + FFN(Z_{O_t}^{(l-1)})`，使其匹配不同层的抽象层级，而非保持固定。
  - 仅在 `l mod s = 0` 时注入：提取动作查询 token 隐状态 `H_l^act`，以交叉注意力注入预测潜变量 `H_l^cross = CrossAttn(H_l^act, Z_{O_t}^{(l)}, Z_{O_t}^{(l)})`。
  - 残差更新：`H_l^act ← H_l^act + β_l · H_l^cross`，其中 `β_l` 为可学习标量，控制各层预测引导强度。
- **关键约束**：该阶段**仅用动作损失训练**，预测信息纯粹作为引导，不再引入预测目标，从根本上规避优化冲突。
- **算法流程**（Algorithm 1 概括）：Step 1 量化两模态 → 统一解码 → 计算对齐损失并更新、随后冻结；Step 2 逐层前向，每 s 层对动作 token 做一次侧路径注入，最终由动作头输出 n 步动作块并用动作损失优化。

## 6. 主要结论与发现

- **性能 SOTA**：
  - LIBERO 平均成功率 **97.9%**（Object 99.4%、Long 96.2%），排名第一，优于 OpenVLA-OFT（97.1%）等通用与预测式基线。
  - RoboTwin 2.0 平均成功率 **72.3%**，大幅超过 π0（60.0%）与 OpenVLA-OFT（58.8%），尤其在细粒度任务上优势明显。
  - 真实世界 Galaxea R1 Lite 上平均 **70%**（对比 DreamVLA 50%、F1 57%、OpenVLA-OFT 55%）；AgileX 平台 72%；OOD T恤折叠达 60%。
- **收敛更快**：训练成本最低（16.2h），收敛曲线显示比无对齐变体及先前基线收敛更快、最终性能更高。
- **对齐的有效性**：显式对齐显著提升跨模态相似度与 CKNNA；对齐后的潜变量注入远优于随机潜变量注入。
- **注入间隔的规律**：最佳注入频率 s ≈ 模型深度的 1/3~1/4，跨骨干（不同注意力与归一化机制）保持一致，调参负担小。
- **增益来源**：受控实验证明增益主要来自"对齐+自适应注入"的组合，而非额外监督、模型容量或训练预算；预测模态本身（图像 vs 世界知识）不是关键。
- **失败与冲突机制被量化**：无对齐变体失败集中于语义落地、位姿/控制和子目标过渡阶段；预测与动作损失的梯度余弦相似度为负（-0.23 ~ -0.29），而 ATI-VLA 从设计上规避了该冲突。

## 7. 优点

- **问题诊断有据**：不停留在"预测式 VLA 效果不好"的表象，而是用潜变量分布、梯度余弦相似度、失败模式统计等**多角度实证**定位到模态鸿沟与优化冲突两大根因。
- **设计针对性强、逻辑自洽**：Align（解决模态鸿沟）+ Inject（解决优化冲突）与两大根因一一对应，且 Stage 2 冻结对齐模块、只用动作损失，从机制上消除冲突，而非事后补救。
- **共享码本设计巧妙**：用对称预测式设计（同时预测未来观测与动作）而非重建，使观测潜变量天然携带控制相关语义，可直接复用为动作引导信号。
- **注入机制务实**：自适应 FFN 变换 + 间隔注入 + 可学习 β_l，兼顾引导强度与解码自主性；且注入间隔规律跨骨干稳定，实用性强。
- **效率与性能兼得**：仅增加 0.7% FLOPs、训练时间反而减少 46.4%，推理延迟几乎不变，工程价值高。
- **实验严谨**：同骨干受控消融、基线同条件复现、多种子统计、OOD 泛化验证、理论分析（Lipschitz 风险上界、局部 Jacobian 扰动累积）与实证相互印证。
- **真实世界验证扎实**：两个平台、长时序任务、含 OOD 变体，且与多个强基线在同设置下对比。

## 8. 不足与局限

- **数据与场景覆盖有限（作者自述）**：真实世界实验主要依赖**任务专属的遥操作演示**（每任务 50 条），未充分覆盖开放世界中的物体、场景、本体形态与交互模式多样性；泛化结论需谨慎外推。
- **骨干与框架依赖**：以 OpenVLA-7B + OpenVLA-OFT 为基座，未在更大规模或异构机器人数据集上验证；共享码本的规模 K、码本学习策略等超参未在正文充分展开。
