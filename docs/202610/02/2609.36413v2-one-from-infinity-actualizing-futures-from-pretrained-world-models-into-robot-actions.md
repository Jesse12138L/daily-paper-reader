## 摘要
预训练的视频世界模型可为同一场景设想出许多合理的未来，但机器人必须实现与任务条件相符的那一个。为将世界模型转化为可执行的机器人策略，现有方法利用大规模机器人数据和计算资源微调沉重的世界模型主干。我们挑战这一现状，认为昂贵的部分已在世界模型预训练中支付，因为视频世界模型的表示空间已经铺陈出多样化的潜在未来。在这种情况下，剩下的就是选择能够完成任务的未来，并读出实现该未来的动作。我们将此任务形式化为实际化，即在冻结世界模型提供的先验之上，学习任务条件下的选择与实现。这可以由一个微小的实际化器模型解决。我们实现了 RoboActualizer，其参数量少至 60M，构建在冻结的世界模型编码器之上。该实际化器由两个轻量级 DiT 专家组成，通过流匹配联合预测未来潜变量和动作。该模型可以完全在单个峰值内存为 32 GB 的 GPU 上训练。与现有 WAM 和 VLA 相比，可训练参数最多少 100 倍，RoboActualizer 在仿真基准上取得了优异性能，包括 LIBERO、LIBERO-Plus、RoboTwin 2.0，以及两个真实世界平台上的五项任务，并具有 39 ms 的低延迟，可实现实时控制。

## Abstract
A pretrained video world model admits many plausible futures for a scene, but a robot must realize the exact task-conditioned one. To turn world models into executable robot policies, existing methods fine-tune the heavy world model backbone using large-scale robot data and computational resources. Challenging this status quo, we argue that the expensive part has already been paid in the world model pretraining since the representation space of a video world model lays out the diverse potential futures. In this case, what remains is to select the future that accomplishes the task and to read out the actions that realize it. We formalize this task as actualization, which learns a task-conditioned selection and realization on top of a prior supplied by a frozen world model. This can be solved by a tiny actualizer model. We implement RoboActualizer with as few as 60M parameters on top of a frozen world model encoder. The actualizer is composed of two lightweight DiT experts that jointly predict future latents and actions by flow matching. The model can be trained entirely on a single GPU with 32 GB peak memory. With up to 100x fewer trainable parameters than existing WAMs and VLAs, RoboActualizer reaches great performance on simulation benchmarks including LIBERO, LIBERO-Plus, RoboTwin 2.0 and five tasks on two real-world platforms, with a low latency of 39 ms that allows real-time control.

## 1. 核心问题与整体含义

- **研究动机**：预训练视频世界模型能从同一场景中“想象”出多种合理未来，但机器人最终必须完成一个由任务指令确定的特定未来，并输出精确动作。
- **现有路线的问题**：
  - 基于规划的方法（如 MPC）保持世界模型冻结，但在测试时需要大量 imagined rollouts，推理成本高、控制频率受限，目标常是目标图像或手工代价。
  - 世界-动作模型（WAM）或 VLA 方法通常微调庞大的世界模型主干，需要大规模机器人数据和大量算力。
- **核心主张**：昂贵的“世界动态建模”已经在视频世界模型预训练中完成；表示空间已经铺陈出多样潜在未来。下游真正需要学的只是：  
  1. **选择**哪个未来对应任务指令；  
  2. **实现**该未来的动作。
- **整体含义**：作者将这一任务形式化为“actualization（实际化）”，并在冻结世界模型先验上训练极小的实际化器。这样可把机器人策略学习从“重新建模世界”降级为“任务条件选择与动作读出”，大幅降低训练和推理成本。

## 2. 方法论

- **核心思想**：
  - 使用冻结的视频世界模型提供场景未来先验，不更新其参数。
  - 用任务指令从多种可能未来中选出任务条件未来，并读出实现动作。
  - 世界模型负责“可能发生什么”，小模型负责“哪个未来发生、如何实现”。

- **形式化分解**：
  - 冻结世界模型编码短观察历史，得到潜变量 \(z_t = g_\phi(x_{t-\Delta:t})\)，其中已包含运动与未来动态先验。
  - 未来潜变量 \(z^+_{t:t+H}\) 表示未来 H 步。
  - 作者用贝叶斯分解说明实际化：
    - 先验 \(p(z^+_{t:t+H}|z_t)\) 由冻结世界模型提供；
    - 选择项 \(p(\ell|z^+_{t:t+H}, z_t)/p(\ell|z_t)\) 需要学习；
    - 实现项 \(p(a_{t:t+H}|z^+_{t:t+H}, z_t,\ell)\) 需要学习。
  - 训练目标为最大似然：在机器人演示上拟合任务条件下的未来潜变量与动作联合分布，同时保持世界模型编码器冻结。

- **世界模型实例**：
  - 采用冻结的 V-JEPA 2.1 视频编码器（ViT-L/16，约 300M）。
  - 输入为短 clip，而不是单帧；输出 latent 已包含跨帧运动与未来延续线索。
  - 未来目标在若干时间步上离散采样，例如 \(t+4, t+8, t+12, t+16\)。
  - 因编码器冻结，所有 latent 可离线缓存，训练时无需反复前向世界模型。

- **RoboActualizer 架构**：
  - 由两个轻量 DiT 专家组成，采用 Mixture-of-Transformers（MoT）：
    - **latent expert**：预测任务条件未来潜变量；
    - **action expert**：预测实现该未来的动作 chunk。
  - 两个专家权重独立，通过共享 self-attention 交互；各自有 cross-attention 和 FFN。
  - 条件输入包括冻结 UMT5 文本编码的任务指令，以及本体状态。
  - 使用流匹配训练，并采用 clean-sample / x-prediction 参数化，让网络预测干净 token，而不是 v-prediction。
  - 损失在速度空间计算：动作损失与潜变量损失加权求和。
  - 推理时：编码器每个观测只前向一次，只有小 actualizer 进行多次去噪，生成动作 chunk。

- **为何小模型足够**：
  - 对 V-JEPA 2.1 latent 做 PCA 分析，DiT-S 宽度 \(d_{model}=384\) 时可保留约 93.8% 方差。
  - 说明世界模型表示空间本身低维，小 actualizer 足以选择任务条件分量并读出动作。
  - x-prediction 比 v-prediction 更适合这种低秩结构。

## 3. 实验设计

- **仿真 benchmark**：
  - **LIBERO**：四个任务套件 Spatial、Object、Goal、Long，共 10 任务/套件，每任务 50 trials，约 2000 episodes/checkpoint。
  - **LIBERO-Plus**：LIBERO 的扰动版本，包含 Camera、Robot、Language、Light、Background、Noise、Layout 七个扰动维度，共 10,030 个扰动任务实例。
  - **RoboTwin 2.0**：大规模双臂操作 benchmark，50 个任务；每任务随机采样 50 条演示，并在 Clean 与 Random 设置下各 25 episodes/task，共 2500 评估 episodes。

- **真实机器人平台**：
  - **FANUC CRX-10iA 单臂**：两个任务，Mug Hanging 与 Cooking Sequence。
  - **Unitree G1 人形双臂**：三个任务，Box Packing、Cup Insertion、Plate Handover。
  - 真实任务收集约 170 条演示/人形任务，约 100 条/单臂任务；评估分别为 30 rollouts 和 20 rollouts。

- **对比方法**：
  - 仿真中对比 OpenVLA、π0、π0.5、UniVLA、Motus、WorldVLA、Fast-WAM、DC-WAM、LingBot-VA 等 VLA/WAM 方法。
  - 真实实验中对比 π0.5（VLA 基线）和 Fast-WAM（WAM 基线）。

- **评估协议**：
  - 闭环节评估，无测试时调参、无动作 ensemble、无测试时增强。
  - LIBERO 使用相同初始状态文件和 seed 42。
  - LIBERO-Plus 直接迁移 LIBERO 训练策略，无额外微调。
  - 推理时未来图像生成关闭，只预测动作；部分设置中缓存中间特征以加速去噪。
