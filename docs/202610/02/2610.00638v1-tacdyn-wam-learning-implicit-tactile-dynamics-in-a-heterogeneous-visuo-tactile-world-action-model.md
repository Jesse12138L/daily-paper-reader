## 摘要
世界动作模型通过以预测未来为条件来改进机器人操作，然而现有触觉变体大多沿用视频生成流程，通过迭代去噪重建未来触觉观测。这种预测在部署漂移下可能变得不可靠：接触位置或力的微小变化可能显著改变触觉像素，即使底层接触演化仍可预测。我们提出 TacDyn-WAM，一种异构视触觉世界动作模型，其预测隐式触觉动力学，而非重建未来触觉观测。它学习 TacRep，一个动力学感知的触觉目标空间，该空间通过在触觉片段上进行掩码时空预测来训练，并通过关系结构蒸馏进行正则化。一个视觉专家和一个隐式触觉动力学专家在各自独立的目标空间中预测未来的视觉和触觉表征，同时通过联合注意力进行交互；触觉专家在单次前向传播中预测多个时间范围上的未来表征及其变化，而只读触觉记忆提供当前触觉状态。在 UniVTAC 上，TacDyn-WAM 仅使用所提供的示范就达到 81.5% 的平均成功率，达到最先进水平，并与在大规模视触觉轨迹上预训练的模型相比仍具竞争力。消融实验证实了两个触觉路径以及 TacRep 相较于像素重建和静态替代方案的益处。在五个真实机器人任务上，TacDyn-WAM 达到 71.0% 的平均成功率，适度规模的预训练将其提升至 85.0%，进一步验证了我们的方法。

## Abstract
World action models improve robotic manipulation by conditioning actions on predicted futures, yet existing tactile variants largely inherit video-generation pipelines that reconstruct future tactile observations through iterative denoising. Such prediction can become unreliable under deployment drift: small changes in contact position or force may substantially alter tactile pixels even when the underlying contact evolution remains predictable. We introduce TacDyn-WAM, a heterogeneous visuo-tactile world action model that predicts implicit tactile dynamics rather than reconstructing future tactile observations. It learns TacRep, a dynamics-aware tactile target space trained through masked spatio-temporal prediction on tactile clips and regularized by relational structure distillation. A visual expert and an Implicit Tactile Dynamics Expert predict future visual and tactile representations in separate target spaces while interacting through joint attention; the tactile expert predicts future representations and their changes at multiple horizons in a single forward pass, and a read-only tactile memory supplies the current tactile state. On UniVTAC, TacDyn-WAM achieves an average success rate of 81.5% using only the provided demonstrations, reaching state-of-the-art-level performance and remaining competitive with models pretrained on large-scale visuo-tactile trajectories. Ablations confirm the benefits of both tactile pathways and TacRep over pixel-reconstruction and static alternatives. On five real-robot tasks, TacDyn-WAM reaches 71.0% average success, and modest-scale pretraining raises it to 85.0%, further validating our method.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAM）通过"预测未来"来条件化动作生成，已被证明能提升机器人操作性能。近年来该思路被扩展到触觉领域，形成触觉世界动作模型（tactile WAM）。
- **核心问题**：现有触觉 WAM 大多**直接沿用视频生成范式**——用同一个 VAE 编码相机与触觉帧，用视频骨干网络迭代去噪生成未来触觉 latent。作者认为这一设计存在两个根本缺陷：
  - **推理慢**：迭代去噪成本高，且随 episode 历史累积而增长；
  - **目标空间错配**：像素重建与触觉物理意义不匹配。
- **关键观察（部署漂移问题）**：专家示范只覆盖"接近正确接触"时的触觉图像；闭环执行中的误差会让策略偏离示范分布。此时相机视角几乎不变，但接触位置或力的微小变化会**剧烈改变触觉像素**（如附录 B 所示的 Pull-out Key、Put Bottle 案例：压痕偏心、旋转角度不同、标记阵列被拉伸撕裂）。然而，**接触演化的物理趋势（压痕加深、滑动、旋转）往往仍然可预测**。
- **核心主张**：应转向**隐式触觉动力学建模**——在动力学感知的表征空间中预测接触演化，而非重建未来触觉观测。
- **对既有 latent 方案的批判**：N0-VTLA 在冻结 DINOv2 特征空间中预测单一时间范围的"净变化"，但 DINOv2 训练于静态自然图像，未针对帧间触觉演化优化；且单一净变化会掩盖"挤压后回弹到相似终态"这类中间事件。
- **整体含义**：论文将触觉世界模型的设计问题从"如何更准地重建触觉像素"重新定位为"哪些隐式动力学对选择动作有用"，并给出一个可部署、低成本、多时间范围的方案。

## 2. 方法论

### 2.1 基础模型与问题设定
- 基于 **InternVLA-A1（3B）** 的 mixture-of-transformers 架构，三专家经块级因果联合注意力耦合：
  - **Understanding Expert**：Qwen3-VL-2B，编码当前 RGB 观测 $I_t$ 与语言指令 $\ell$ 为前缀块 $U$；
  - **Visual Generation Expert**：接收由冻结 Cosmos tokenizer 编码的视觉历史块 $V$，预测未来视觉 latent $z^v_{t+15}$；
  - **Action Expert**：接收机器人状态 $s_t$ 与加噪动作块 $A$，用**流匹配**（flow matching）去噪出长度 $H=50$ 的动作块，损失为 $L_{act}=\mathbb{E}\|\ v_\theta(a^\sigma_t,\sigma\mid U,V,s_t)-(\epsilon-a_t)\|_2^2$。
- 扩展设定：加入 $K$ 个视触觉传感器（每夹爪两个）。给定 $C_t=(U,V,\{x^k_{t-3:t}\}_{k=1}^K,s_t)$，模型同时预测未来视觉 latent、未来触觉表征及其变化 $\{\hat z^k_{t+h},\Delta\hat z^k_{t+h}\}$（$h\in\mathcal{H}=\{5,15,25\}$）与动作块。**未来观测只作训练目标，预测只依赖已观测历史与当前状态。**

### 2.2 TacRep：动力学感知触觉表征空间（Stage 1）
- **动机**：像素/VAE latent 把预测绑定在不稳定的像素模式上；需要一个"捕捉接触演化、容忍像素级偏差"的空间。
- **触觉动力学预测（TDP）**：编码器 $E_\theta$ 由蒸馏版 V-JEPA 2.1 ViT-B 初始化；四帧片段按 tubelet=2 分组为 $2\times24\times24$ 的 patch token 网格。EMA 目标编码器 $\bar E$，遮蔽时空块 $\mathcal{M}$（每个遮蔽块**跨越全部四帧**，迫使编码器理解压痕的运动而非静态凝胶纹理），轻量预测器 $P_\phi$ 恢复被遮蔽 token 的目标特征：
  $$L_{TDP}=\mathbb{E}_{\mathcal{M}}\big\|P_\phi(E_\theta(X\setminus\mathcal{M}),\mathcal{M})-sg[\bar E(X)]\big\|_1$$
  采用 V-JEPA 2.1 的两种多块遮蔽视图（小块多、大块少），并对可见 token 加同样损失（权重 0.5）。
- **关系结构蒸馏（RSD）**：TDP 不显式保局部空间关系。用冻结 **DINOv2 ViT-B** 作结构教师，但对齐的是**局部余弦关系矩阵**而非特征值本身（避免把触觉特征拉向静态图像表征、削弱动力学）：
  $$L_{RSD}=\frac{1}{|\mathcal{N}|}\sum_{(i,j)\in\mathcal{N}}\text{SmoothL1}\big(z_i^\top z_j-d_i^\top d_j\big)$$
  其中 $\mathcal{N}$ 为 7×7 网格上相距不超过两行两列的 patch 对。总目标 $L_{TDP}+\lambda_{RSD}L_{RSD}$（$\lambda_{RSD}=0.1$，只作正则）。训练后丢弃预测器与教师，保留 $\bar E$ 作为冻结的 TacRep Encoder。

### 2.3 隐式触觉动力学专家（ITDE，Stage 2）
- **输入**：冻结 TacRep Encoder 将每传感器四帧片段转为两张时序特征图，平均池化为 4×4 并投影，得 **32 个 TacRep Context Token/传感器**；每个预测时间范围附加 **16 个可学习 Future Token Query**（4×4 空间网格）。加入空间、模态与连续时间嵌入；机器人状态 $s_t$ 经零初始化条件块注入每一层 Transformer。
- **Dynamics Predictor**：每传感器 80 个 token 过 28 层、隐藏维 1024 的 Transformer（约 **0.4B**，与视觉/动作专家层几何一致以共享注意力，但从头初始化）。32 个 context token 与 48 个 future token 的输出构成触觉块 $T$。
- **Future 与 Delta 双读出**：16 个紧凑 token 在 0.4B 预测器**之外**扩展为 7×7 预测（各 49 个可学习 query 交叉注意力 + 线性头）。目标为冻结 TacRep Encoder 对单帧输出池化归一化后的 $z^k_{t+h}$ 与 $\Delta z^k_{t+h}=z^k_{t+h}-z^k_t$。**只预测未来易退化为记忆典型终态，只预测 delta 则缺乏起点信息，二者同时预测才迫使模型建模"当前状态如何演化到未来"。**
- **Patch 自适应损失重加权**：多数 patch 在预测范围内几乎不变，无权平均会被静态区域主导。按真值变化幅度加权 $w_{h,p}\propto 1+\alpha\|\Delta z_{t+h,p}\|_2$（$\alpha=2$，均值归一化为 1，上限截断为 5），聚焦接触扩张、收缩、滑动的区域。
- **单次前向、无迭代去噪**；读出仅在训练用，部署时动作专家直接读触觉块 $T$。

### 2.4 触觉理解记忆（Tactile Understanding Memory）
- 用冻结 **AnyTouch2** 编码器（大规模多传感器语料预训练）编码同一四帧片段；其输出每传感器数百 token，经 **Compact Attentive Pooler** 压成 **10 个 token**（1 个来自 class embedding 的全局 token + 最新时序特征图 3×3 池化的 9 个局部 token），再经两层 **Compact Tactile Q-Former** 跨传感器自注意力融合、并以交叉注意力条件化于前缀 $U$。
- **只读集成**：记忆 token 不进入任何专家的残差流，每层联合注意力用轻量投影将其映射为额外的 **keys 和 values**；因不贡献 query 故从不被更新，占用前缀之后的固定位置 ID，仅增加约 **1% 参数量**，被遮蔽时不影响原块。
- 分工逻辑：AnyTouch2 的重建式预训练保留当前接触的细粒度信息，用于"理解"；TacRep 空间专门用于"预测"，不做像素重建。

### 2.5 异构联合注意力与四阶段训练
- **联合注意力**：每层中前缀、视觉、触觉、动作块各自计算 Q/K/V 后拼接，在块级因果掩码下处理。最终阶段：前缀只关注自身；视觉与触觉块关注前缀、记忆及两个世界模型块；动作块关注全部上下文并对自身因果。
- **四阶段渐进训练**（避免随机初始化的触觉模块破坏预训练专家）：
  1. **Stage 1：TacRep 训练**（产出冻结编码器）；
  2. **Stage 2：触觉世界接地**（只训 ITDE 与读出，其他专家冻结；ITDE 可读前缀与视觉块，但尚不可被它们读取）；
  3. **Stage 3：触觉—动作对齐**（训触觉记忆与动作专家，动作块可读两条触觉通路）；
  4. **Stage 4：联合训练**，总损失 $L=L_{act}+\lambda_{vis}L_{vis}+\lambda_{tac}L_{tac}$（$\lambda_{vis}=0.01$，$\lambda_{tac}=500$，按梯度量级匹配设定）。保留 $L_{tac}$ 以防触觉块退化为"动作捷径"。
- 超参细节：bfloat16、AdamW、线性 warmup + cosine 衰减、按参数组梯度裁剪 norm=1.0；Stage 2 用 Smooth L1（$\beta=1$）；Stage 1 编码器逐步解冻（预测器与最后 4 块先训，20% 步数后以更低学习率解冻 4–7 块，前 4 块与 patch embedding 始终冻结），EMA 动量 0.999→0.9999。

## 3. 实验设计

### 数据集 / 场景
- **仿真：UniVTAC**（基于 TacEx 与 Isaac Sim）——接触丰富操作的挑战性 benchmark。单臂 Franka + 平行夹爪 + 每指一个 GelSight Mini。八个任务跨三类：
  - 姿态推理：Lift Bottle、Lift Can、Put Bottle；
  - 形状感知：Grasp Classify；
  - 精确接触交互：Insert Hole、Insert Tube、Insert HDMI、Pull-out Key。
- **真机：Franka Research 3** + 平行夹爪 + 每指一个 Xense 视触觉传感器 + 腕部相机与第三人称相机。五个接触丰富任务：Stack Cups、Remove Plug、Insert Plug、Unscrew Cup Lid、Wipe Whiteboard，每任务 60 条遥操作示范。
- **预训练数据：OmniViTac**（21,879 条轨迹、86 任务），作者选取 **6,000 条**子集（装配 2,500、抓取 2,000、擦拭 1,000、调整 500，排除切割与剥离）+ 自采 300 条真机示范。

### 对比方法
- **视觉-only 策略**：π0.5、StarVLA-α、InternVLA-A1（基座模型，作者按相同协议重测）、Xiaomi-Robotics-0、GigaWorld-Policy、LingBot-VA、Fast-WAM。
- **视触觉策略**：ACT+UniVTAC、VITaL、RDP、TacForcing、Tactile-WAM、FTP-1。
- **大规模视触觉轨迹预训练策略**：N0-VTLA（基于 π0.5，冻结 DINOv2 + 单范围净变化预测）、N0-TWAM（7.2B 视频扩散 WAM，共享 VAE latent 迭代去噪；含 20% 数据变体）。二者在 **30,000+ 小时、6 种本体、450 任务**上预训练。
- **真机对比**：LingBot-VA、InternVLA-A1、FTP-1（约 3,000 小时触觉数据预训练），均在相同示范上按任务微调。

### 评估协议
- 仿真：每任务 100 次 rollout，随机初始构型，用官方 UniVTAC 成功判据；默认执行完整 50 步 chunk，Insert Hole 与 Lift Can 执行前 32 步（接触更稳定）。
- 真机：每任务 20 次试验，随机位姿，按附录 G 判据（如 Wipe Whiteboard 要求 ≥95% 字迹被清除）。
- 延迟：同一 A100、batch size 1、同步推理，30 次运行取中位数，仅计 GPU 从输入张量到动作块的计算。

## 6. 局限与潜在风险

- **多时间范围的设计仍属"手动先验"**：$\mathcal{H}=\{5,15,25\}$ 与动作块长度 $H=50$ 的搭配未做系统性扫描。为何恰好是这三个尺度、是否随任务接触时长变化而需要自适应调整，论文未给出答案。
- **损失权重的强不对称性**：$\lambda_{tac}=500$ 与 $\lambda_{vis}=0.01$ 相差四个数量级，作者说明是"按梯度量级匹配"，但这意味着触觉目标在总损失中占据主导。虽然有助于防止触觉块退化为动作捷径，但也可能压缩视觉世界模型的表征质量；论文未报告单独监控 $L_{vis}$ 收敛情况的分析。
- **ITDE 的参数量代价**：0.4B 的动力学预测器约占总参数 3.6B 的 11%，加上 28 层的结构与视觉/动作专家同几何，其收益是否必须由如此大的模块承担，缺少"缩小 ITDE"的对照。
- **记忆模块的只读设计**：AnyTouch2 编码 + Q-Former 压成 10 token 的做法参数高效，但由于记忆 token 从不被更新、且仅作为 keys/values 注入，其信息流方向是单向的。若触觉理解与动力学预测之间存在相互修正的需求（例如预测失败后回溯修正当前接触估计），该架构无法支持。
- **部署漂移的核心主张缺少直接量化**：论文用附录 B 的定性案例（Pull-out Key、Put Bottle）论证像素空间对接触扰动的敏感性，但没有给出"闭环执行中触觉观测偏离示范分布"的统计度量（如分布距离随时间的增长曲线），也没有对比 TacRep 空间与像素空间在同一扰动下的稳定性指标。这是全文最关键的动机，却主要以定性证据支撑。
- **真机评测规模**：5 任务 × 20 trials，且仅对比 3 个基线（其中 FTP-1 的预训练数据量约 3,000 小时，远小于 N0 系列的 30,000+ 小时），跨方法的预训练预算并不对齐，真机结论的稳健性弱于仿真主表。
- **延迟对比的范围**：Table 4 只与 LingBot-VA 对比，未与同样强调效率的 Fast-WAM、GigaWorld-Policy 等一并测量；且仅报告 GPU 计算时间，不含传感器采集、通信与运动执行开销，端到端控制频率未披露。

## 7. 相对既有工作的定位

论文的贡献可归为三点递进关系：

1. **问题重构**：把触觉世界模型的目标从"重建未来触觉观测"改为"预测对动作选择有用的隐式触觉动力学"，并明确指出像素/共享 VAE latent 空间在闭环漂移下的失效机制。
2. **表征层面的解法**：TacRep 用"遮蔽块跨全部四帧"的 TDP 强制编码运动而非静态纹理，再用关系结构蒸馏（对齐局部余弦关系而非特征值）引入空间结构而不牺牲动力学——这是一个可复用的通用触觉表征配方，不绑定具体策略。
3. **架构与训练层面的解法**：ITDE 以单次前向替代迭代去噪，以 Future + Delta 双读出避免"记忆典型终态"与"缺乏起点"两种退化，以 patch 自适应重加权聚焦变化区域；四阶段渐进训练解决随机初始化触觉模块污染预训练专家的问题；只读触觉记忆以约 1% 参数代价引入重建式理解的互补信息。

与 N0-VTLA（冻结 DINOv2 + 单范围净变化）和 N0-TWAM（7.2B 视频扩散 WAM、迭代去噪）的对比，构成"表征是否为动力学优化"与"是否必须迭代生成"两条正交的批判线，这也是论文最清晰的差异化定位。

## 8. 结论与启示

- **核心结论**：在接触丰富操作中，触觉世界模型的价值不在于生成逼真的未来触觉图像，而在于提供一个容忍像素级偏差、但保留接触演化趋势的预测目标；配合单次前向的紧凑预测器与只读的多传感器理解记忆，可在保持甚至超过大参数视频扩散 WAM 性能的同时显著降低推理成本。
- **方法学启示**：
  - 自监督目标的设计（掩码跨越全时序窗口）本身就是一种"任务先验注入"，比事后加正则更有效；
  - 同时预测"未来状态"与"相对变化"是一种低成本的防退化技巧，可迁移到其他模态的世界模型；
  - 渐进式训练阶段划分 + 块级因果注意力的模块可见性控制，是"在预训练基座上外挂新模态"的通用工程范式；
  - 只读 keys/values 注入是扩展现有大模型上下文的一种高性价比手段。
- **后续可探索方向**：自适应时间范围选择、触觉记忆的双向更新、跨传感器与跨本体的表征迁移、以及把"漂移检测"本身作为触觉世界模型的下游信号用于在线纠正。
