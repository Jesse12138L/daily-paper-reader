## 摘要
世界-动作模型联合学习机器人策略并预测未来观测，使表征空间成为控制与预测之间的接口。我们通过受控比较研究该空间的设计，发现仅凭重建保真度或预训练感知特征都不足以确保有效的策略学习。这些发现促使我们提出 ReWAM，一种以表征为中心、基于预训练 DINO 特征构建的世界-动作模型。特征校准（Feature Calibration）与时序表征瓶颈（Temporal Representation Bottleneck）将这些特征组织为适合动力学建模的紧凑世界状态。动作锚定的表征塑造（Action-Grounded Representation Shaping）仅将动作损失梯度路由至瓶颈，从而使策略塑造表征所编码的内容，而世界模型学习表征如何演化。无需生成式视频预训练，ReWAM 在 RoboTwin 2.0 上达到 93.6% 的成功率。在 RoboDojo 上，使用约 600 小时的具身预训练数据，它取得了 12.29 的平均得分和 8.28% 的成功率。

## Abstract
World-action models jointly learn robot policies and predict future observations, making the representation space an interface between control and prediction. We study the design of this space through controlled comparisons, finding that neither reconstruction fidelity nor pre-trained perceptual features alone ensure effective policy learning. These findings motivate ReWAM, a representation-centric world-action model built on pre-trained DINO features. Feature Calibration and a Temporal Representation Bottleneck organize these features into compact world states suited to dynamics modeling. Action-Grounded Representation Shaping routes only action-loss gradients to the bottleneck, thereby letting the policy shape what the representation encodes while the world model learns how it evolves. Without generative video pre-training, ReWAM achieves 93.6% success on RoboTwin 2.0. On RoboDojo, it achieves an average score of 12.29 and a success rate of 8.28% using approximately 600 hours of embodied pre-training data.

- **关键发现（受控比较）**：

## 2. 方法论：ReWAM

### 2.1 核心思想

以**冻结 DINOv3-L 特征**为基础，通过三层设计构建以表征为中心的世界-动作模型：特征校准 → 时序表征瓶颈 → 动作锚定表征塑造，全程**无需生成式视频预训练**。

### 2.2 关键技术细节

- **整体架构**：
  - 编码非重叠观测对：`z_j = E_φ(o_{j-1}, o_j)`，其中 `E_φ` = 冻结 DINOv3-L + 特征校准 + 可训练 TRB。
  - 采用 Mixture-of-Transformers（MoT）：世界分支 `W_θ`（30 层，宽 2048）与动作分支 `A_θ`（30 层，宽 1024），总参数约 **3.58B**；两组 token 均关注当前状态世界特征，但彼此注意力被阻断。
  - 条件模型因式分解：`p_θ(z_{1:H}, a_{1:H} | z_0, c) = p_θ(z_{1:H} | z_0, c) · p_θ(a_{1:H} | z_0, c)`。
  - 两分支均用 **flow matching** 训练；世界分支用因果时序注意力与独立噪声水平；推理时世界分支只处理 `z_0` 一次用于条件化，**不生成未来状态**（沿用 Fast-WAM 思路）。

- **特征校准（Feature Calibration）**：
  - **多层聚合**：取 DINOv3-L 第 {12,14,16,18,20,22,24} 块特征，做非仿射 LayerNorm 并去除特殊 token，对所选层求平均后加上最后一层（第 24 块）的空间均值，保留 patch 网格与特征宽度（d=1024）。
  - **归一化**：固定统计量（冻结特征基线）或 TRB 输出的运行时统计量（ReWAM）。
  - **表征感知噪声调度**：采样 `u~U(0,1)`，令 `τ = αu / (1 + (α−1)u)`，`α = √(D/D_base)`，`D_base = 4096`；未来状态各自独立采样 flow time，当前状态保持干净。该位移对大目标偏向更噪的输入。

- **时序表征瓶颈（TRB）**：
  - 每相机将非重叠 **2×2×2 时空块**展平为 8d 维 token，跨视角拼接后经单层 8 头自注意力（2D RoPE，base 10000，坐标缩放 16，含相机特定 query/key 偏置）与线性投影，得到 **128 维**紧凑世界状态。
  - **因果运行时归一化**：用前面批次累积的逐通道均值/方差归一化 TRB 输出，并以 EMA 更新，推理时统计量固定。

- **动作锚定表征塑造（AGRS）**：
  - 损失：`L_world`（预测未来状态速度）与 `L_action`（预测动作块速度），均采用线性 flow matching，`y_τ = (1−τ)y + τϵ`，目标速度 `ϵ − y`。
  - **非对称梯度路由**：`∇_θL = ∇_θL_world + ∇_θL_action`，而 `∇_φL = (∂z_0/∂φ)ᵀ ∂L_action/∂z_0`；即**只有动作损失梯度经当前状态 z_0 回传至 TRB**，世界损失梯度在当前与未来表征处均被 stop-gradient 截断。世界分支同时从两个目标学习，但表征编码器只由动作目标塑造。

尽管其 RGB 重建 SSIM 仅为 0.70（Video-VAE 为 0.91）。这说明以像素重建为目标优化的隐空间，其"信息丰富度"与"控制可用性"之间存在系统性错配——高保真重建保留的纹理、光照、相机噪声等细节，对策略学习而言可能是噪声而非信号。

- **预训练感知特征不能直接用作动力学接口**：DINO 特征逐帧独立，不显式编码帧间时序变化；其统计分布与 flow matching 的噪声注入尺度不匹配。因此论文主张"特征校准"是必要前置步骤，而非可选技巧。消融显示多层聚合（第 {12,…,24} 块）贡献最大（+6.87），其次是归一化（+3.92）与表征感知噪声调度（+1.41）。
- **时序表征瓶颈（TRB）是控制友好的中间抽象层**：将 2×2×2 时空块压缩至 128 维世界状态，既降低世界分支的建模负担，又通过因果运行时归一化保持训练/推理分布一致；TRB 时序组织相较逐帧 token 带来 +2.89 的提升，且 128 维紧凑维度在表 6 中优于更大维度，暗示"信息瓶颈"本身具有正则化作用。
- **动作锚定表征塑造（AGRS）是性能关键**：非对称梯度路由让表征编码器只接收动作损失梯度，使表征空间被"塑造为对控制有用"，而世界分支仍可从未来状态预测目标中学习动力学。AGRS 在 clean/random 上分别贡献 +3.94/+3.18，是单项消融中除多层聚合外收益最大的设计。

## 8. 启示与后续方向

- **表征设计应被视为一等公民**：论文的核心方法论启示是"策略塑造表征所编码的内容，世界模型学习该表征如何演化"。这一分工原则可迁移至其他具身模型——与其在预训练视频生成器的隐空间上做适配，不如先问"控制需要什么样的表征"，再据此设计编码器与梯度路由。
- **重建目标与控制的解耦值得系统化研究**：SSIM 探针提供的反例提示，视觉生成社区常用的重建/感知指标与下游控制性能可能长期存在偏差，建立面向控制的表征评测协议（论文附录 E 是一次尝试）比单点指标更有价值。
- **可探索方向**：(1) 将 AGRS 的梯度路由思想推广到其他模态（触觉、力觉、语言）；(2) 把 TRB 的时空块与因果归一化用于在线自适应，考察非平稳环境下的鲁棒性；(3) 引入轻量世界分支的推理期使用（如仅在不确定时展开一步预测），检验预测成分的真实边际价值；(4) 在更大规模、更异构的具身数据上验证"600 小时即可对标万小时"这一结论的可扩展性。
- **对实践的取舍建议**：若算力受限、无法承担视频生成预训练，ReWAM 提供了一条可行路径；但若已有高质量视频生成预训练模型与充足数据，其相对优势是否仍成立，论文尚未给出直接答案，这构成一个明确的开放问题。
