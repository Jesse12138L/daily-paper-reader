## 摘要
机器人策略正越来越多地融入语义推理与未来世界预测，但将这些能力结合起来并不能保证局部预测和动作始终与任务进展保持一致。我们提出 CogWAM，一种认知引导的世界-动作模型，它通过持久化的 Semantic State 在任务推理与世界-动作学习之间建立显式的语义接口；该状态存储已完成的任务事件和当前活跃子任务。CogWAM 仅在观测表明发生语义转换时更新该状态，从而使任务级上下文能够跨多个动作块持续存在。为将语义上下文与物理预测和控制衔接起来，CogWAM 采用以进展为条件的 WORLD 和 ACTION 查询，选择性地提取与任务相关的信息，用于未来世界预测和动作生成。在训练期间，Semantic State 为两个分支提供共享的任务进展上下文；而在推理时，移除未来预测分支，直接根据观测和所维护的状态生成动作。我们进一步引入语义训练策略，以改进转换学习和闭环条件化。无需额外的机器人动作预训练，CogWAM 在 RoboDojo 上取得 15.56 / 11.70 % 的 Score/SR，在 BiCoord 上取得当前最优性能；同时真实世界实验展示了闭环双臂操作，其 Semantic State 重新生成次数比逐步更新少 16.4 次。

## Abstract
Robot policies increasingly incorporate semantic reasoning and future-world prediction, yet combining these capabilities does not guarantee that local predictions and actions remain aligned with task progress. We introduce CogWAM, a cognition-guided world-action model that establishes an explicit semantic interface between task reasoning and world-action learning through a persistent Semantic State, which stores completed task events and the active subtask. CogWAM updates this state only when observations indicate semantic transitions, allowing task-level context to persist across multiple action chunks. To bridge semantic context with physical prediction and control, CogWAM employs progress-conditioned WORLD and ACTION queries that selectively extract task-relevant information for future-world prediction and action generation. During training, the Semantic State provides shared task-progress context for both branches, while inference removes the future-prediction branch and directly generates actions from observations and the maintained state. We further introduce semantic training strategies to improve transition learning and closed-loop conditioning. Without additional robot-action pretraining, CogWAM achieves 15.56 / 11.70 % Score/SR on RoboDojo and state-of-the-art performance on BiCoord, while real-world experiments demonstrate closed-loop dual-arm manipulation with 16.4 fewer Semantic State regenerations than step-wise updating.

## 1. 核心问题与研究动机

- **背景**：机器人基础模型沿两条互补路线发展——VLA（视觉-语言-动作）模型提供语义理解与多任务泛化，WAM（世界-动作模型）通过预测未来世界表征提供空间变化与交互动力学监督。两者分别回答"下一步该做什么"与"物理交互会如何演化"。
- **核心痛点**：简单叠加语义推理与未来预测，并不能保证局部场景预测或动作与任务进度对齐。一个局部合理的预测/动作，可能对应已经完成或尚未到达的子任务。
- **根本缺失**：现有分层策略、记忆型策略（MemoryVLA、MEM、SeqVLA 等）关注语义推理或记忆累积，但**没有显式规定任务进度应如何被表示、维护并在语义分支与世界-动作分支之间共享**。
- **论文主张**：应把任务进度建模为一个**持久化的认知状态（Semantic State）**，而不是在每一步从单帧观测中反复推断；并通过结构化接口将其传递给预测与控制分支。

## 2. 方法论

### 2.1 核心思想

- 用持久化 **Semantic State** `S_t = (m_t, s_t)` 显式表示任务进度：`m_t` 为已完成任务事件记忆，`s_t` 为当前活跃子任务。
- 将**语义时间尺度**与**控制时间尺度**解耦：动作需高频重规划，而任务语义只在少量阶段转换处变化。状态可跨多个动作块持续存在。
- 概率分解为两部分：
  - `p(St, Z_{t+H}, at | Ot, ℓ, St−) = p(St | Ot, ℓ, St−) · p(Z_{t+H}, at | Ot, ℓ, St)`
  - 第一项建模任务进度转换，第二项建模进度条件化的世界预测与动作生成。
- **关键设计**：动作生成不依赖预测的未来表征；未来预测仅作为训练期目标，推理时移除世界分支。

### 2.2 事件触发语义状态更新

- 由 VLM 预测二值决策 `d_t ∈ {KEEP, UPDATE}`：`d_t ∼ pθ(d_t | O_t, ℓ, S_t−)`。
- 当 `d_t = UPDATE` 时，自回归生成记忆增量与更新后的子任务：`(Δm_t, s_t) ∼ pθ(· | O_t, ℓ, S_t−, d_t=UPDATE)`。
- 状态更新规则：
  - `KEEP` → 保持 `S_t = S_t−`
  - `UPDATE` → `S_t = (m_t− ⊕ Δm_t, s_t)`（⊕ 为追加）
- 推理时 `d_t` 单次前向即可判定：KEEP 避免自回归生成，仅 UPDATE 才解码语义内容。

### 2.3 进度条件化 WORLD/ACTION 接口

- 在观测、指令、语义上下文之后追加两组**可学习查询 token** `Q_w`（16 个）与 `Q_a`（25 个），因果序列中共同注意力于当前上下文，输出 `H_w`、`H_a` 分别路由至未来多视图潜在预测与连续动作生成。
- 分支特异性监督使查询各自抽取面向自身目标的表示，实现"共享任务级语义 + 保留目标特异性表征"。

### 2.4 潜在世界-动作建模

- 冻结 DINO 编码器将当前/未来多视图图像映射为 `Z_t`、`Z_{t+H}`；预测未来 DINO 特征而非像素重建，保留物体结构与空间信息且更轻量。
- 采用 **Mixture-of-Transformers（MoT）** 双流结构：World 流预测 `Z_{t+H}`，Action 流生成 `a_t`，共享 `Z_t` 为视觉锚点，通过多模态自注意力交互。
- 结构化注意力掩码阻止 Action token 关注未来潜在 token，避免目标泄漏；World 分支为训练期协同目标而非中间规划。

### 2.5 训练策略与损失

- 两个分支均用 flow matching：对动作与未来表征分别插值噪声，预测速度场，损失为 `L_action` 与 `L_world`（均为预测速度与目标速度之差的 L2）。
- 语义损失 `L_sem = L_dec + 1[d*_t=UPDATE]·L_gen`，总损失 `L = L_action + λ_world·L_world + λ_sem·L_sem`（λ_world=1.0，λ_sem=0.005）。
- **边界感知语义采样**：语义转换稀疏（仅 9.19% 帧为 UPDATE），对 UPDATE 与"hard KEEP"（转换边界前后一个重规划间隔的帧）过采样，构成 1:1:1 语义批次；该重平衡仅用于语义监督，不影响世界/动作训练分布。
- **渐进式语义条件化**：以概率 ρ_k 使用模型预测状态 `Ŝ_t`、否则使用标注状态，ρ_k 随训练从 0 增至 0.5（30k 前为 0，40k 为 0.2，50k 为 0.5），缓解训练-推理状态分布不匹配。
- **离线语义标注**：用 GPT-5.6 Sol 作为固定标注器定位阶段边界，生成右开区间子任务跨度；对阶段数依赖情节的任务（如 Arrange Largest Number）先从早期观测推断阶段数；再做规范化（吸收空隙）与位置化记忆增量计算（用最长公共前缀而非集合差，避免同句重复子任务被误删）。

- **局限**：真实世界每任务仅 20 次试验、每分布偏移每任务 5 次，统计功效有限；部分任务（如 Block Sorting 5/20）方差风险较高；未做跨 checkpoint 的受控闭环对比（作者自己说明仅做了非正式机测）；语义状态子任务条件化与累积记忆未做组件级分离消融。

## 6. 主要结论与发现

- **性能**：
  - RoboDojo 无机器人预训练下达到 **15.56 / 11.70% Score/SR**，较 StarVLA-α 提升 9.16 Score / 8.46 SR，并超过多个有预训练基线。
  - BiCoord 平均 **58.0 / 43.8% SSR/SR**，超最强基线 π0.5 达 7.2 / 8.2 个百分点。
  - 真实世界基本任务 94/120，泛化设置 72/120。
- **更新时机比频率更重要**：事件触发在 RoboDojo 与 BiCoord 上均最优；同步更新虽重生成频率高得多，却未超过异步更新。
- **部署效率**：真实机器人 30 Hz 控制、每 10 步重规划（333 ms 预算）下，同步更新延迟 927.8 ms（超预算 2.8×），异步 309.3 ms 但转换延迟升至 502 ms；CogWAM 每步仅做 KEEP/UPDATE 单次前向决策，延迟降至 146.7 ms，重生成次数减少 **16.4×**，转换延迟保持与同步相同的 152 ms。
- **接口可迁移**：同一语义接口挂到 Fast-WAM，平均 Score/SR 从 3.48/2.03% 提升
