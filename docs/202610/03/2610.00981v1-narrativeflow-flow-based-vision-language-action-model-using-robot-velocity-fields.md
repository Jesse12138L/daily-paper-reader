## 摘要
我们关注语言条件下的基于流的操作，其中机器人流（机器人速度场）作为与具身无关、以运动为中心的表征，用于利用从多个机器人平台收集的数据。该任务至关重要，因为语言条件下的操作对于实际机器人系统必不可少，但扩展机器人基础模型仍受限于特定具身数据劳动密集的采集过程。现有方法要么用稀疏关键点位移粗略近似机器人流，要么无法处理语言条件下的操作。为解决这一局限，我们提出 NarrativeFlow，它使用以语言为条件的流匹配形式，将机器人流建模为连续速度场。因此，NarrativeFlow 生成的机器人流与真实世界操作在物理上一致。为验证 NarrativeFlow，我们在语言条件下操作的标准数据集上进行了实验。实验结果表明，NarrativeFlow 在标准评估指标上优于代表性基线方法。此外，通过真实世界实验，我们表明 NarrativeFlow 在多种操作任务上取得了比基线方法更高的成功率。项目页面见 https://shota0520.github.io/NarrativeFlow-project-page/

## Abstract
We focus on language-conditioned flow-based manipulation, where robot flows (robot velocity fields) serve as embodiment-agnostic, motion-centric representations for leveraging data collected from multiple robot platforms. This task is crucial because language-conditioned manipulation is essential for practical robotic systems, yet scaling robot foundation models remains limited by the labor-intensive collection of embodiment-specific data. Existing methods either coarsely approximate robot flows with sparse keypoint displacements, or cannot handle language-conditioned manipulation. To address this limitation, we propose NarrativeFlow, which models robot flows as continuous velocity fields using a flow-matching formulation conditioned on language. Accordingly, NarrativeFlow generates robot flows that are physically consistent with real-world manipulation. To validate NarrativeFlow, we have conducted experiments on standard datasets for language-conditioned manipulation. The experimental results show that NarrativeFlow outperforms representative baseline methods on standard evaluation metrics. Furthermore, through real-world experiments, we show that NarrativeFlow achieves higher success rates than baseline methods across multiple manipulation tasks. ## 1. 核心问题与整体含义

- **研究动机**：语言条件下的操作对制造、物流、医疗等实际机器人系统至关重要，但扩展机器人基础模型受限于**特定具身数据采集成本高、劳动密集**。
- **核心问题**：如何利用来自多个机器人平台的数据，学习一种**与具身无关、以运动为中心**的中间表示，并在此基础上完成语言条件下的操作。
- **现有方法局限**：
  - 许多基于流的方法（如 FLIP、Im2Flow2Act）用**稀疏关键点位移**粗略近似机器人流，难以刻画连续、时变的物理操作过程。
  - Flow as Flow 可将机器人流建模为稠密速度场，但只支持**目标图像条件**，无法处理语言条件。
  - 现有方法通常只使用流生成主损失，缺少对任务相关语义的显式监督，容易受背景、光照等无关视觉细节干扰。
- **整体含义**：NarrativeFlow 试图把机器人流建模为**连续概率速度场**，并通过语言条件流匹配生成物理一致的机器人流，从而缓解跨平台数据瓶颈，推动可扩展的语言条件操作基础模型。
