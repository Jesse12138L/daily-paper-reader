## 摘要
机器人世界模型预测以动作为条件的未来场景，为理解动作结果提供了基础。然而，将替代预测转化为有用的学习信号仍然具有挑战性：相似的候选会限制有信息量的质量比较，而发散的轨迹则要求持续维护各自的个体历史。我们提出 FutureWorlds，一个统一了候选构建、历史维护以及基于相对质量进行学习的框架。FutureWorlds 构建于多模态离散自回归模型之上，在强化学习过程中使用多样化束搜索来构建兼顾置信度与多样性的候选未来。候选特定的有界记忆保留场景状态，并确保生成与策略评分使用相匹配的历史。我们进一步提出 MemSPO（记忆条件化搜索引导策略优化，Memory-Conditioned Search-Guided Policy Optimization），它将视频轨迹奖励转换为组相对优势，以优化世界模型。在 RT-1、BridgeV2 和 RoboCasa 上，相对于各数据集上最强的基线，FutureWorlds 将 32 帧预测的 LPIPS 分别降低了 14.78%、20.84% 和 9.12%。在固定评估配置下，仅 200 次 MemSPO 更新便进一步提升了生成质量，并支持在训练范围之外继续进行预测。记忆消融、解码敏感性分析和光流评估表明，这些收益不仅限于视觉质量，还延伸到更准确的运动预测和更一致的物体状态。项目页面与代码：https://github.com/Alexander-wu/FutureWorlds。

## Abstract
Robotic world models predict action-conditioned future scenes, providing a foundation for understanding action outcomes. However, turning alternative predictions into useful learning signals remains challenging: similar candidates limit informative quality comparisons, while diverging trajectories require persistent maintenance of their individual histories. We introduce FutureWorlds, a framework that unifies candidate construction, history maintenance, and learning from relative quality. Built on a multimodal discrete autoregressive model, FutureWorlds uses diverse beam search during reinforcement learning to construct candidate futures that balance confidence and diversity. Candidate-specific bounded memory preserves scene states and ensures that generation and policy scoring use matching histories. We further propose MemSPO (Memory-Conditioned Search-Guided Policy Optimization), which converts video trajectory rewards into group-relative advantages to optimize the world model. On RT-1, BridgeV2, and RoboCasa, FutureWorlds reduces LPIPS for 32-frame predictions by 14.78%, 20.84%, and 9.12%, respectively, relative to the strongest baseline on each dataset. Under fixed evaluation configurations, only 200 MemSPO updates further improve generation quality and support continued prediction beyond the training horizon. Memory ablations, decoding sensitivity analysis, and optical-flow evaluation show that these gains extend beyond visual quality to more accurate motion prediction and more consistent object states. Project page and code: https://github.com/Alexander-wu/FutureWorlds.

## 1. 核心问题与整体含义

- **研究动机**：机器人世界模型需要预测“给定观测、动作序列、语言指令”下未来场景如何演化，为动作结果预测、视觉规划、行为学习和策略评估提供基础。
- **核心挑战**：同一条件下模型可生成多种替代未来，但把这些替代未来转化为有效学习信号并不容易：
  - 候选未来若过于相似，缺乏有信息量的质量比较；
  - 候选未来若发散，每条轨迹都需要持续维护自己的历史，否则生成与策略评分条件不一致；
  - 传统自回归世界模型主要依赖教师强制监督训练，训练时使用真实历史，推理时使用自生成历史，存在曝光偏差和误差累积；
  - token 级似然也不直接优化完整生成序列的质量。
- **整体含义**：论文提出 FutureWorlds，将“候选构建—历史维护—相对质量学习”统一起来，让世界模型能够从自己生成的替代未来中学习，从而提升动作条件视频预测的质量、运动一致性和长时预测能力。

## 2. 方法论

- **核心思想**：基于多模态离散自回归世界模型，在强化学习后训练阶段构造多样化候选未来，为每个候选维护独立且有界的记忆，并通过组相对奖励比较候选质量，更新世界模型。
- **基础模型与 SFT**：
  - 使用 GPT 风格自回归模型，对视觉 token、动作和语言条件联合建模。
  - 视觉侧采用压缩 tokenization：初始场景用较多 context token，后续动态帧用较少 dynamic token，并通过 FSQ 离散化。
  - 动作经归一化和离散化，语言由冻结 T5 编码器通过 cross-attention 注入。
  - SFT 使用负对数似然，仅监督目标动态 token，更新自回归主干、动作嵌入和文本 cross-attention。
- **候选构建：多样化束搜索**：
  - 在 RL 后训练中维护 G 个搜索组，每组 b 个 beam。
  - 组 g 的搜索分数在模型对数概率基础上加入跨组差异惩罚：
    - \(S_g(y \oplus v) = S_g(y) + \log \pi_{old}(v|u(y)) - \lambda_{div} d_g(v)\)
  - 其中 \(d_g(v)\) 衡量同一位置 token 被更早组选择的归一化频率，用于减少候选冗余。
  - 每组最终返回一条轨迹，产生 G 个候选视频。
- **候选特定有界记忆**：
  - 每个候选 i 在预测第 t 帧前维护记忆：
    - 初始场景编码 C；
    - 状态锚 \(z_{anc}\)；
    - 初始动作；
    - 最近 W 帧的预测动态 token 和对应动作。
  - 记忆窗口满足 token 预算 \(|M_t^{(i)}| \le B\)。
  - 搜索分支继承父分支记忆，并在候选选择后同步重排。
  - 策略评分使用与生成完全相同的记忆和帧内前缀，保证“生成条件”和“打分条件”一致。
- **MemSPO：记忆条件化搜索引导策略优化**：
  - 解码候选轨迹后，用视频奖励评估质量，基础奖励为逐帧 MAE 与 LPIPS 的负和：
    - \(R_i = -\frac{1}{H}\sum_t [\text{MAE}(\hat{o}_t^{(i)}, o_t) + \text{LPIPS}(\hat{o}_t^{(i)}, o_t)]\)
  - 组内归一化得到相对优势：
    - \(A_i = (R_i - \bar{R}) / (\text{Std}(R_1,\dots,R_G) + \varepsilon)\)
  - 使用 GRPO 风格组相对优势和 clipped policy surrogate 更新模型，并加入参考策略正则项。
  - 当前策略、旧策略和冻结参考策略都在相同候选历史条件下评分。
  - 每个新候选集执行一次世界模型更新；视觉 tokenizer、文本编码器和记忆规则保持冻结。
- **理论分析**：
  - 在旧策略处，奖励梯度可写成候选对之间的成对分解。
  - 若所有候选奖励相同，或所有候选 score gradient 相同，则奖励梯度为零。
  - 给出候选分数梯度坍缩时的梯度幅度上界，说明候选多样性对学习信号的重要性，但强调搜索改变候选分布，不保证无偏 on-policy 梯度或单调改进。

## 6. 主要结论与发现

- **视频生成质量显著提升**：
  - 相对于各数据集最强基线，32 帧预测 LPIPS 分别降低：
    - RT-1：14.78%；
    - BridgeV2：20.84%；

  - PSNR 和 SSIM 也在三个数据集上领先。
- **后训练效率高**：
  - 固定评估配置下，仅 200 次 MemSPO 更新即可进一步改善生成质量。

- **支持超出训练时长的预测**：

  - 光流评估显示 FutureWorlds 降低 flow error 和 magnitude gap，并提高 DINO 相似度。
