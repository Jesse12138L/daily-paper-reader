## 摘要
视觉-语言-动作（VLA）模型连接多模态理解与机器人控制，推动了具身智能的主流范式。然而，现有大多数模型依赖大型 Transformer，其时延和能耗成本阻碍了在资源受限平台上的部署。通过稀疏的事件驱动计算，脉冲神经网络为高性能与高能效计算提供了一种有前景的范式。在此，我们提出首个脉冲驱动的 VLA 框架，可实现面向机器人操作的端到端直接训练，主要包含三个核心组件。首先，我们开发了用于多模态感知的脉冲视觉编码器和指令编码器，将视觉观测和语言指令编码为稀疏、可靠的脉冲表示，以供后续跨模态融合。然后，我们引入多赢家脉冲融合（Multi-Winner Spike Fusion）用于指令引导的场景理解，利用双向 top-$k$ 赢者通吃脉冲路由来抑制背景干扰并生成融合记忆。最后，我们提出脉冲动作分块 Transformer（Spike Action Chunking Transformer），其融合了基于融合记忆和当前机器人状态的脉冲交叉注意力，能够高效地端到端生成用于机器人控制的连续动作块。在 LIBERO 和 Meta-World 上的大量实验表明，脉冲驱动 VLA 以更少参数和更低的估计推理能耗，实现了与传统 VLA 模型有竞争力的性能。这项工作为神经形态 VLA 建模建立了一个基础框架，为资源高效的具身智能的未来发展铺平了道路。

## Abstract
Vision-language-action (VLA) models bridge multimodal understanding and robotic control, advancing the dominant paradigm for embodied intelligence. However, most existing models rely on large Transformers, whose latency and energy costs hinder deployment on resource-constrained platforms. Through sparse event-driven computation, spiking neural networks offer a promising paradigm for high-performance and energy-efficient computing. Here, we propose the first Spike-driven VLA framework enabling end-to-end direct training for robotic manipulation, which mainly comprises three core components. First, we develop spiking visual and instruction encoders for multimodal perception, encoding visual observations and language instructions into sparse, reliable spike representations for subsequent cross-modal fusion. Then, we introduce Multi-Winner Spike Fusion for instruction-guided scene understanding, using bidirectional top-$k$ winner-take-all spike routing to suppress background interference and yield fused memory. Finally, we propose a Spike Action Chunking Transformer that incorporates spiking cross-attention over the fused memory and the current robot state, enabling efficient end-to-end generation of continuous action chunks for robotic control. Extensive experiments on LIBERO and Meta-World demonstrate that Spike-driven VLA achieves competitive performance with fewer parameters and lower estimated inference energy than conventional VLA models. This work establishes a foundational framework for neuromorphic VLA modeling, paving the way for future advances in resource-efficient embodied intelligence.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉–语言–动作（VLA）模型将多模态理解与机器人控制统一到同一策略中，是具身智能的主流范式（RT-2、PaLM-E、Octo、OpenVLA、π0 等）。
- **核心痛点**：主流 VLA 依赖大型预训练视觉–语言骨干，模型规模大、计算密集（稠密 MAC），带来高内存、高延迟与高能耗，难以部署在资源受限的机器人/边缘平台上。
- **已有的轻量化路线不足**：TinyVLA、TurboVLA、SmolVLA 等仅通过紧凑架构压缩模型，仍沿用稠密乘加计算范式，闭环控制中反复推理代价依旧高昂。
- **脉冲神经网络（SNN）的潜力与缺口**：SNN 以稀疏事件驱动计算，突触计算可用累加（AC）替代乘法（MAC），在 45nm ASIC 上 AC 能耗仅为 MAC 的 1/5–1/10。但现有脉冲 VLA（如 SpikeVLA）多依赖 ANN-to-SNN 转换，须保留源 ANN 架构、无法做任务定制化设计，且需多时间步累积脉冲近似连续激活，时间开销大。
- **本文定位**：提出**首个支持端到端直接训练的脉冲驱动 VLA 框架**，面向机器人操作，目标是在更少参数、更低估计推理能耗下取得与主流 ANN-VLA 有竞争力的性能。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体架构（三阶段）
- **阶段一**：脉冲视觉编码器（SVE）+ 脉冲指令编码器（SIE）进行多模态感知，输出稀疏脉冲表示 $Z_{v,n}\in\mathbb{R}^{N_v\times d}$、$Z_\ell\in\mathbb{R}^{N_\ell\times d}$。
- **阶段二**：多赢家脉冲融合（MWSF）实现指令引导的跨模态交互，输出任务条件记忆 $M_n\in\mathbb{R}^{(N_v+N_\ell)\times d}$（保留连续膜电位残差）。
- **阶段三**：脉冲动作分块 Transformer（SpikeACT）结合融合记忆与当前机器人状态，并行输出连续动作块 $\hat{A}_n\in\mathbb{R}^{K\times d_a}$。

### 2.2 基础组件
- **LIF 脉冲神经元**：膜电位积分 $\tilde u^l[t]=\lambda u^l[t-1]+I^l[t]$，超过阈值 $V_{th}$ 发放脉冲 $s^l[t]=H(\tilde u^l[t]-V_{th})$，随后软/硬重置；Heaviside 不可导，反向传播用替代梯度（sigmoid/fast sigmoid/arctan 类）。
- **脉冲自注意力（SSA）**：Q、K、V 均由 `SN(BN(Linear(·)))` 生成；**去掉 Softmax**，仅保留缩放因子 $s$：$\text{Score}=s\cdot QK^\top$，$\text{Attn}=\text{SN}(\text{Score}\times V)$，实现无 softmax 的高能效全局依赖建模。

### 2.3 脉冲视觉编码器 SVE
- 三阶段金字塔结构：前两阶段分别含 1 个和 2 个 Conv Mixer 块提取局部特征并下采样；第三阶段含 7 个 SSA 块建模全局空间依赖。
- 三阶段特征图尺寸为 $C\times H/4\times W/4$、$2C\times H/8\times W/8$、$4C\times H/16\times W/16$。
- **双视角编码**：主视角与腕部视角共享同一骨干权重，各得到 $14\times14=196$ 个空间 token，线性投影到 $d=256$ 后拼接为 392 个视觉 token。
- 骨干先在 ImageNet-1K 上预训练，再与融合/动作模块联合微调。

### 2.4 脉冲指令编码器 SIE
- 采用脉冲 BERT 骨干（SmoothSpike-12-768）：12 层、12 头、隐维 768、MLP 维 3072、时间步 $T=4$。
- 用 MLM（15% 掩码）预训练，输入最大长度 128；预训练语料约 176 亿训练 token（1.37 亿个 128-token 块）。
- **训练时冻结骨干**，仅训练维度适配器 `BN(Linearℓ(·))`（768→256），为每条指令提供固定语义特征；保留时间维不取平均。
- 骨干中的正交变换（Hadamard 初始化 + Newton–Schulz 迭代）可折叠进相邻线性权重，推理不引入额外矩阵乘法。

### 2.5 多赢家脉冲融合 MWSF
- **动机**：视觉 token 远多于语言 token 且背景杂乱；直接对全局做 SSA 会让弱背景响应累积、稀释显著证据。
- **流程**：
  1. 模态特定脉冲投影得到 $Q_v, V_v$（视觉）与 $K_\ell, V_\ell$（语言），均为二值脉冲。
  2. 构造**共享跨模态亲和矩阵** $R_n = Q_v K_\ell^\top \in \mathbb{Z}^{T\times B\times N_v\times N_\ell}$。
  3. 对 $R_n$ 与 $R_n^\top$ 分别做 **Top-k 多赢家选择（WTA$_k$）**：掩码 $a_j^{(k)}=1$ 当且仅当 $j\in\text{TopK}_k(r)$ 且 $r_j>0$，否则为 0——**无需 softmax 归一化**。
  4. 双向上下文：$C_v = Z_{v,n}+\text{BN}(\text{Linear}(\text{SN}(\text{WTA}_{k_v}(R_n)V_\ell)))$，$C_\ell = Z_\ell+\text{BN}(\text{Linear}(\text{SN}(\text{WTA}_{k_\ell}(R_n^\top)V_v)))$；两个方向使用不同路由预算 $k_v, k_\ell$ 以应对视觉/语言长度不平衡。
  5. 拼接后加带可学习通道尺度 $\gamma$ 的残差：$M_n=[C_v;C_\ell]+\gamma\odot\text{BN}(\text{Linear}(\text{SN}([C_v;C_\ell])))$；$\gamma$ 推理时可折入 BN 的仿射参数，不破坏脉冲驱动计算。

### 2.6 脉冲动作分块 Transformer（SpikeACT）
- 状态编码器 $E_s$ 将机器人状态编码为 $N_s$ 个状态 token，与 $M_n$ 拼接得到状态增强记忆 $\tilde M_n\in\mathbb{R}^{N_m\times d}$（$N_m=N_v+N_\ell+N_s$）。
- 使用 **K 个可学习动作 token** $P_a$ 作为 query，$\tilde M_n$ 生成 key/value，构造亲和矩阵 $R_{a,n}=Q_aK^\top$。
- 经 $\text{WTA}_k(R_{a,n})$ 稀疏路由，每个动作 query 只检索位置特定的视觉/语言/状态证据（端到端由动作监督学习）。
- 时间维读出：$\hat A_n=\tanh(\text{Avg}_T[\text{Linear}_a(\text{SN}(\text{WTA}_k(R_{a,n})V))])$，$\tanh$ 约束连续控制量范围；**一次前向并行预测 K 步动作块**。

### 2.7 训练设置
- 行为克隆 + **掩码 L1 损失**（预测动作块 vs 专家动作块），每步构造 12 步相对动作目标，轨迹末端填充位置被掩码。
- LIBERO：$K=12$，$d_a=7$；Meta-World MT50：$K=12$，$d_a=4$。
- 优化：AdamW（β=(0.9, 0.95)），视觉骨干 LR $1\times10^{-5}$、其他可训练参数 LR $5\times10^{-5}$，10K 步线性 warmup 后恒定；全局梯度范数裁剪到 1；EMA 衰减 0.999；FP32、关闭 TF32；有效批大小 256（8 GPU × 32 样本）；训练 80K 更新（约 2048 万样本曝光）。
- 不采用分阶段目标切换，也不使用 ANN-to-SNN 转换。
