## 摘要
视频生成模型（VGMs）为具身观测-动作建模提供了强大的时空先验。然而，关节空间动作向量缺乏显式的图像空间结构，且在不同具身之间维度和语义各异，这使得直接利用 VGM 丰富的时空先验颇具挑战。末端执行器可视化提供了一种替代方案，但未指定机器人执行所需的完整关节构型。我们提出 Dream4ACT，一个为跨具身联合视频-动作建模而构建的世界模型。为统一跨具身的动作表示，我们引入一种共享视觉动作接口，称为动作视图，它使用基于 URDF 的正向运动学，从四个预设虚拟相机渲染目标关节构型。这种共享视觉表示保留了具身特有的关节几何结构，同时允许观测序列和动作序列共享一个视频自编码器和扩散 Transformer。通过掩码流匹配，我们的模型通过改变哪些未来序列被破坏，在单个联合训练模型中支持前向动力学、逆向动力学以及联合观测-动作生成。为了从预测的动作视图中恢复可执行的动作序列，我们提出一种无需训练、受 URDF 约束的多视图恢复机制，且不需要学习具身特定的解码器。Dream4ACT 在 RoboTwin 2.0 上达到 88.98% 的平均成功率，在 TriWorldBench 上取得 65.66 的总分，支持有效的闭环操作，并通过视觉动作接口实现有竞争力的动作条件多视图预测。

## Abstract
Video generation models (VGMs) offer strong spatiotemporal priors for embodied observation--action modeling. However, joint-space action vectors lack explicit image-space structure and vary in dimensionality and semantics across embodiments, making it challenging to directly leverage the rich spatiotemporal priors of VGMs. End-effector visualizations provide an alternative but do not specify the full articulated configuration needed for robot execution. We present Dream4ACT, a world model built for joint video-action modeling across embodiments. To unify action representations across embodiments, we introduce a shared visual action interface, called action views, which render target joint configurations from four prescribed virtual cameras using URDF-based forward kinematics. This shared visual representation preserves embodiment-specific articulated geometry while allowing observation and action sequences to share a video autoencoder and diffusion transformer. Through masked flow-matching, our model supports forward dynamics, inverse dynamics, and joint observation--action generation within a single jointly trained model by varying which future sequences are corrupted. To recover executable action sequences from predicted action views, we propose a training-free, URDF-constrained multiview recovery mechanism, without a learned embodiment-specific decoder. Dream4ACT achieves an average success rate of 88.98\% on RoboTwin~2.0 and an overall score of 65.66 on TriWorldBench, supporting effective closed-loop manipulation and competitive action-conditioned multiview prediction through the visual action interface.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视频生成模型（VGMs）具备强大的时空先验，已被广泛用于具身智能中的观测-动作建模。然而，如何将 VGM 的时空先验直接迁移到机器人控制仍存在根本性障碍。
- **核心矛盾**：
  - **关节空间动作向量**缺乏显式的图像空间结构，且在不同具身（机器人本体）之间维度、语义、关节数量均不一致，导致无法直接复用 VGM 的共享建模能力。
  - **末端执行器可视化**（如末端位置热图）虽提供了视觉表示，但只描述末端位姿，无法给出机器人执行所需的完整关节构型；从末端指令到关节目标仍需具身特定的逆解，可能不存在解或存在多解。
- **研究目标**：构建一个跨具身的**共享视觉动作接口**，使观测（RGB）与动作序列能够共享同一个视频自编码器与扩散 Transformer，同时保留具身特定的关节几何，并可从预测结果中恢复可执行的关节目标。
- **整体意义**：为多具身视频-动作世界模型提供了一种无需具身特定动作解码器、可统一前向动力学、逆向动力学与联合生成的建模范式。

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想
- 将**目标关节构型渲染为图像**（称为 **action views**），使异构关节空间拥有统一固定形状的视觉表示，从而与 RGB 观测共享同一视频建模主干。
- 通过**掩码流匹配（Masked Flow Matching）**在同一模型中切换前向动力学、逆向动力学与联合生成三种模式。
- 通过**免训练、URDF 约束的多视图匹配**从生成的 action views 中恢复关节目标，无需学习具身特定解码器。

### 2.2 关键技术细节

- **视觉动作表示（Action Views）**
  - 使用 URDF 正运动学 `FK(S_{t'}; U)` 将当前与未来关节构型映射到 4 个预设虚拟相机（front、top、left、right）下渲染，得到固定尺寸图像：
    `x_i^{t'} = R(FK(S_{t'}; U); K_i, T_i), i ∈ V`
  - 虚拟相机内外参由任务级预设固定，**不依赖物理相机外参标定**；不同具身共享视图角色与渲染规范，仅数值参数按组不同。

- **指令接地语义适配器**
  - 使用冻结的 Qwen3.5-VL 9B，将指令 `l` 与头部相机当前帧联合处理，取最后 4 层隐藏层的视觉/语言 token 分别拼接投影。
  - 用 4 个可学习 query 对视觉特征做交叉注意力压缩，再与语言 token 拼接做联合自注意力，得到语义条件 `F_sem`，与生成主干联合训练。

- **多序列潜空间 Token 化**
  - 共享 Wan2.2 VAE 编码器分别编码每条 RGB 序列与 4 条 action view 序列。
  - 为每个潜特征加入**模态嵌入**（rgb/action）与**视图嵌入**，RoPE 位置编码中通过 `δ_s` 偏移为不同序列分配独立空间区域，避免位置冲突。

- **联合扩散 Transformer 与掩码流匹配**
  - 对每条序列使用模态特定的噪声水平（`τ_rgb`、`τ_act`），构造联合的干净/加噪潜表示：
    `z̃_{s,f} = (1-m_{s,f}) z_{s,f} + m_{s,f}[τ_s z_{s,f} + (1-τ_s) ε_{s,f}]`
  - 损失仅在 corrupted 位置上计算速度场回归。
  - 掩码 `m_{s,f} = 1[s ∈ M ∧ f ≥ 1]` 决定生成模式：
    - **前向动力学**：M = S_rgb（RGB 加噪，action 干净）
    - **逆向动力学**：M = V（action 加噪，RGB 干净）
    - **联合生成**：M = S（全部加噪）
  - 训练时三种模式按 0.2 / 0.2 / 0.6 采样，并额外以 0.7/0.3 采样 I2V 与 V2V 前缀条件。

- **免训练动作恢复（Training-Free Action Recovery）**
  - 对预测 action view 做二值化+膨胀，与候选构型渲染图比较。
  - 评分函数：`E(A) = Σ_i [1 - IoU(x_i(A), x̃_i)] + λ Σ_i d→(x̃_i, x_i(A))`，IoU 奖励轮廓重叠，Chamfer 距离区分不相交轮廓。
  - 流程分三阶段：**帧级估计**（Levenberg–Marquardt / Gauss–Newton 多起点优化，式 20 为阻尼正规方程）、**窗口级估计**（三次 B 样条轨迹拟合 + 时序正则）、**夹爪解码**（基于红-绿颜色解码 + 三帧中值滤波）。

### 3.1 数据集与场景
- **仿真操作**：RoboTwin 2.0（50 个双臂操作任务），收集 2,500 clean + 25,000 randomized 演示（每任务 50 / 500 条）。
- **世界模型评测**：TriWorldBench（官方 500 回合测试集），使用同步头相机与腕相机生成视频。
- **真实世界**：4 个平台——Aloha-Agilex、TienYi2.5 Pro（双臂）、Franka Research 3、UR5e（单臂）；4 个任务（place_block、wipe_plate、stack_blocks、storage_item），12 个具身-任务对，共 720 条演示。
- **多具身评测**：5 个具身——Aloha-Agilex、ARX-X5、Franka-Panda、Piper、UR5-Xsg，取 31 个共享任务。
- **消融数据集**：DROID（1,000 条训练轨迹，50 条 CLVR/RAD 测试轨迹）。

### 3.2 Benchmark
- RoboTwin 2.0 官方任务成功判据（clean / randomized 各 100 次试验/任务）。
- TriWorldBench 六项指标：TVC、TA、P3D、MQ、TC、VQ 及总分 TWB-Score。
- 消融使用 PSNR、SSIM、LPIPS 衡量 RGB 预测保真度。

### 3.3 对比方法
- **操作任务**：π0.5、Motus、LingBot-VA、Fast-WAM。
- **视频预测**：Ctrl-World、Motus、Genie Envisioner、DreamDojo、BWM。
- **消融**：camera-aligned skeleton conditioning（PointWorld 相机精修投影）vs. action-view rendering。

## 4. 资源与算力

- 文中明确说明：训练使用 **16 × NVIDIA B200 GPU**，batch size 16，AdamW 优化器，学习率 1×10⁻⁵，余弦调度，warmup 1000 步，权重衰减 1×10⁻²。
- 真实世界推理部署使用 **NVIDIA A800 GPU**：生成约 **6.9 秒/80 步 chunk**，动作恢复约 **2.7 秒/chunk**。
- **训练时长未明确给出**，论文未报告总训练时间或总 GPU 小时数。

## 5. 实验数量与充分性

- **主要实验组数**：
  1. RoboTwin 2.0 全 50 任务 clean + randomized（表 3、表 10 逐任务）。
  2. TriWorldBench 6 指标评测（表 4）。
  3. 5 具身 × 31 任务 × clean/randomized 多具身评测（表 5、表 9、表 11）。
  4. 4 真实平台 × 多任务 × 20 次试验（表 6）。
  5. DROID 消融（骨架 vs. action view，表 7）。
  6. 动作恢复误差评测（位置 mm / 旋转度，表 9）。
- **充分性评估**：
  - 覆盖仿真、真实、多具身、消融四个维度，实验规模较大（如多具身 775 次试验/设置、真实 20 次/对）。
  - **客观性**：操作基线采用公开报告结果，评测遵循官方协议；消融在相同轨迹与相同 checkpoint 步数下对比，控制较严。
  - **公平性注意点**：部分基线为公开报告数值而非同一环境复现；多具身任务仅取 31 个交集任务，与全 50 任务评测使用不同 checkpoint，直接横向比较需谨慎。

## 6. 主要结论与发现

- **闭环操作**：RoboTwin 2.0 上 clean 90.50%、randomized 87.46%，平均 **88.98%**；优于 π0.5（79.80%）与 Motus（87.80%），略低于 LingBot-VA（92.20%）与 Fast-WAM（91.80%）。
- **世界模型**：TriWorldBench 总分 **65.66**，与 BWM（65.54）相当；取得最高 P3D、MQ、TC，VQ 与 BWM 持平。
- **多具身**：同一份权重在 Aloha-Agilex、ARX-X5、Piper 上平均成功率 >81%，Franka-Panda 63.48%，UR5-Xsg 30.97%，无需具身特定动作头。
- **真实世界**：共同任务平均成功率 85–90%（Aloha 87.5%、TienYi 85.0%、Franka 87.5%、UR5e 90.0%）；含 stack/storage 时双臂平台四任务均值为 61.3% / 66.3%。
- **消融**：action-view 渲染优于相机对齐骨架投影（PSNR 23.19→24.33，SSIM 0.899→0.906，LPIPS 0.105→0.093），且无需物理相机外参标定。
- **总体发现**：action views 既能作为多视图预测的条件信号，又能作为可恢复为可执行命令的生成表示，双重角色得到验证。

## 7. 优点

- **表示设计新颖**：用 URDF 渲染的固定四视图替代关节向量或末端热图，兼顾异构关节空间的统一性与具身几何的保真性。
- **无需具身特定解码器**：恢复过程免训练，依赖 URDF 约束的多视图几何匹配，避免了为每个机器人训练动作头。
- **统一建模框架**：单一共享权重通过掩码切换支持前向动力学、逆向动力学与联合生成，训练/推理模式灵活。
- **不依赖物理相机外参**：虚拟相机预设在构建与恢复中均无需物理标定，降低了数据采集门槛。
- **实验覆盖广**：涵盖仿真、真实、多具身、视频生成与消融，且提供逐任务结果，透明度较高。
- **消融设计合理**：在相同轨迹与相同训练步数下对比骨架投影与 action view，结论可信。

## 8. 不足与局限

- **具身与任务覆盖有限**：仅验证 5 个仿真具身 + 4 个真实平台，对未见具身的迁移能力尚未验证。
- **依赖 URDF 与渲染规范**：恢复需要具身特定 URDF 和与训练一致的渲染约定；运动学不匹配会影响物理执行。
- **恢复精度受限于生成视图质量与几何可观测性**：如 UR5-Xsg 恢复误差达 11.85 mm / 21.39°，成功率仅 30.97%，Franka-Panda 也明显低于其他具身。
- **推理延迟高**：每个 80 步 chunk 需约 6.9 s 生成 + 2.7 s 恢复，仅支持 chunk 级执行，无法实时逐步重规划。
- **多具身评测任务子集化**：仅 31 个交集任务，且与全 50 任务使用不同 checkpoint，削弱了跨实验的严格可比性。
- **基线比较不完全对等**：部分基线为公开报告值，未在同一环境复现；训练数据规模与采集策略可能存在差异。
- **训练时长与总算力未披露**：仅给出 16×B200 与超参，缺少训练时长、总 GPU 小时等信息，复现成本难以评估。
- **真实世界数据多样性有限**：演示仅在标称背景下采集，未包含背景变化或额外干扰物，泛化性验证不充分。
