## 摘要
机器人脑模型整合视觉、语言和机器人状态，为复杂操作任务生成动作。大多数模型预测固定长度的动作块，这些动作块可能跨越多个任务阶段。这会掩盖阶段转换，并偏向频繁出现的动作模式，从而损害动态环境中的动作时序。我们提出 PhasePlan，一种面向机器人脑模型的有序未来阶段规划方法。它根据当前多模态观测，预测每个未来动作位置处的任务阶段。由此得到的规划表示对相应动作进行条件化，保持任务进展与动作生成之间的时间对齐。训练时首先学习规划器，然后在动作模型自适应期间冻结它，以保持稳定的阶段表示。我们在预训练的 $π_{0.5}$ 和 AcrossWAM1.0 机器人脑模型上实例化 PhasePlan。详细的定量评估使用 $π_{0.5}$ 实现。在传送带操作任务上，相较于原始 $π_{0.5}$ 模型，PhasePlan 将离线关节动作误差降低约 22.5%。它还改进了阶段转换建模和跨阶段动作预测。这些结果证明了有序未来阶段规划对于连续动作生成的价值。

## Abstract
Robot brain models integrate vision, language, and robot state to generate actions for complex manipulation tasks. Most predict fixed-length action chunks that may span multiple task phases. This can obscure phase transitions and favor frequent action patterns, compromising action timing in dynamic environments. We propose \method, an ordered future-phase planning method for robot brain models. From current multimodal observations, it predicts the task phase at each future action position. The resulting planning representations condition the corresponding actions, preserving temporal alignment between task progress and action generation. Training first learns the planner, then freezes it during action-model adaptation to maintain stable phase representations. We instantiate \method on pretrained $π_{0.5}$ and AcrossWAM1.0 robot brain models. Detailed quantitative evaluation uses the $π_{0.5}$ implementation. On conveyor-belt manipulation, \method reduces offline joint-action error by approximately 22.5\% relative to the original $π_{0.5}$ model. It also improves phase-transition modeling and cross-phase action prediction. These results demonstrate the value of ordered future-phase planning for continuous action generation.

## 1. 核心问题与研究动机

- **背景**：机器人脑模型（Robot Brain Models）整合视觉、语言与机器人状态，通过 VLA（Vision-Language-Action）策略为复杂操作任务生成可执行动作。代表性工作包括 RT-1/RT-2、Open X-Embodiment、OpenVLA、π₀、π₀.₅、GR00T N1、LingBot-VLA 等。
- **核心痛点**：多数策略预测**固定长度动作块**（action chunk），一个输出块可能跨越多个任务阶段（如 Wait→Act 或 Act→Release）。这带来两个问题：
  - 阶段转换（phase transition）被模糊化，转换时机难以精确定位；
  - 动作优化偏向高频出现的动作模式（如长时间 Wait/Transport），而短阶段（如 Release）被欠拟合。
- **关键观察**：两个阶段计数相同的序列（如 `Wait, Wait, Act, Act` 与 `Act, Act, Wait, Wait`）在每个未来位置上所需的动作完全不同。仅用"未来技能直方图"这类聚合分布无法表达阶段顺序与转换位置。
- **研究含义**：需要一种**位置对齐（position-aligned）**的任务进度表示，在动作块内部显式刻画"每个未来位置处于哪个阶段"，从而保持任务进度与动作生成的时间对齐。

## 2. 方法论

### 2.1 核心思想

- 对动作块中的每个未来位置 `h`（共 H=16），预测其任务阶段分布 `p_{t,h}`，并用该分布与上下文规划表示共同**条件化**对应位置的动作 token，实现"位置到位置"的规划—动作对齐。

### 2.2 问题形式化

- 输入观测：`o_t = (I_head, I_wrist, s_t, ℓ)`，即头部 RGB、腕部 RGB、本体状态、语言指令。
- 输出动作块：`A_t = (a_{t+1}, …, a_{t+H})`，`a ∈ R^{d_a}`。
- 阶段词表：`Z_τ`，传送带任务含 4 个阶段：Wait、Act、Release、Return-Home。
- 阶段标签由 VLX-Seek 物体标注 + 夹爪状态 + 任务特定时序规则构造，为每个有效未来动作窗口提供逐位置监督。

### 2.3 有序未来阶段规划器

- 引入 H 个可学习阶段查询 `u_1,…,u_H`，每个查询对应一个未来动作位置，共享同一观测上下文 `X_t = E(o_t)`，但保留各自的位置身份。
- 计算：
  - `Q_{t,h} = P_{θP}(u_h, X_t)`（上下文规划表示）
  - `p_{t,h} = softmax(W_z Q_{t,h} + b_z)`（阶段分布）
- 规划损失为逐位置阶段分类交叉熵 `L_phase`，仅在有效未来位置集合 `V_t` 上计算，保留阶段类别与转换位置两重信息。
- 消融显示：**独立查询（independent queries）**略优于交互查询，最终采用独立结构。

### 2.4 规划条件化的动作生成

- 将阶段分布映射为软阶段嵌入：`ē_{t,h} = E_z^T p_{t,h}`。
- 与规划表示融合：`e_{t,h} = W_Q Q_{t,h} + W_P ē_{t,h}`，同时包含任务上下文与显式阶段概率。
- 通过轻量网络 `f_{θM}` 预测逐位置的缩放与偏移 `(γ_{t,h}, β_{t,h})`，对动作专家表示 `x_{t,h}` 做调制：
  - `x̃_{t,h} = (1 + γ_{t,h}) ⊙ RMSNorm(x_{t,h}) + β_{t,h}`
- `f_{θM}` 最后一层零初始化，保证适配初期不破坏预训练动作路径；每个 `e_{t,h}` 只影响对应位置的 `x_{t,h}`，维持全块的位置对齐。

### 2.5 两阶段训练与推理

- **第一阶段**：优化 `L_phase`，训练阶段查询与规划器层，动作专家冻结。
- **第二阶段**：冻结规划器，优化原始 flow-matching 动作目标 `L_flow`，更新动作专家与逐位置调制路径。
- 推理流程：`o_t → (Q_{t,1:H}, p_{t,1:H}) → A_t`，规划器作为策略内部活跃组件，部署时只需标准多模态输入，不依赖物体标注。

## 9. 对后续研究的启示与可借鉴点

- **"位置对齐"是任务进度表示的关键维度**：论文用同计数不同顺序的反例说明，仅靠聚合分布（直方图、全局技能比例）无法表达阶段顺序与转换位置。这一观察可推广到任何需要"未来进度条件化"的策略设计中。
- **逐位置监督可迁移到更广的长时程任务**：只要任务能被分解为阶段/子技能序列，就可为动作块内每个未来位置构造阶段标签，将规划信号以位置对齐方式注入动作专家，而不必改变动作生成范式。
- **调制机制与骨干模型解耦**：软阶段嵌入 + FiLM 式逐位置缩放/偏移 + 零初始化适配路径，是一种对动作专家侵入性小、训练稳定的通用插件，理论上可插入 flow-matching、diffusion 或自回归等不同动作头。
- **两阶段"先规划、后冻结适配"的配方**：先学语义规划、再冻结规划器适配动作，可避免规划表示被动作目标带偏；这一解耦思路对其它"高层表示 + 低层控制"的联合训练问题具有参考价值。
- **阶段标签自动化是落地瓶颈**：当前依赖 VLX-Seek 标注 + 夹爪状态 + 人工时序规则。后续可用 VLM 自动分段、变化点检测、HMM/自监督技能发现来降低标注成本，从而扩展到更多任务。
- **评估范式建议**：后续工作应优先补充闭环成功率、多任务/长时程基准、H 与阶段词表敏感性、推理延迟，以及与更多进度建模基线的公平对比。

## 10. 总体评价

PhasePlan 针对机器人脑模型中"固定长度动作块跨越多个任务阶段"这一结构性问题，提出了一个简洁而针对性强的解决方案：用 H 个位置对齐的阶段查询预测每个未来位置的任务阶段分布，并以该分布逐位置调制对应动作 token。其核心贡献不在于新的动作生成架构，而在于**任务进度表示的位置对齐化**——它弥补了聚合式未来技能直方图无法区分阶段顺序与转换位置的缺陷，并通过消融（Ours-P 与完整方法对比、oracle 上界、视觉输入必要性）较清晰地隔离了该机制的贡献。实验在真实传送带任务上取得了约 22.5% 的整体关节 MAE 下降与 93.2% 的夹爪准确率，并给出规划器约 92.5% 的逐位置阶段准确率，证据链相对完整。主要短板在于任务覆盖面单一、阶段标签构造依赖人工规则、闭环与真机定量评估不足、算力与推理开销未披露。总体而言，这是一篇**问题定义精准、方法轻量、消融扎实**的工作，其"逐位置阶段规划 + 位置对齐条件化"的思想对长时程机器人操作策略具有较好的可迁移性与启发意义，但距离通用、自动化、可大规模验证的阶段感知策略仍有明显距离。
