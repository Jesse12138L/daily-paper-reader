## 摘要
使用离散动作token的视觉-语言-动作（VLA）模型已被证明能有效控制机械臂完成操作任务。然而，对于人形机器人而言，全身动作空间——腿、躯干、手臂和手——维度高得多且异质，带来了此前VLA模型未曾解决的token化、训练和实时推理挑战。我们提出Holo-M，据我们所知，这是首个用于人形机器人移动操作的离散VLA模型，它通过用动作token扩展语言模型的词表，内在地利用语言模型。在该模型中，我们设计了一个统一的动作分词器，将人形机器人动作空间分解为四个针对身体部位的分词器——末端执行器、身体、手和运动学——从而能够跨差异极大的具身形态和数据源进行训练，包括人形机器人遥操作、第一人称人类视频和仿真。通过用这些动作token扩展语言模型的词表，我们避免了使用独立连续动作专家的模型所固有的知识隔离问题。为满足实时控制需求，我们通过分组离散扩散解码来解码每个身体部位的动作token，而不是对动作token使用自回归。我们在SIMPLE人形机器人移动操作基准上进行了大量实验，Holo-M在通用与专用评估中均取得了最高成功率，并以显著优势领先第二名。我们将发布所有代码和模型权重。

## Abstract
Vision-language-action (VLA) models using discrete action tokens have proven effective for controling robotic arms on manipulation tasks. For a humanoid, however, the whole-body action space -- legs, torso, arms, and hands -- is far higher-dimensional and heterogeneous, raising tokenization, training, and real-time inference challenges that the previous VLA models do not address. We present Holo-M, to our knowledge the first discrete VLA model for humanoid loco-manipulation that intrinsically exploits the language model by extending its vocabulary with action tokens. In this model, we devise a unified action tokenizer that decomposes the humanoid action space into four body-part-specific tokenizers -- end-effector, body, hand, and kinematics -- enabling training across drastically different embodiments and data sources, including humanoid teleoperation, ego-centric human video, and simulation. By extending the language model's vocabulary with these action tokens, we avoid the knowledge-insulation problem inherent to the models that use separate continuous action experts. To meet real-time control requirements, we decode each body part's action tokens through grouped discrete diffusion decoding, rather than using autoregression on the action tokens. We have conducted extensive experiments on the SIMPLE humanoid loco-manipulation benchmark, in which Holo-M achieves the highest success rates in both the generalist and specialist evaluations, leading the second best by significant margins. We will release all the code and model weights.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型已成为通用机器人策略的主流方案。其中一类工作将动作表示为与文本共享词表的**离散 token**，使动作生成退化为语言模型本就擅长的序列建模问题；但这类方法此前几乎只针对**机械臂**（动作空间低维：少量关节角或末端位姿+夹爪）。
- **核心问题**：人形机器人的全身动作空间（腿、躯干、手臂、灵巧手）维度远高于单臂或轮式双臂平台，且在不同尺度与时间尺度上高度**异构**。直接套用机械臂式方案会遭遇三重叠加困难：
  - **Token 化**：单一扁平词表要么过粗（精度不足），要么过大（超出可用上下文）；
  - **训练**：没有任何单一数据集覆盖人形全部自由度，必须从差异极大、部分重叠的数据源中学习；
  - **实时推理**：在显著更长的动作 token 序列上做自回归解码，对全身控制而言过慢。
- **现状缺口**：现有人形 VLA 模型（如 Ψ0）普遍采用**连续动作生成**——在 VLM 主干上外挂 flow-matching / 扩散动作专家，而这类专家必须与预训练 VLM 主干做梯度隔离（knowledge insulation），否则会破坏其语义表征。
- **整体含义**：论文提出 **Holo-M**，据作者所知是**首个面向人形 loco-manipulation 的离散 VLA 模型**，通过用动作 token 扩展语言模型词表，让动作生成直接受益于主干模型能力，同时避免知识隔离边界。

## 2. 方法论

### 2.1 核心思想

将人形全身动作空间**按身体部位分解**为四个独立分词组，把各组动作 token 加入语言模型词表，并用手**分组离散扩散**并行解码，从而同时解决 token 化、跨本体训练与实时推理三个问题。

### 2.2 统一动作分词器（Unified Action Tokenizer）

- **规范化动作表示**：动作块含 T = 30 步、30 Hz，总维度 96，按固定组顺序 **EEF → body → hand → kinematics** 拼接。
- **四组维度与 token 数**：

  | 组 | 表示 | 维度 | Token 数 |
  |---|---|---|---|
  | End effector | 腕部与指尖位姿 | 48 | 100 |
  | Body | 身体关节目标 | 29 | 62 |
  | Hand | 手部关节目标 | 14 | 32 |
  | Kinematics | 基座运动指令 | 5 | 14 |
  | 合计 | — | 96 | 208 |

- **EEF 组**含双臂腕位置、6D 腕旋转、相机坐标系下指尖位置；body/hand 为硬件特定顺序的关节空间目标；kinematics 含基座速度、高度、偏航角速度指令。
- **FAST-RVQ 分词**（在 FAST 基础上的改造）：
  - 沿时间轴对每个动作维度做 **DCT**，仅保留前 N 个低频系数（实现中 N = 2），其余时域残差用**残差向量量化（RVQ）**编码（Q = 4 级，各级码本由 k-means 拟合，不训练额外神经分词器）。
  - 相比 FAST 的 BPE 变长序列，FAST-RVQ 产生**定长** token 序列，便于掩码并行解码：每组 token 长度 L_g = N·D_g + Q = 2D_g + 4。
  - 验证集动作块重建误差为 **0.0068**。
- **跨源监督**：各组仅在其数据源实际提供时计入损失（组有效性掩码 v_g），缺失组不做人工填充，从而统一遥操作人形数据、第一人称人类视频与仿真数据。

### 2.3 VLM 主干与动作 token

- 主干为 **Qwen3-VL-2B**；机器人数据用头部相机 RGB，人类数据用对应第一人称 RGB，图像缩放至 640×360，训练时施加颜色抖动。
- **条件上下文顺序**：image → task → setup → state；setup 字段标识本体与数据源（如 "G1 humanoid robot from Humanoid Everyday"、"Human egocentric data from EgoDex"）；state 为选定关节角，裁剪至 [−π, π] 后归一化并均匀量化为 256 个 state-bin token。state token 仅作条件，不计入 208 个动作 token。
- 动作序列用结构 token 包裹：`Action: <action_output><action_start> <end_effector_start>[100]<end_effector_end> <body_start>[62]... <kinematics_start>[14]... <action_end>`。
- 目标函数为按组、按 token 的因果分解 p(y_t | c_t)，不可用组通过 v_g 排除。

### 2.4 分组离散扩散解码

- **训练（Grouped Masked-Token Training，基于 DiffusionVL 适配）**：每个动作组构成一个扩散块；**块内 token 双向交互**（可并行重建），**块间保持因果依赖**（当前组只能看到条件上下文与前置组）。对每个有效组独立采样掩码率 p_g，对被掩码位置按重加权对数似然求损失，再按组权重 w_g 与有效性 v_g 加权归一化；不引入独立扩散模型或动作头。
- **推理（Confidence-based De-masking）**：四组按规范顺序**串行**解码，组内所有位置初始为 [MASK]，每轮由模型预测所有掩码位置并给出置信度，高置信位置先解掩码，每轮解掩码数量由该组 token 长度与扩散步数决定；组完成后追加到因果上下文用于下一组；条件前缀与已完成组跨轮缓存。
- **加速效果**：以每组 8 步去掩码为例，四个组共需 **32 步串行解码**，相比 208 步逐 token 自回归，串行深度降低 **6.5×**。

### 2.5 四阶段训练流程

1. **Stage I 自回归预训练**：在 EgoDex 与 Humanoid Everyday 上联合预训练，用同一组有效性掩码混合异构数据（如 EgoDex 样本仅 EEF 组计入损失）。
2. **Stage II 人形后训练**：在 SIMPLE 人形训练集上继续自回归训练，对齐目标机器人观测、动作与交互动力学；产出 Holo-M AR 基线检查点。
3. **Stage III 分组离散扩散微调**：以分组掩码扩散目标微调 Stage-II 检查点，主干、词表、组顺序均不变，得到 Holo-M 通用策略。
4. **Stage IV 任务特定微调**：从 Stage-III 出发，用单任务演示微调，得到 Holo-M 专家策略；架构、词表、目标均不变。

- 全程**冻结视觉编码器**，仅优化语言主干用于动作 token 预测。
