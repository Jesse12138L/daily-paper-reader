## 摘要
基于流的视觉-语言-动作（VLA）策略通过输运来自任务无关的各向同性高斯源的样本生成动作块。由于该源既不以近期执行也不以预测的未来演化为条件，(i) 它丢弃了由近期已执行运动所建立的局部连续性。(ii) 即使引入预测性世界表示，它们通常也只对输运动力学施加条件，而不决定生成从何处开始、可偏离多远，或可沿哪些动作方向扩展。基于这一观察，我们提出 ProAct，一种世界校准的提议到动作框架，使生成源本身可预测。(i) 为保持运动连续性，轻量级提议专家通过一个以运动为锚的端点流匹配步骤，将近期动作转换为场景感知假设，从而在演示动作流形附近初始化生成。(ii) 为同时捕捉意图中的场景演化以及提议与未来之间的兼容性，一个前瞻性世界专家将该假设视为软运动先验，同时预测与任务一致的潜在未来。(iii) 基于这种兼容性，模型校准一个以提议为中心的各向异性源；其中，有界的每步范围控制允许的偏差，而在条件数预算下的迹归一化低秩几何将细化分配到耦合的平移、旋转和夹爪方向上。与 $π_{0.5}$ 相比，ProAct 在仿真和真实世界任务中提升了性能，同时将去噪步数减少 50%、推理延迟最多降低 25.8%，并将吞吐量最多提升 34.8%。

## Abstract
Flow-based Vision-Language-Action (VLA) policies generate action chunks by transporting samples from a task-agnostic isotropic Gaussian source. As this source is conditioned on neither recent execution nor predicted future evolution, (i) it discards the local continuity established by recently executed motion. (ii) Even when predictive world representations are introduced, they often only condition the transport dynamics rather than determine where generation starts, how far it may deviate, or along which action directions it may expand. Building on this observation, we introduce ProAct, a world-calibrated proposal-to-action framework that makes the generative source itself predictable. (i) To preserve motion continuity, a lightweight Proposal Expert converts recent actions into a scene-aware hypothesis via one motion-anchored endpoint flow-matching step, initializing generation near the demonstrated action manifold. (ii) To jointly capture intended scene evolution and proposal-future compatibility, a prospective World Expert treats the hypothesis as a soft motion prior while predicting the task-consistent latent future. (iii) From this compatibility, the model calibrates a proposal-centered anisotropic source, where a bounded per-step extent controls the allowed deviation and a trace-normalized low-rank geometry under a condition-number budget allocates refinement over coupled translation, rotation, and gripper directions. Compared with $π_{0.5}$, ProAct improves performance across simulation and real-world tasks while reducing denoising steps by 50%, inference latency by up to 25.8%, and increasing throughput by up to 34.8%.

## 1. 核心问题与整体含义

- **背景**：基于流匹配/扩散的视觉-语言-动作（VLA）策略通常从任务无关的各向同性高斯源采样，再通过生成式输运得到动作块。
- **核心问题**：
  - 该源既不以近期执行动作，也不以预测未来演化为条件，因此丢弃了机器人运动的局部连续性。
  - 即便引入世界模型或未来预测，现有方法多只用未来信息调制输运动力学，而不决定“从哪里开始生成、允许多大偏差、沿哪些动作方向细化”。
- **整体含义**：论文提出 **ProAct / PROACT**，将生成源本身变为可预测、可校准的“世界校准提议源”。核心思想是：近期运动只应作为软提议，而不是直接复用；该提议需要由任务一致的未来预测来校准，从而兼顾运动连续性、未来兼容性与生成效率。

## 2. 方法论

- **总体框架**：提出 **propose–calibrate–refine** 流程：
  1. **Proposal Expert**：把近期执行动作转为场景感知运动假设。
  2. **World Expert**：预测任务一致的潜在未来，并评估提议与未来的兼容性。
  3. **Action Expert**：从校准后的各向异性源出发，输运生成可执行动作块。
- **问题分解**：
  - 给定观测、语言、本体状态和近期动作历史，生成未来动作块。
  - 生成概率分解为：提议 `p(P|Ha)`、世界建模 `p(Hw|P)`、源校准 `p(X|P,Hw)`、动作生成 `p(A|X,Hw)`。
- **Proposal Expert**：
  - 用平滑运动状态 `m_t = β m_{t-1} + (1-β)Δa_t` 外推近期运动，得到运动外推块。
  - 外推公式为 `a_mom_{t,k} = a_{t-1} + (1-λ^k)/(1-λ) m_t`，夹爪维度保持最后执行值。
  - 使用浅层 Proposal Expert，从 VLM 的 18 层 KV 中以三层窗口融合压缩上下文。
  - 将运动外推作为流匹配源，只做一步端点流匹配，得到场景感知提议 `P_t`。
  - 训练时扰动提议源，推理时直接使用运动外推，并用 `L_prop` 监督提议接近演示动作。
- **World Expert**：
  - 使用冻结的 **V-JEPA 2** 编码未来视频片段，得到潜在未来目标。
  - World Expert 是 Transformer，无流时间条件，学习时空查询。
  - 将提议作为上下文 token 注入，但未来预测目标仍是演示未来，避免提议错误“自证”。
  - 同时输出未来预测和校准读数；校准目标使用演示动作与提议的残差 `A* - P`。
  - 采用非对称设计：未来目标与提议正确性解耦，提议只作为软运动先验。
- **世界校准源构造**：
  - **细化范围**：由提议–未来兼容性预测每步偏差范围。
    - 残差 `r = A* - P`，用动作尺度矩阵归一化。
    - 兼容性目标 `U* = 1 - exp(-e/τ_u)`，模型预测 `U = sigmoid(f_u(g_w))`。
    - 每步标准差 `σ = σ_min + U(σ_max - σ_min)`，用 MSE 监督。
  - **细化几何**：预测低秩因子 `B ∈ R^{d_a×r}`，构造尺度归一化协方差：
    - `C = σ² d_a (I + BBᵀ) / tr(I + BBᵀ)`。
    - 迹归一化防止 `B` 改变平均方差。
    - 对 `B` 做 Frobenius 范数投影，满足 `||B||_F² ≤ S_max`，从而控制条件数 `κ ≤ 1 + S_max`，论文设 `S_max = 5`。
    - 用马氏项和对数行列式项 `L_B` 学习几何。
  - **采样源**：`X_src = P + L_t ε`，其中协方差为块对角形式，允许平移、旋转、夹爪方向耦合。
- **Action Expert**：
  - 保留基础 VLA 的流参数化，只替换高斯源为校准源。
  - 路径 `X_s = s X_src + (1-s) A*`，目标速度 `v* = X_src - A*`。
  - 使用 `L_flow` 训练 Action Expert；Action Expert 同时关注 VLM 上下文、世界 token 和自身动作状态。
- **总损失**：
  - `L = λ_p L_prop + λ_f L_future + λ_u L_U + λ_b L_B + λ_a L_flow`。
  - 各损失分别负责提议质量、未来预测、细化范围、细化几何和动作输运。
