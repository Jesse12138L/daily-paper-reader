## 摘要
世界动作模型将未来视觉动态与机器人动作预测相结合，但其可扩展性仍受限于对带有动作标注的机器人轨迹的需求。仅观测视频包含关于交互动力学的丰富证据，但现有方法通常要么用它们预训练视觉表征，之后还需适配到控制任务，要么用它们推断潜在动作，随后再将这些潜在动作与机器人指令关联起来。我们提出 NAVA-WAM，它通过直接从仅观测视频中预训练动作策略，引入原生动作先验学习，避免了从表征到控制的间接迁移，也避免了单独的潜在动作模型。我们的训练分为两个阶段。首先，我们在仅观测视频上进行预训练，其中对视觉过渡的未来视频流匹配监督通过过渡结构化的联合注意力进行传播，以优化 Action-DiT 并学习与动作相关的先验。其次，我们使用带动作标注的演示数据对 Action-DiT 进行后训练，以通过联合视频—动作流匹配实现机器人控制，同时非对称注意力将视觉分支与迭代动作去噪解耦，并支持高效的仅动作推理。大量实验表明，NAVA-WAM 在分布内和分布外设置下均持续优于先前方法，同时展现出很强的动作标签效率以及有效的真实机器人泛化能力。这些结果确立了原生动作先验学习作为一种有效方法，可直接从仅观测视频中预训练动作策略，为超越带动作标注的机器人数据提供了一条可扩展路径。

## Abstract
World action models integrate future visual dynamics with robot action prediction, but their scalability remains limited by the need for action-annotated robot trajectories. Observation-only videos contain rich evidence about interaction dynamics, but existing approaches typically use them either to pretrain visual representations that must later be adapted for control, or to infer latent actions that are subsequently grounded to robot commands. We present NAVA-WAM, which introduces native action-prior learning by directly pretraining the action policy from observation-only videos, avoiding indirect representation-to-control transfer or a separate latent-action model. Our training consists of two stages. First, we pretrain on observation-only videos, where future-video flow-matching supervision over visual transitions is propagated through transition-structured joint attention to optimize the Action-DiT and learn action-relevant priors. Second, we use action-labeled demonstrations to post-train the Action-DiT for robot control through joint video--action flow matching, while asymmetric attention decouples the visual branch from iterative action denoising and enables efficient action-only inference. Extensive experiments show that NAVA-WAM consistently outperforms prior approaches under both in-distribution and out-of-distribution settings, while demonstrating strong action-label efficiency and effective real-robot generalization. These results establish native action-prior learning as an effective approach to directly pretrain action policies from observation-only videos, providing a scalable path beyond action-labeled robot data.

# NAVA-WAM 论文总结

## 1. 核心问题与研究背景

- **世界动作模型（WAMs）的瓶颈**：WAM 将未来视觉动态预测与动作生成耦合，有望提升策略泛化性，但其扩展性受制于**带动作标注的机器人轨迹**——采集成本高、跨本体难以标准化。
- **纯观测视频的价值与浪费**：大规模无动作标注视频蕴含丰富的物理交互与状态转移信息，是潜在的可扩展监督源，但现有利用方式存在两条"绕路"：
  - **视觉表征学习**：先学视觉/预测表征，再用动作标注数据在其上训练策略，形成"表征→控制"的**间接迁移**，视频先验始终停留在视觉中心表征中。
  - **潜在动作学习**：从视觉过渡推断类动作变量作为中间监督，需**额外的潜在动作建模阶段**，且依赖复杂架构/优化约束防止"捷径解"（潜在动作直接复制目标观测），会限制潜在动作空间表达力。
- **本文提出的核心问题**：能否让纯观测视频**直接优化动作策略**，而不依赖任何中间接口？作者给出肯定答案——**原生动作先验学习（Native Action-Prior Learning）**，即 NAVA-WAM。
- **整体含义**：为超越昂贵的动作标注机器人数据、实现 WAM 的可扩展预训练提供了一条直接路径。

## 2. 方法论

### 2.1 核心思想

- 采用 **Mixture-of-Transformers（MoT）** 架构：预训练 **Video-DiT**（θ_V，初始化自 Wan2.2-5B）+ **Action-DiT**（θ_A，1B 参数、隐藏维 1024），两者保留模态专属参数，通过**联合注意力**交换信息（式 2）。
- 预训练阶段：**冻结 Video-DiT**，仅用**未来视频流匹配**监督，通过"过渡结构化联合注意力"让视频目标直接反向传播到 Action-DiT，从而在动作策略内部直接习得动作相关先验——**无中间接口**。
- 后训练阶段：用动作标注演示做**视频–动作联合流匹配**，把先验落地为本体特定连续控制；并通过**非对称注意力**实现视觉分支可缓存、仅动作推理。

### 2.2 关键技术细节

**（a）逆–前向动力学隐式建模**

- 借鉴逆动力学 `r_k = q(z_{k-1}, z_k)` 与前向动力学 `ẑ_k = f(z_{k-1}, r_k)` 的分解，但不引入独立模型，而是**通过注意力结构隐式实现**。
- 每个视觉过渡 `z_{k-1} → z_k` 构造一个**过渡段（segment）**：包含干净的先前状态 `z_{k-1}`、加噪的未来状态 `z_{k,τv}`、以及对应的 Action-DiT token 组 `x^a_k`；段间由注意力掩码完全隔离（附录 B.3、图 7）。

**（b）过渡结构化联合注意力（式 4、5）**

- Action-DiT 查询可同时访问前序状态与（加噪）未来状态：`H_{A,k} = Attn(Q_{A,k}, [K_{V,k-1}; K_{V,k,τv}; K_{A,k}], ...)` —— 类似逆动力学，形成过渡的内部表示。
- 加噪未来状态查询可访问视觉状态与 Action-DiT 表示：`H_{V,k,τv} = Attn(...)` —— 类似前向动力学。
- **关键设计**：Action-DiT 只能看到未来状态的**加噪版本** `z_{k,τv}`，无法直接复制干净目标 `z_k`，避免捷径解。

**（c）预训练目标（式 6、7）**

- 流匹配：`z_{k,τv} = (1-τv) z_k + τv ε^v_k`，目标速度 `u^v_k = ε^v_k - z_k`；Action-DiT 输入独立采样噪声 `ε^a_k`，动作时间步固定为 τa=1。
- `L_pre = E[ Σ_k w(τ) ||v_{θ̄V,θA}([z_{k-1}, z_{k,τv}], ε^a_k, τ | l) - u^v_k||² ]`，仅优化 θ_A。
- **机制**：未来视频预测依赖 Action-DiT 表示，而 Video-DiT 冻结，因此最小化视频目标即通过联合注意力通路直接更新 θ_A。

**（d）后训练与推理（式 8–13）**

- **非对称过渡注意力**：Video-DiT 查询仅关注视觉流（式 8）；Action-DiT 查询仍关注视觉+动作流（式 9）。
- 联合流匹配损失：`L_post = λv L^v_FM + λa L^a_FM`（λv=λa=1），视频目标适配视觉专家到目标域，动作目标将 Action-DiT 落地为机器人控制。
- **仅动作推理**：在 τv=τa=1 时做一次联合前向，缓存各层 Video-DiT 的 K/V（`C_V`）；之后仅通过 Action-DiT 迭代去噪（式 13，10 步均匀 Euler），无需生成未来视频，实现高效闭环控制（算法 1）。

**（e）理论分析（附录 A）**

- **命题 A.1**：过渡表示 r_k 的预测价值等于条件期望差 `E[||E[z_k|z_{k-1},r_k] - E[z_k|z_{k-1}]||²] ≥ 0`。
- **命题 A.2**：在 `z_k|z_{k-1} ~ N(µ, Σ)` 假设下，任意 τ>0 时条件协方差 `(Σ^{-1} + (1-τ)²/τ² I)^{-1}` 严格正定，即未来状态无法被完美传递，**加噪有效阻断目标复制捷径**。
