## 摘要
世界动作模型（WAM）通过预测观测与动作随时间如何演化，推动了机器人控制的发展。尽管取得了这些进展，基于 RGB 与动作的未来预测并未显式处理机器人操作所需的空间理解。现有工作通常通过专门的头部或分支加入有限的一组空间预测任务，使空间监督的范围与模型架构均呈现碎片化。我们提出 XGenAct，一种世界动作模型，它通过确定性编解码器将 RGB 观测、机器人动作、度量深度、表面法线与功能角色分割统一表示为 RGB 视频。通过在训练过程中对感知任务与动作任务进行采样，XGenAct 仅使用一个视频扩散 Transformer 和一个目标函数，即可在这些空间上学习时序预测，而无需模态特定的学习头部。在留出的 RLBench 任务上，结构化感知训练相比仅使用 RGB 的训练提升了平均闭环成功率；在五项任务的外部对比中，XGenAct 取得 52% 的成功率，而评估中最强的基线为 26%。与先生成 RGB、再应用冻结感知专家的评估流程相比，它也能更准确地预测未来的深度与分割。

## Abstract
World action models (WAMs) have advanced robot control by predicting how observations and actions evolve over time. Despite this progress, RGB and action based future prediction does not explicitly address the spatial understanding needed for robot manipulation. Existing efforts often add a limited set of spatial prediction tasks through specialized heads or branches, leaving both the range of spatial supervision and the model architecture fragmented. We introduce XGenAct, a world action model that represents RGB observations, robot actions, metric depth, surface normals, and functional role segmentation as RGB videos through deterministic codecs. By sampling perception and action tasks during training, XGenAct uses one video diffusion transformer and one objective to learn temporal prediction across these spaces without modality specific learned heads. On held out RLBench tasks, structured perception training improves average closed loop success over RGB only training, and XGenAct achieves 52% success in the five task external comparison, versus 26% for the strongest evaluated baselines. It also predicts future depth and segmentation more accurately than the evaluated pipelines that generate RGB first and then apply a frozen perception expert.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）通过联合预测未来 RGB 视频与机器人动作来实现生成式机器人控制，相比直接预测动作的 VLA 模型，能提供关于视觉动态与时序上下文的稠密监督。
- **核心问题**：现有 WAM 的进展主要是**时序上的，而非空间上的**。机器人工作在三维世界中，但大多数 WAM 仅用二维 RGB 视频表示预测世界。仅靠外观预测无法显式捕捉度量深度、表面朝向等物理交互所需的空间结构，这成为 WAM 进一步发展的主要瓶颈。
- **已有方案的不足**：
  - 直接预测 3D/4D 表示（点云、点轨迹）虽有丰富几何结构，但需要额外表示与解码流程，难以与动作高效联合预测。
  - 更常见的做法是通过**辅助预测头、门控残差模块或模态专用分支**引入深度、光流、语义图等空间监督，各自有独立的表示与训练目标。
  - 监督覆盖**碎片化**：深度受关注最多，表面法线、任务相关功能区域等互补信息很少被纳入单一模型。
- **核心主张**：空间监督不应是附着在 RGB-based WAM 上的辅助组件，而应把多种几何与语义预测任务表达在**与观测和动作相同的生成空间**中，让结构化空间知识直接塑造共享的动作生成器。

## 2. 方法论

### 2.1 核心思想
- 受 Action Images（将 7-DoF 动作表示为多视角 RGB 视频）启发，把**图像空间作为感知与控制的统一接口**。
- 度量深度、表面法线、功能角色分割都可经确定性编解码器表达为可解码的 RGB 图像。
- 所有流由**同一个冻结视频 VAE** 编码进共享潜空间，由**同一个扩散 Transformer、同一个输出头、同一个流匹配目标**处理，无模态专用学习头、无辅助损失、无需人工平衡的损失系数。

### 2.2 几何增强的视频空间（确定性编解码器 γₘ）
- **RGB**：恒等映射。
- **动作**：沿用 Action Images 编解码器，把每个 7-DoF 末端位姿投影到相机视角，渲染为 RGB 视频（三通道高斯 blob，σ = 0.05·min(H,W)，工具长度 ℓ=0.1 m；蓝通道低响应背景额外存储夹爪开合基座）。
- **度量深度**：先用单调幂变换压缩（Barron 2025 的 power transform，λ=−3，c=10³），再把标量映射到 RGB 立方体上的一条分段线性 Hamiltonian 路径（8 个顶点间逐坐标变化）；解码时把生成像素投影到最近路径边，恢复 y 后反变换得深度；偏离路径的像素标记为无效，构成"离开有效流形"的显式检测器。
- **表面法线**：由度量深度经相机感知有限差分计算，再映射为 γ_normal(n) = (n+1)/2；解码后重归一化为单位长度。
- **功能角色分割**：固定 RGB 调色板 LUT（背景、目标、目标区域、机械臂、夹爪、干扰物、工具、固定物 8 类 + 1 个被拒的 unknown），跨任务/回合/视角/帧共享，语义是**功能角色**而非物体类别。
- **准入门槛**：每个编解码器在训练前都要通过直接往返与冻结 VAE 往返检验（深度 AbsRel 0.066%→0.362%；法线余弦 0.999998→0.9906；分割 IoU >0.98→中位 0.965）。新增感知任务只需增加确定性编解码器。

### 2.3 任务模板与条件计划
- 每个训练样本选择一个感知模态 m，与两视角动作流组成模板：Πₘ = [m⁽¹⁾, a⁽¹⁾, m⁽²⁾, a⁽²⁾]，m ∈ {RGB, depth, normal, segmentation}，四段顺序固定。
- 条件计划定义哪些位置被观测（F=整段给定，I=只给首帧其余生成，1=只含首帧）：
  - ρ_joint = (I,I,I,I)：联合预测未来感知与动作
  - ρ_policy = (1,I,1,I)：从当前感知预测未来动作
  - ρ_inverse = (F,I,F,I)：从完整感知序列反推动作
- 所有模板共享同一计划分布；另有 10% 概率丢弃动作流，退化为仅从首帧生成整段感知视频。
- 模板分布：video+action 概率 0.4，depth/segmentation/normal+action 各 0.2。

### 2.4 共享训练目标
- 打包潜序列 Z_Π 被计划划分为观测集 O（保持干净）与预测集 P（与高斯噪声按 (1−t)Z + tε 插值）。
- 流匹配损失**只作用于需生成的位置**，观测位置只提供上下文：
  L(θ) = E[w(t)/|P| · Σ_{i∈P} ‖f_θ(Z̃_t, t, ρ, c)_i − (ε_i − Z_i)‖²]
- 该目标对所有模态、模板、计划完全相同，跨任务训练只改变共享潜序列的内容与被预测的位置。

### 2.5 基础架构
- 基于 Wan2.2-TI2V-5B 潜视频扩散 Transformer，因果 3D VAE 冻结；41 帧 512² 片段编码为 11×32×32 网格（48 通道），仅微调扩散 Transformer。
- 相机条件：两视角，Plücker 射线嵌入经冻结 VAE 编码，每个 Transformer block 有独立相机编码器，输出在自注意力前加到 token 特征上。
- 推理：给定当前视角与位姿，同一权重 50 步流采样，冻结 VAE 解码 → 动作图经双视角射线融合恢复 7-DoF → IK 执行 → 重规划。

## 6. 主要结论与发现

1. **结构化感知训练显著提升闭环控制**：每个带感知流的菜单都优于 RGB-only，平均成功率从 32.5% 提升至 52.5–61.25%，最优为 **RGB+N+S 的 61.25%（+28.75 个百分点）**。
2. **更多模态并非单调更好**：在 RGB+N+S 上加入深度反而使平均从 61.25% 降到 58.75%，说明在固定模型容量与训练预算下各流存在重叠或竞争，最优菜单取决于任务的主要歧义（分割利于"目标与背景分离"，法线利于旋转薄平面部件）。
3. **外部对比大幅领先**：XGenAct 平均 **52%**，是最强基线（π0.5 与 VLANeXt 的 26%）的两倍；在 close drawer（100% vs ≤50%）、close microwave（60% vs 30%）、close laptop（40% vs 25%）上最好，且是唯一在每个任务上都超过 10% 的方法。
4. **失败模式不同**：PAD-Depth 与 UWM 多为超时（100 次试验中 88/86 次），VLA-JEPA 与 MolmoAct 常因 IK 失败停止（48/22 次）；XGenAct 从不耗尽 20 次 IK 失败预算，所有失败都是超时。
5. **直接生成几何/语义优于 RGB→专家级联**：深度 AbsRel 从 0.41–0.43 降至 0.28–0.33，分割 mIoU 约翻倍（0.22–0.24 → 0.42–0.49）；表面法线两路线基本持平（0.76–0.77 余弦），仅 RGB+D+N 下直接路线略差（0.71 vs 0.76）。
6. **感知流代价很小**：加入感知流后未来 RGB 的 LPIPS 仅从 0.39 升到 0.40–0.43。
7. **生成深度可直接当几何用**：反投影到 3D 后与真值点云在桌面、固定物、物体布局上重合，差异主要在机械臂（预测位姿超前或滞后于示范）；想象未来与实际执行高度一致（整帧 PSNR 21–24 dB）。
