## 摘要
在接触丰富的操作中，可靠的动作评估需要超越当前观测，考虑未来的视觉与接触后果。现有的噪声空间强化学习能高效引导冻结的视觉-语言-动作（VLA）策略，但其评论器在很大程度上忽略了这些后果。我们提出 Imagine-RL，它通过动作条件化的视觉-力矩想象来增强噪声空间 VLA 后训练。对于每个候选动作块，冻结的视觉-力矩潜世界模型（VTLWM）自回归地预测紧凑的未来表示，而无需像素重建。当前图像-状态-动作查询会关注已观测历史和预测未来，而前窗预测残差提供逐 token 的置信度先验，以抑制不可靠的未来 token。通过结合当前证据与预测后果，动作评论器能更好地评估候选动作并监督 actor，同时 VLA 与 VTLWM 保持冻结。在四个真实机器人任务中，每个任务进行 50 次评估试验，Imagine-RL 仅使用 100 条 RL 轨迹，将平均成功率较 DSRL 提升 (23.6%)，较 VLA 基线提升 (60%)。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

## 一、核心问题与研究动机

- **背景**：VLA（Vision-Language-Action）模型能将语言、图像与机器人状态映射为动作，具备跨任务、跨本体泛化能力，但其观测以视觉为主，在**接触丰富（contact-rich）操作**中难以感知阻力、打滑、卡死等接触现象。
- **现有力/力矩感知 VLA 的局限**：ForceVLA、TA-VLA 等通过多模态融合或辅助预测引入力矩，但**仅用于动作生成**，并未用于**价值估计**。
- **RL 后训练的困境**：
  - 真实机器人交互成本高，样本效率要求极高；
  - 传统 critic 只依据**当前观测 + 候选动作**打分，当两个视觉上相似的动作可能分别导致成功与失败时，评估不可靠；
  - 在**潜噪声（latent-noise）VLA-RL** 中（如 DSRL），动作 critic 还要蒸馏出噪声 critic 并监督 actor，因此"后果感知的动作排序"尤为关键。
- **世界模型的机会与空白**：世界模型可提供前瞻性证据（视觉未来、价值估计、虚拟交互），如 LeWorldModel 能在不做像素重建的前提下预测紧凑物理表征；但**力/力矩条件化的想象用于 critic 学习仍未被充分探索**。
- **论文核心命题**：为冻结 VLA 的潜噪声 RL 后训练引入**动作条件化的视觉–力矩想象**，让 critic 同时依据"当前证据"与"预测后果"评分，从而在极少真实交互下提升接触丰富任务成功率。

## 二、方法论

### 2.1 整体框架（Imagine-RL）

- 三个模块协同：**冻结的流匹配 VLA（π₀）** + **冻结的视觉–力矩潜世界模型（VTLWM）** + **轻量噪声 actor/双 critic**。
- 部署侧保持轻量：RL 期间**只训练噪声 actor 与 critic**，VLA 主干与 VTLWM 均不微调，也**不做像素级规划**。
- 双 critic 结构：
  - **动作 critic** \(Q_a(o,\bar a;h_{\bar a})\)：评估解码后的机器人动作块，输入包含世界模型生成的历史/未来视觉–力矩特征；
  - **噪声 critic** \(Q_w(o,w)\)：由 \(Q_a(o,\pi_0(o,w))\) **蒸馏**得到，使部署策略仍可只依赖潜噪声空间。

### 2.2 潜噪声 VLA-RL

- 冻结 VLA 映射：\(\bar a_t=\pi_0(o_t,w_t)\)，输出长度为 \(H_a\) 的动作块。
- 学习轻量潜噪声 actor：\(w_t\sim\pi_\theta(w\mid o_t)\)，间接"操控"冻结 VLA。
- 回放缓冲区**每次 VLA 查询存一条 transition**，使用**块级奖励 \(r_t\) 与折扣 \(\gamma^{H_q}\)**（\(H_q\) 为实际执行步数）。
- 采用多个 Q 网络取均值作为 Bellman 目标以抑制偏差：
  \(y_t=r_t+\gamma^{H_q}\frac1n\sum_{i=1}^n \bar Q_{a,i}(o_{t+1},\bar a'_{t+1};h^{a'}_{t+1})\)。
- 噪声 critic 通过采样潜噪声 \(\tilde w\) 并查询冻结 VLA 得到 \(\tilde a\) 来蒸馏动作 critic：
  \(\min_{Q_w}\mathbb{E}[(Q_w(o_t,\tilde w_t)-Q_a(o_t,\tilde a_t;h^{\tilde a_t}_t))^2]\)。
- 噪声 actor 以最大化 \(Q_w(o,\pi_\theta(o))\) 更新，实现中使用熵正则（SAC 体系）。

### 2.3 视觉–力矩潜世界模型（VTLWM）

- **JEPA 风格、无像素重建**：共享编码器将多视角图像融合为 \(z_t\)；力矩归一化为 \(\hat\tau_t\)，动作经编码为 \(E_a(a_t)\)；状态定义为 \(x_t=[z_t,\hat\tau_t]\)。
- **因果预测器**：历史长度 \(H=15\)，用前 \(H\) 个状态–动作对预测 \(H+1\) 个状态；推理时把最终预测追加进上下文并整体滑动一步，形成**自回归未来序列**（外推 \(H_f=10\) 个有效未来步）。
- **训练损失**：视觉预测 MSE + 力矩预测 SmoothL1（权重 \(\lambda_\tau\)）+ SIGReg 正则项（权重 \(\lambda_{sig}\)）。
- **RL 阶段完全冻结**，仅作为 critic 的特征生成器。

### 2.4 残差置信度引导的交叉注意力 Critic

- **Token 构造**：对每个模态 \(m\in\{z,\tau\}\)，特征构建器返回
  - 当前历史 \(X^{m,hist}_t\)；
  - 以被评估动作为条件的未来预测 \(X^{m,fut}_t(a_t)\)；
  - 前一窗口的预测 \(P^{m,prev}_t\)；
  - **残差** \(R^m_{t,j}=X^{m,hist}_{t,j}-P^{m,prev}_{t,j}\)（同一时间戳上"已观测"与"早先预测"之差，反映世界模型生成的稳定可靠性）。
- **Query**：由当前观测与候选动作 \(\zeta_t=(o_t,a_t)\) 经学习映射得到 256 维查询 \(q_t\)；历史与未来特征加位置/动作嵌入后作为 key/value token（视觉维度 192、力矩维度 14）。
- **可靠性置信度**：定义相对误差
  \(\rho^m_{t,j}=\dfrac{E_m(R^m_{t,j})^{1/2}}{\tfrac12[E_m(X^{m,hist}_{t,j})+E_m(P^{m,prev}_{t,j})]+\epsilon}\)，
  置信度 \(\alpha^m_{t,j}=\max(\alpha_{\min},e^{-\beta\rho^m_{t,j}})\)；其中 \(\epsilon=10^{-6}\)、\(\beta=1\)、\(\alpha_{\min}=0.05\)；不可用的残差取 \(\alpha_{\min}\) 与 \(\rho=4\)。
- **注意力偏置**：多头（4 头、每头 64 维）softmax 打分中加入加性偏置 \(B^m_t\)：有效历史为 0，有效未来步为 \(\log\alpha^m_{t,j}\)，无效槽位为 \(-\infty\)。即**用 \(\log\alpha\) 把未来 token 的权重按可靠度折扣**，把"相关性"与"可信度"结合；全无效序列产生零上下文。
- **价值融合**：拼接视觉/力矩上下文与四个可靠性统计量（有效未来槽上置信度的均值、最小、最大及平均相对误差，无有效槽时为 0），得到
  \(h_{a_t}=[c^z_t,c^\tau_t,g^z_t,g^\tau_t]\)，最终 \(Q_a(o_t,a_t;h_{a_t})=Q([\zeta_t,h_{a_t}])\)，由 MLP critic 输出 Q 值。

### 2.5 算法流程（Algorithm 1，基于 SAC）

1. 从回放缓冲区采样 \((o_t,w_t,\bar a_t,r_t,o_{t+1})\)；
2. **动作 critic 更新**：采样下一噪声并解码 \(\bar a'_{t+1}\)，构造动作对齐特征，最小化 TD 误差；
3. **噪声 critic 更新**：采样 \(\tilde w\sim\mathcal N(0,I)\)，解码 \(\tilde a\)，以动作 critic（停止梯度）为蒸馏目标；
4. **噪声 actor 更新**：最大化 \(Q_w(o,\pi_\theta(o))\)；
5. 每采集 \(N\) 条新轨迹触发一次更新循环。

- **Benchmark / 对比方法**：
  - **π₀**：预训练视觉 VLA，无任务级 RL；
  - **TA-VLA**：引入力物理反馈/
