## 摘要
高混合环境中的机器人装配需要能够处理多样零件的适应性系统，然而当前方法通常依赖于针对每个插入任务专门化的策略。尽管这可以达到很高的成功率，但也使针对新问题部署系统的过程变得繁琐且耗时。我们提出了一种使用世界模型实现可泛化插入的框架，该模型将机器人本体感受信息与腕部安装相机采集的原始视觉观测相结合。我们的基于模型的方法在多达90个具有几何多样性零件的插入任务上训练单个世界模型，在未见过的、几何未知的物体上实现了56%的零样本成功率，而仅使用无模型基线时为7%。重要的是，随着训练数据集中包含更多物体，性能会提升，展现出很强的可扩展性。最后，在留出物体上微调该通用模型与从头训练相比显著提高了数据效率，并在某些情况下实现了更好的渐近性能。据我们所知，这是首个能够以完全数据驱动的方式装配未见物体的系统，因此朝着可扩展、可泛化的机器人装配系统迈出了重要一步。

## Abstract
Robotic assembly in high-mixture settings requires adaptable systems that can handle diverse parts, yet current approaches typically rely on policies specialized to each insertion task. Although this can reach high success rates, it makes the process of deploying systems for new problems tedious and time consuming. We present a framework for generalizable insertion using world models that combine robot proprioceptive information with raw visual observations captured by a wrist-mounted camera. Our model-based approach trains a single world model on up to 90 insertion tasks with geometrically diverse parts, achieving 56% zero-shot success on unseen objects with unknown geometry compared to just 7% with a model-free baseline. Importantly, performance improves as more objects are included in the training dataset, demonstrating strong scalability. Lastly, finetuning the generalist model on held-out objects significantly enhances data-efficiency compared to training from scratch and, in some cases, achieves better asymptotic performance. To our knowledge, this is the first system capable of assembling unseen objects in an entirely data-driven manner, and thus represents a significant step toward scalable, generalizable robotic assembly systems.

## 1. 核心问题与整体含义

- **研究背景**：高混合（high-mixture）制造场景下的机器人装配需要系统能够处理几何形状各异的零件。工业界现有方案多为手工设计的专用控制器，难以跨物体几何与场景配置泛化；学术界的现有学习型系统则主要采用**专用策略（specialist policy）**，即每个物体对（插入任务）单独训练一个策略。
- **核心痛点**：专用策略虽能达到较高成功率，但每次面对新装配任务都需要重新训练和调参，部署过程繁琐、耗时，从根本上限制了系统的可扩展性与适应性。
- **关键问题**：作者提出一个更本质的追问——与单纯增加数据和算力相比，**改变学习算法范式**（从无模型 RL 转向基于模型的世界模型）是否能够更有效地构建通用装配策略？
- **整体含义**：论文提出 **InsertionWM**，一个基于视觉世界模型的学习框架，能够在**完全未知几何形状的未见物体**上实现零样本插入。作者强调，本工作的核心贡献不在于提出全新算法，而在于**证明视觉基于模型的 RL 在工业装配领域具有巨大未开发潜力**，能够训练出比以往工作更广泛、性能更强的通用多任务策略。

## 2. 方法论

### 2.1 核心思想

- 摒弃传统无模型 RL（如 PPO）用于装配控制的路线，转而采用**基于模型（model-based）的 RL**，具体基于 **TD-MPC2** 算法。
- 直觉依据：预测性世界模型可以从每个 transition 中产生**稠密的自监督信号**（将表征学习与稀疏奖励解耦），并支持决策时的**规划（planning）**；当单一高容量视觉编码器需在大量任务间共享时，这比无模型策略梯度更样本高效，且更不易发生任务干扰。
- 目标：训练一个**单一世界模型**，输入机器人本体感知信息 + 腕部相机原始深度观测，输出 6 DoF 末端执行器增量位姿命令，无需任何物体特定先验（如 CAD 模型、物体 ID）。

### 2.2 问题建模

- 将机器人插入建模为 **POMDP**：$(S, A, T, R, \gamma)$。
  - 动作 $a$：6 DoF 增量末端位姿，归一化到 $[-1,1]$。
  - 由于真实状态 $s$ 难以直接获取，用原始深度观测 $x \in \mathbb{R}^{96\times96}$ 与本体感知 $q \in \mathbb{R}^{24}$ 近似状态，即 $s \approx [x, q]$。
- 目标：最大化折扣累计回报 $\mathbb{E}_\pi[\sum_{t=0}^{\infty} \gamma^t r_t]$。

### 2.3 世界模型架构（TD-MPC2）

世界模型由 5 个组件构成，全部端到端从数据学习：

| 组件 | 符号 | 作用 |
|---|---|---|
| Encoder | $z = h(s)$ | 产生隐状态 |
| Dynamics | $z' = d(z, a)$ | 预测下一隐状态 |
| Reward | $\hat{r} = R(z)$ | 预测奖励 |
| Terminal value | $\hat{q} = Q(z, a)$ | 预测未来回报 |
| Policy prior | $\hat{a} \sim p(z)$ | 预测动作先验 |

- **规划**：推理时采用 **MPPI**（Model Predictive Path Integral）配合学习到的策略先验，在隐空间中进行基于采样的轨迹优化（local trajectory optimization）。

### 2.4 训练目标

- 联合优化目标：
$$\mathcal{L}(\theta) = \mathbb{E}_{(s,a,r,s')_{0:H}\sim\mathcal{B}}\left[\sum_{t=0}^{H}\lambda^t \mathcal{L}(\theta;t)\right]$$
其中 $\lambda$ 使近期预测权重更高，$H$ 为固定序列长度（horizon）。
- 单步损失由三部分组成：
  - **奖励预测**：$\text{CE}(\hat{r}_t, r_t)$（two-hot 离散化 + 交叉熵）
  - **价值预测**：$\text{CE}(\hat{q}_t, q_t)$
  - **联合嵌入预测**：$\|z'_t - \text{sg}(h(s'_t))\|_2^2$，其中 sg 为 stop-grad 算子，防止梯度回传至目标隐状态。
- 策略先验的训练目标：最大化熵与每步终端价值 $Q(z,a)$。
- 特点：**不解码原始观测**，直接在隐空间学习。

### 2.5 多模态编码器设计

编码器 $h$ 由三个模块组成：
$$h(x,q) = h_{\text{fuse}}(h_{\text{depth}}(x) + h_{\text{prop}}(q))$$
- $h_{\text{depth}}$：浅层 ConvNet，处理深度观测；
- $h_{\text{prop}}$：2 层 MLP，处理本体感知；
- $h_{\text{fuse}}$：2 层 MLP，融合两者为单一隐状态 $z$；
- 三者均对输出应用 **SimNorm** 归一化。
- 视觉输入的必要性：以往专用策略仅靠本体感知即可完成单一插入，但要让**单一策略操纵多种物体（含未见物体）**，必须依赖视觉反馈来推断物体几何。

### 2.6 零样本泛化策略

- 多任务训练时，对 90 个装配体各维护一个并行环境实例，保证装配体分布均匀，并对场景配置大幅随机化。
- **刻意不使用物体 ID 的 one-hot 编码**：虽然它可能提升已知物体性能，但无法零样本迁移到新物体；因此完全依赖视觉信息进行物体消歧。

## 3. 实验设计

### 3.1 数据集与场景

- **数据集**：基于 AutoMate [1] 提出的装配资产数据集，共 **100 个几何多样的双零件装配体**（plug 插入 socket），源自 [4][5] 的工作。装配体沿至少一个轴存在不对称性，插入策略因物体而异。
- **训练/测试划分**：按 ID 保留最后 10 个装配体作为固定留出测试集（同分布但训练中未出现），其余 90 个用于训练通用模型；训练子集按 ID 升序选取，以避免人工选择偏差。
- **仿真环境**：基于 AutoMate 的环境，Franka Panda 机械臂 + 平行夹爪，腕部相机模拟 Intel RealSense D435 RGB-D；使用 Isaac 进行 GPU 加速并行仿真。
- **观测空间**：腕部相机原始深度 $x\in\mathbb{R}^{96\times96}$ + 本体感知 $q\in\mathbb{R}^{24}$（7 个关节角 + 带白噪声的 6D 末端与 socket 位姿 + 目标位置）。
- **奖励函数**：$R = r_{\text{penetration}}(r_{\text{dist}} + r_{\text{imitation}} + r_{\text{success}})$，沿用 [6][1] 的奖励函数未作修改。
- **训练课程**：采用简单课程学习，根据当前成功率调整初始状态分布，且对每个装配体单独调整。

### 3.2 Benchmark 与对比方法

- **主要对比基线**：**AutoMate** [1]，当前基于 RL 的机器人插入 SOTA，使用 PPO 训练专用策略，并以点云嵌入训练通用策略（依赖 CAD 模型）。
- **框架变体对比**：
  1. 无视觉输入的"盲"世界模型（仅本体感知）；
  2. 腕部相机替代放置位置的世界模型；
  3. 有无课程学习的对比（默认课程 vs 逆课程 vs 无课程）；
  4. 使用每装配体 100 条专家轨迹的通用模型（特权基线）。

### 3.3 评估设置

- 通用模型成功率：在训练集（域内）和测试集（未见）上分别平均，每个装配体 **100 次试验**。
- 专用策略：每个装配体独立训练，报告 **5 个随机种子** × 每种子 100 次试验的均值。

### 5.1 实验规模概览

## 6. 主要结论与发现

1. **专用策略性能超越 SOTA**：InsertionWM 在 100 个装配体上平均成功率 **79.78%**，超过 AutoMate 的 **70.31%**；在小型、薄型 socket 上优势尤为明显，但在大型 socket 上因视觉遮挡而表现较差（如物体 296、726）。

2. **通用策略缩放性显著优于前作**：
   - 在 90 个已见装配体上达到 **55.0%** 成功率，而 AutoMate 在 80 个已见装配体上仅 **15.6%**；
   - 零样本泛化性能随训练装配体数量增加而提升，训练 90 个时对未见物体达到最高 **56%** 零样本成功率；
   - 在该规模下，域外性能已接近域内性能，作者推测未来会在此水平附近饱和。

3. **微调显著提升数据效率**：从 90 物体通用模型微调到留出装配体，相比从头训练大幅提高数据效率，在部分物体（1036、1041）上甚至**超过专用策略的渐近性能**。

4. **视觉至关重要**：无视觉的"盲"模型性能大幅下降（专用 55.2% vs 79.8%，通用 39.6% vs 54.5%），相机位置也对性能有显著影响。

5. **课程学习一致有益**：默认课程与逆课程均优于无课程，具体课程形式相对次要；使用专家演示仅有边际提升，且因依赖预训练专家而扩展性差，故未被采纳为默认方案。

## 7. 优点

- **范式创新**：首次将基于模型的世界模型 RL 成功应用于机器人装配领域，证明其相对无模型方法的样本效率和泛化优势。
- **完全数据驱动的零样本泛化**：无需 CAD 模型、物体 ID 或位姿估计等特权信息，部署管线比 AutoMate 大幅简化（AutoMate 部署时仍需逐物体 CAD 与点云嵌入）。
- **强缩放行为**：性能随训练物体数量单调提升，展现出向更大装配数据集扩展的潜力。
- **数据高效**：专用策略仅需 2M 步 vs AutoMate 的 50M 步；通用模型仅需 3 天训练。
- **实验严谨**：固定 ID 划分、多随机种子、每装配体 100 次试验、95% 置信区间、官方代码复现基线、系统消融研究。
- **诚实的自我评估**：明确指出失败案例（大 socket 遮挡）与性能下降的装配体，并分析原因。

## 8. 不足与局限

- **视觉遮挡敏感**：当 plug 较大、部分遮挡 socket 时系统容易失败，这是当前方法的主要失效模式。
- **域内性能轻微下降**：随着训练物体数量增加，域内性能出现轻微下滑，提示多任务学习可能存在任务干扰或容量瓶颈。
- **仅限仿真验证**：所有实验在 Isaac 仿真中完成，未部署到真实硬件。作者指出视觉基于模型方法面临额外 sim-to-real 挑战：
  - 商用深度相机噪声大，小零件边缘模糊；
  - 接触难以高保真仿真；
  - 实时视觉处理的计算需求。
- **数据集规模受限**：装配数据集构建需大量人工，目前仅 100 个物体对，限制了通用模型的进一步扩展。
- **对比公平性的细微不确定性**：AutoMate 通用策略的确切训练/测试划分未知，虽作者论证设置可比，但严格意义上并非完全受控对比。
- **未披露硬件并行规模**：仅给出单卡型号与训练时长，未说明 GPU 数量与并行环境的具体硬件配置，影响复现性评估。
- **未来方向**：

将方法部署到真实硬件，并系统研究视觉世界模型在真实装配场景中的 sim-to-real 迁移，具体挑战包括商用深度相机噪声、接触-rich 任务的动力学建模以及实时规划的计算效率。此外，扩大装配资产数据集的规模与多样性、开发更鲁棒的视觉编码器以应对遮挡、以及探索多任务学习中的容量分配与干扰缓解策略，都是值得深入的方向。
