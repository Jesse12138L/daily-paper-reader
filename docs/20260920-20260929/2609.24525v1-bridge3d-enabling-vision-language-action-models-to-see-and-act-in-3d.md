## 摘要
视觉-语言-动作（VLA）模型通过大规模多模态预训练，在机器人操作中展现出卓越的泛化能力。然而，VLA模型主要基于以2D为中心的观测进行训练，这本质上限制了其进行精确空间操作的能力。先前方法通过引入隐式空间先验来增强3D感知，但仍缺乏显式的几何引导。本文提出Bridge3D，将隐式和显式3D几何引导同时集成到预训练的2D VLA模型中，使其能够在3D中“看见”和“行动”。Bridge3D引入两种策略：1）隐式融合（Implicit Fusion），利用3D基础模型的特征丰富视觉token，以提升3D“看见”能力；2）显式条件化（Explicit Conditioning），将动作去噪与显式3D语义场相结合，以实现3D“行动”。此外，我们利用提出的逐层线性探测（layer-wise linear probing）来提高学习效率。实验表明，Bridge3D相较于当前最先进方法取得了更优性能。在RoboTwin 2.0基准上，Bridge3D超过$π_0$ 14.0个百分点，而在真实世界实验中，其超过Spatial Forcing 11.7个百分点。这些结果证明了Bridge3D在高精度和空间敏感操作任务中的强大能力。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable generalization in robotic manipulation via large-scale multimodal pretraining. However, VLA models are mainly trained on 2D-centric observations, which inherently constrains their capacity for precise spatial manipulation. Previous methods enhance 3D awareness by introducing implicit spatial priors, but still lack explicit geometry guidance. In this paper, we propose Bridge3D that integrates both implicit and explicit 3D geometry guidance into pre-trained 2D VLA models, enabling them to ''see'' and ''act'' in 3D. Bridge3D introduces two strategies: 1) Implicit Fusion, which enriches visual tokens with features from 3D foundation models to improve ''seeing'' in 3D; 2) Explicit Conditioning, which integrates action denoising with an explicit 3D semantic field to achieve ''acting'' in 3D. Furthermore, we utilize the proposed layer-wise linear probing to improve learning efficiency. Experiments show that Bridge3D achieves superior performance against state-of-the-art methods. On the RoboTwin 2.0 benchmark, Bridge3D exceeds $π_0$ by 14.0 percentage points, while in real-world experiments, it outperforms Spatial Forcing by 11.7 percentage points. These results demonstrate Bridge3D's strong capabilities in high-precision and spatial-sensitive manipulation tasks.

## 2. 方法论
- **总体思想**：提出层级式 3D 增强框架 Bridge3D，包含两个协同策略：
  - **Implicit Fusion**：增强视觉 token 的 3D 感知。
  - **Explicit Conditioning**：将动作去噪与显式 3D 语义场结合，指导精确动作生成。
  - 使用 **逐层线性探测** 选择性插入显式条件模块，提高学习效率。

- **Implicit Fusion 隐式融合**：
  - **双流 token 编码**：
    - 语义流：预训练 VLM 编码器 \(\Phi_{VLM}\) 处理多视角 RGB，得到语义 token \(z^{VLM}_v \in \mathbb{R}^{L \times C}\)。
    - 几何流：使用 VGGT 等 3D 基础模型 \(\Phi_{3D}\) 提取几何 token \(z^{3D}_v \in \mathbb{R}^{L \times D}\)，并与语义 token 做 patch 级对齐。
  - **Token-wise 残差融合**：
    - 用两层 MLP 残差适配器 \(\Gamma: \mathbb{R}^D \rightarrow \mathbb{R}^C\) 将几何特征映射到 VLM 视觉特征空间。
    - 融合方式为 \(z^{fuse}_v = z^{VLM}_v + \Gamma(z^{3D}_v)\)，保留预训练表示空间，同时加入几何线索。
  - 论文比较了 Concat Fusion、Cross-Attention Fusion 和 Residual Addition，发现 **Residual Addition 效果最好且计算高效**。

- **Explicit Conditioning 显式条件化**：
  - **3D 语义场构建**：
    - 从机器人头部 RGB-D 观测出发，用 Grounded-SAM 生成实例掩码，只保留机器人与被操作物体。
    - 用 DINOv3 提取密集语义特征，并按照 D3Fields 思路将 2D 特征提升到 3D。
    - 场景表示为 \(F=\{(p_i, f_i)\}_{i=1}^N\)，其中 \(p_i\) 是空间点，\(f_i\) 是对应语义特征。
    - 为效率下采样：操作相关点 \(N_m=1536\)，背景点 \(N_e=256\)。
  - **3D 条件动作生成**：
    - 动作隐藏状态 \(f_{act}\) 与 VLM 特征融合；双臂操作时分成左右两流，用末端执行器嵌入 \(e_{arm}\) 做 FiLM 调制：
      \[
      \hat f_{act} = \gamma(e_{arm}) \odot f_{act} + \beta(e_{arm})
      \]
    - 对 query 和 key 使用 3D RoPE：
      \[
      Q = \text{RoPE}_{3D}(\hat f_{act}, P_{ee}),\quad
      K = \text{RoPE}_{3D}(F_{pts}, P),\quad
      V = F_{pts}
      \]
    - 通过 spatial cross-attention：
      \[
      \text{CrossAttn}(\hat f_{act}, F)=\text{Softmax}\left(\frac{QK^\top}{\sqrt d}\right)V
      \]
    - 动作隐藏状态在共享坐标框架下查询 3D 场点，使动作生成受度量 3D 空间约束。
  - **逐层线性探测**：
    - 冻结 VLA backbone，在每层 DiT block 的隐藏状态上训练线性 ridge regression，预测机器人末端执行器 3D 坐标。
    - 发现初始层误差低，但 **#7–#11 层误差急剧上升**，说明深层几何感知退化。
    - 因此只在 **blocks #7–11** 插入 spatial cross-attention，避免冗余并防止破坏语义一致性。

  - 微调时冻结 VLM backbone，优化 residual adapter 与 action expert。
  - 使用 AdamW，学习率 \(1 \times 10^{-4}\)。
