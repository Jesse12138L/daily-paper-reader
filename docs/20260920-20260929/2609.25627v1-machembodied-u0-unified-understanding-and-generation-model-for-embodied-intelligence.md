## 摘要
通用机器人控制要求模型能够理解任务意图、识别交互位置、捕捉场景如何演化，并生成精确动作。视觉-语言-动作模型提供了强大的语义先验，但通常不显式建模场景动态；而世界-动作模型将视觉预测与控制耦合，却未必能揭示细粒度操作所需的任务相关语义和空间结构。我们提出 MachEmbodied-U0（ME-U0），一种统一的具身基础模型，通过混合Transformer架构连接理解与生成专家。子任务预测和可供性定位通过流匹配引导联合的视觉动态与动作生成。视觉动态涵盖未来RGB、深度、表面法线和光流，为外观、几何和运动提供互补监督。多速率旋转位置编码（MRPE）将视觉动态与细粒度控制对齐。我们在约4200小时来自机器人数据集和第一人称视角数据集的精选演示上预训练 ME-U0。仅使用每个下游基准中原生可用的监督，ME-U0 在 RoboDojo 仿真基准上取得 17.66 的平均分，并在 LIBERO 和 LIBERO-Plus 上分别取得 99.0% 和 82.5% 的平均成功率。我们还在真实世界机器人操作任务上验证了 ME-U0，证明其有效性超越仿真。在没有相应下游监督的情况下，ME-U0 进一步在仿真和真实世界观测中展示了零样本子任务预测、可供性定位和视觉动态。总体而言，ME-U0 将具有竞争力的下游控制性能与可迁移的任务定位和视觉动态能力相结合，涵盖仿真和真实世界。

## Abstract
General-purpose robot control requires models to understand task intent, identify where to interact, capture how the scene evolves, and generate precise actions. Vision-language-action models provide strong semantic priors but typically do not explicitly model scene dynamics, while world-action models couple visual prediction with control without necessarily exposing the task-relevant semantic and spatial structure needed for fine-grained manipulation. We present MachEmbodied-U0 (ME-U0), a unified embodied foundation model connecting understanding and generation experts through a Mixture-of-Transformers architecture. Subtask prediction and affordance grounding guide joint visual-dynamics and action generation via flow matching. Visual dynamics encompass future RGB, depth, surface normals, and optical flow, providing complementary supervision for appearance, geometry, and motion. Multi-rate Rotary Position Encoding (MRPE) aligns visual dynamics with fine-grained control. We pretrain ME-U0 on approximately 4,200 hours of curated demonstrations from robotic datasets and egocentric datasets. Using only the supervision natively available in each downstream benchmark, ME-U0 achieves an average score of 17.66 on the RoboDojo simulation benchmark and average success rates of 99.0\% and 82.5\% on LIBERO and LIBERO-Plus, respectively. - **整体含义**：论文主张一种**以操作为中心的统一范式**——把子任务分解、可供性定位、几何/运动感知的视觉动态与动作生成组织在同一条通路中，使高层意图、局部交互几何与可执行控制直接相连。

## 2. 方法论

### 2.1 核心思想
- 采用 **Mixture-of-Transformers（MoT）** 架构，连接**理解专家**与**生成专家**：
  - 专家各自拥有专用参数，以适配语义理解与连续生成的不同需求；
  - 通过**共享多模态注意力**实现协调，使语义上下文注入控制过程。
- 模型从 Lance 初始化，再训练获得机器人专用能力。
- 三条互补设计：显式子任务推理与可供性定位；联合多模态视觉动态与动作生成；动作-子任务时间对齐。

### 2.2 理解专家
- 将子任务与可供性预测建模为**自回归文本生成**，以 next-token 交叉熵训练：
  - **子任务预测**：给定总指令与当前观测，描述当前局部操作目标，连接整体任务与当前阶段。
  - **可供性预测**：问答形式，识别任务相关目标、输出边界框，并预测预期交互与交互点；当两类标注同时可用时，可供性紧随子任务出现在同一助手回复中。
- 语义视觉 token 与任务指令共同进入共享多模态序列。
- 损失：$L_{und} = -\frac{1}{T}\sum_{t=1}^{T}\log p_\theta(y_t \mid y_{<t}, x)$，仅在受监督的回复 token 上计算。

### 2.3 生成专家
- 在共享序列中，文本 token 位于当前观测与机器人状态 token 之后，并先于未来视觉与动作 token；因果注意力阻止文本 token 关注未来目标。
- **视觉动态生成**：按提示模态生成 RGB、深度、表面法线或光流；几何与运动统一表示为三通道视觉目标，全部共享同一 video VAE 隐空间与生成主干，无模态专用预测头。
- **动作生成**：每个时间步一个 token；每个去噪步中噪声动作 token 与视觉 token 经双向自注意力共同处理，动作专用输出头预测速度场，用显式欧拉步更新；与视觉生成同步进行。
- **Flow Matching 训练**：
  - 以共享流时间 $\tau$ 对干净视觉目标 $z$ 与动作轨迹 $a$ 加独立高斯噪声：$z_\tau=(1-\tau)z+\tau\epsilon_z$，$a_\tau=(1-\tau)a+\tau\epsilon_a$；
  - 采样 $\tau=\text{sigmoid}(u+\log 4),\ u\sim N(0,1)$，即偏移 logit-normal 分布，偏向高噪声水平；
  - 分别预测速度场 $(\hat{u}_z,\hat{u}_a)=v_\theta(z_\tau,a_\tau,\tau;c)$；
  - 联合目标：$L_{gen}=\mathbb{E}[\lambda_z\|\hat{u}_z-(\epsilon_z-z)\|^2_{M_z}+\lambda_a\|\hat{u}_a-(\epsilon_a-a)\|^2_{M_a}]$，掩码 $M$ 只在有效元素上计算 MSE。
- **坚持联合去噪**的理由：另设独立动作去噪器会削弱"理解—视觉预测—控制"的架构统一性；联合去噪让动作与视觉预测在去噪全程交互。
- 架构还支持三种模式（通过变换条件与目标）：前向动力学 $(c,a)\to z$、逆向动力学 $(c,z)\to a$、联合策略预测 $c\to(z,a)$。
- 总目标：$L_{total}=L_{gen}+\lambda_{und}L_{und}$。

### 2.4 Multi-rate Rotary Position Encoding (MRPE)
- 基于 mRoPE，编码文本位置与视觉时空坐标。
- 问题：视频在时间上被下采样，而动作保持原始采样率，若共享同一位置索引，chunk 内动作顺序将无法区分。
- 方案：保留与该视频 latent 帧相同的**时间位置**，但按动作在 chunk 内的顺序为其分配**不同的 height 轴索引**，width 轴索引固定；从而在保持动作-视频时间对齐的同时显式编码 chunk 内动作位置。

### 2.5 统一多模态提示

- 字段包括：控制模式（关节/EEF）、动作语义（相对/绝对、夹爪编码）、子任务查询、可供性查询、视频模态（rgb/depth/normal/flow）。
