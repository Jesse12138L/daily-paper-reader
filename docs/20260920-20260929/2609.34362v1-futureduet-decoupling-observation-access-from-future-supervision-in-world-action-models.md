## 摘要
世界动作模型（WAM）通过未来视觉监督增强机器人动作生成。现有 WAM 通常将主视角与手腕视角观测融合为单一视觉流，并用相同的未来视频目标训练二者，尽管它们的视觉动态不同。稳定的主相机揭示场景级任务演化，而手腕相机随末端执行器移动，将局部交互变化与视角偏移及自遮挡混合在一起。这些对比鲜明的预测需求表明，两种视角可能受益于不同的未来目标。我们提出 FutureDuet，它在控制中保留两种视角，同时允许每个视觉流接受不同的未来目标。对于主视角，未来 RGB 建模任务演化，而交互掩码和机器人骨架将监督聚焦于任务物体和机器人运动。对于手腕流，未来潜在预测建模短时程交互变化，而无需像素级重建。ActionDiT 联合读取由此得到的任务状态与交互状态，将场景级进展与近距离交互证据相结合。所有辅助预测模块仅用于训练，不增加推理开销。FutureDuet 在 RoboTwin50 上实现了 94.2% 的清洁场景成功率和 94.1% 的随机化成功率，在 LIBERO 上平均成功率为 99.2%。这些改进在六个需要精确交互的 RoboTwin50 任务上最为显著，在清洁和随机化设置下相比 Fast-WAM 平均分别提升 9.2% 和 12.8%。受控研究进一步表明，分离手腕路径并为两种视角分别设计未来监督可带来互补增益。

## Abstract
World Action Models (WAMs) augment robot action generation with future visual supervision. Existing WAMs commonly fuse main and wrist observations into one visual stream and train both with the same future-video objective, despite their different visual dynamics. A stable main camera reveals scene-level task evolution, whereas wrist cameras move with the end effector, mixing local interaction changes with viewpoint shifts and self-occlusion. These contrasting predictive demands suggest that the two views may benefit from different future objectives. We introduce FutureDuet, which retains both views for control, while allowing each visual stream to receive a different future objective. For the main view, future RGB models task evolution, while interaction masks and robot skeletons focus supervision on task objects and robot motion. For the wrist stream, future latent prediction models short-horizon interaction changes without requiring pixel-level reconstruction. ActionDiT jointly reads the resulting Task State and Interaction State, combining scene-level progress with close-range interaction evidence. All auxiliary prediction modules are training-only, adding no inference overhead. FutureDuet achieves 94.2% clean and 94.1% randomized success on RoboTwin50 and 99.2% average success on LIBERO. The improvements are most pronounced on six RoboTwin50 tasks that require precise interaction, averaging gains of 9.2% and 12.8% over Fast-WAM in clean and randomized settings. Controlled studies further show complementary gains from separating the wrist pathway and designing future supervision separately for the two views.

## 1. 核心问题与整体含义
- **研究背景**：世界动作模型（World Action Models, WAMs）在机器人动作生成中引入未来视觉监督，利用预测的场景演化改善策略学习。Fast-WAM 已表明，即使部署时不生成未来观测，未来预测作为训练信号仍有效。
- **核心问题**：现有 WAM 常将主视角与腕部视角观测融合为单一视觉流，并用统一的未来视频目标训练。但两类视角的视觉动态和预测需求不同：
  - 主相机相对稳定，反映场景级任务演化、物体关系和机器人运动；
  - 腕部相机随末端执行器运动，混合局部交互变化、视角快速偏移和自遮挡。
- **整体含义**：论文主张将“哪些观测可用于控制”与“每个视觉流应预测什么未来”解耦。两种视角可以共同支持动作生成，但不必被迫预测同一种未来目标。辅助未来预测模块仅训练时使用，不增加推理开销。

## 2. 方法论
- **核心思想**：FutureDuet 保留主视角和腕部视角用于控制，但为二者设计不同的未来监督目标：
  - 主视角学习 **Task State**，建模场景级任务演进；
  - 腕部流学习 **Interaction State**，建模短时程近距离交互变化；
  - 二者经 Duet Interface 融合后由 ActionDiT 联合读取并生成动作。
- **整体流程**：
  - 输入：语言指令 \(c\)、本体感知 \(p_t\)、主视角历史 \(o^m_{\le t}\)、腕部历史 \(o^w_{\le t}\)；
  - 输出：动作块 \(a_{t:t+H-1}\)；
  - VideoDiT 提取主视角特征 \(H^m_t\)；轻量在线编码器提取腕部特征 \(H^w_t\)；
  - 通过 learned-query adapters 分别得到 Task State \(S^{task}_t\) 和 Interaction State \(S^{int}_t\)；
  - Duet Interface 将两者投影、融合为 \(C^{duet}_t\)；
  - ActionDiT 读取融合状态以及当前主视角 K/V 特征、指令和本体感知，通过 flow matching 生成动作。
- **主视角监督**：
  - 未来 RGB 预测：将未来帧编码为 VAE latent，VideoDiT 在噪声下预测其 flow velocity；
  - 交互掩码：用 SAM 3 离线生成被操作物体及目标区域掩码；
  - 机器人骨架：将记录的机器人构型投影到标定主视角；

  - 损失为有效 latent 元素上的平均绝对误差，排除 padding 位置。
- **训练目标**：
  - 动作生成和主视角 RGB 预测均使用 flow matching；

    L = L_{act} + \lambda_{rgb}L_{rgb} + \lambda_{mask}L_{mask} + \lambda_{ske}L_{ske} + \lambda_{wrist}L_{wrist}

  - 主视角未来损失训练 VideoDiT，腕部目标训练在线腕部编码器，动作损失通过 Duet Interface 更新两条流。

## 3. 实验设计
- **数据集与场景**：
  - **RoboTwin 2.0 / RoboTwin50**：50 个双臂操作任务，包含 clean 与 randomized 设置，作为主基准；
  - 每任务使用 50 个 clean 和 500 个 randomized 演示，共 27,500 个演示；
  - 训练数据、骨干、预处理、训练预算、检查点选择和评估均与 Fast-WAM 匹配；
  - **LIBERO**：四个十任务、语言条件的单臂操作套件，每任务 50 个演示，用于验证跨双臂以外的泛化。
- **对比方法**：
  - LIBERO：π0、GR00T-N1、π0.5、OpenVLA-OFT、Motus、Fast-WAM、MaskWAM、LingBot-VA；
  - RoboTwin50：π0、X-VLA、π0.5、UWM、Motus、X-WAM、Fast-WAM、LingBot-VA；
  - 部分基线数值来自原论文或基准报告，而非全部在同一环境下重训。
- **消融与控制实验**：
  - **腕部路径研究**：比较主视角仅、统一 RGB 路径、分离轻量路径无未来预测、分离路径 + 未来 RGB、分离路径 + 未来 latent、直接部署 V-JEPA；
  - 使用 3 个任务、3 个随机种子、每任务每种子 100 个 randomized 评估回合；
  - **主视角 factorial 研究**：交叉 4 种主视角目标配置（RGB、+Mask、+Skeleton、+Mask+Skeleton）与两种腕部路径（统一 future RGB、分离 future latent）；
