## 摘要
比较当前与过去的观测有助于机器人在操作过程中理解场景变化并选择后续动作。然而，当物体或相机移动时，在同一图像位置比较视觉特征可能会混入不同的场景内容。我们提出 CoRe-WAM，一种世界动作模型，通过参数高效的时序接口引入对应关系对齐的视觉变化。其 TraceDelta 模块使用来自冻结跟踪模型的对应关系，将历史视觉特征传输到当前位置，然后在共享的预训练特征空间中计算有符号差异。因此，对应关系决定了哪些历史内容与当前内容进行比较，而不是作为单独轨迹表示进入策略。一个轻量级适配器将这些差异转换为有效性门控残差，以补充当前视觉条件，使策略能够在利用当前场景信息的同时使用近期变化。CoRe-WAM 基于 Motus 构建，保持预训练骨干网络权重冻结，仅优化 159 万个参数。在 5,000 次更新的适应预算下，CoRe-WAM 在 50 个 RoboTwin 2.0 任务上达到 92.22% 的干净成功率，较 Motus 高 3.56 个百分点；在随机化评估中，达到 89.60% 的成功率，提升 2.58 个百分点。将 TraceDelta 集成到基于 StarVLA 的策略中，可将干净成功率从 58.10% 提升至 67.62%，支持该时序接口在 Motus 之外的迁移。

## Abstract
Comparing current and past observations helps robots understand scene changes and select subsequent actions during manipulation. However, comparing visual features at the same image location can mix different scene content when objects or the camera move. We introduce CoRe-WAM, a world-action model that incorporates correspondence-aligned visual changes through a parameter-efficient temporal interface. Its TraceDelta module uses correspondences from a frozen tracking model to transport historical visual features to current locations before computing signed differences in a shared pretrained feature space. Correspondence thus determines which historical content is compared with the present, rather than entering the policy as a separate trajectory representation. A lightweight adapter converts these differences into validity-gated residuals that supplement current visual conditioning, allowing the policy to use recent changes alongside current-scene information. Built on Motus, CoRe-WAM keeps the pretrained backbone weights frozen and optimizes 1.59 million parameters. With a 5,000-update adaptation budget, CoRe-WAM achieves 92.22% clean success across 50 RoboTwin 2.0 tasks, 3.56 percentage points above Motus; on randomized evaluation, it achieves 89.60% success, a 2.58-point gain. Integrating TraceDelta into a StarVLA-based policy improves clean success from 58.10% to 67.62%, supporting transfer of the temporal interface beyond Motus.

## 1. 核心问题与整体含义

- **研究动机**：机器人操作中，当前观测描述当前场景，历史观测揭示场景如何演化。将二者结合有助于工具使用、物体交接、铰接物体操作和多阶段放置等任务。
- **核心痛点**：直接比较同一图像位置上的预训练视觉特征，会在物体或相机运动时把“同一区域内容变化”和“不同内容占据该区域”混在一起。历史信息本身不等于有意义的时序比较，关键在于“与什么历史内容比较”。
- **整体含义**：论文提出 **CoRe-WAM**，核心原则是“先建立对应关系，再计算变化”。它不把轨迹坐标或轨迹编码特征作为额外策略 token，而是用对应关系作为历史特征的“搬运算子”，在共享预训练特征空间中计算有符号差异，再以轻量残差补充当前视觉条件。
- **定位**：面向世界动作模型/视觉-语言-动作模型，在 Motus 基础上构建，保持预训练骨干冻结，仅优化少量时序与动作侧参数。

## 2. 方法论：核心思想与关键技术

- **核心思想**：对应关系决定历史中“哪个内容”与当前区域比较；比较结果以有效性门控残差形式注入当前视觉 token，当前观测路径保持完整。
- **TraceDelta 三步骤**：
  1. **对齐历史**：用冻结的 Trace Anything 估计当前 token 中心 \(p_i\) 到历史时刻的后向对应 \(q_i = C_{t\to h}(p_i)\)，再用双线性采样从历史特征 \(F_h\) 得到对齐历史特征 \(\bar f_{h,i}=W(F_h,q_i)\)。
  2. **比较特征**：计算有符号差异 \(\Delta_i^{\text{trace}}=F_t(p_i)-\bar f_{h,i}\)。与 Raw Delta 的 \(\Delta_i^{\text{raw}}=F_t(p_i)-F_h(p_i)\) 不同，TraceDelta 比较的是对应内容，而非同一图像坐标。
  3. **注入变化**：轻量适配器 \(g_\psi\) 将差异映射到 Motus 理解维度，结构为 \(2048\to256\to512\)，含 LayerNorm、GELU 和线性层。残差写为 \(r_i=\alpha m_i g_\psi(\Delta_i^{\text{trace}})\)，其中 \(m_i\) 为对应有效性掩码，无效位置为 0。
- **注入位置**：残差只加到头相机 token 位置 \(\Omega\)，实现中为 60 个 token，按 \(6\times10\) 网格排列，对应打包视觉 token 序列索引 10–69。最终 \(U'_t=P(Z_t)+\text{Scatter}_\Omega(\{r_i\})\)，当前观测路径 \(P(Z_t)\) 不被替换。
- **训练与推理**：
  - 冻结 VLM、视觉编码器、专家权重和对应估计模型。
  - 优化时序适配器、动作侧 LoRA 和现有动作解码器，总计约 159 万参数，占策略约 0.02%。
  - 历史不可用时，时序分支直接旁路，策略退化为仅使用当前视觉条件。
  - 推理时冻结 Trace Anything 在线估计对应，仅使用当前和过去观测，保持因果性。
