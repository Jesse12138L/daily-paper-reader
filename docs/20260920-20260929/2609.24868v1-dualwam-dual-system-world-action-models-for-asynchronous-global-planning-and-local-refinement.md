## 摘要
世界动作模型（WAM）能够联合生成机器人动作并预测未来世界状态，从而将视频预训练中的先验迁移到机器人控制中。然而，未来视觉预测的计算开销很大，因此现有 WAM 往往依赖长动作块来将推理成本分摊到多个控制步骤上，代价是闭环响应能力下降。我们提出 DualWAM，一种双系统 WAM，通过解耦全局规划与局部细化，在保持更长时间跨度的世界-动作生成的同时，实现高频闭环动作更新。系统二周期性地在更长的世界-动作块上进行高噪声双向去噪，以建立全局规划；而仅使用腕部观测的系统一则从中间去噪状态中提取时间对齐的短窗口，并利用最新的腕部观测完成低噪声细化，这些观测提供了交互过程中与动作对齐的局部几何、运动和接触线索。两个系统沿共享的去噪轨迹异步运行：每个全局规划在多次局部更新中被复用，同时系统一反复纳入新的交互反馈。在 Franka 和 Galbot 上的零样本操作任务中，DualWAM 相比评估的最强基线平均将成功率提高 4.5 个百分点，同时实现 16.6 倍的关键路径加速。进一步研究表明，角色匹配的自我中心数据和 UMI 数据将成功率提高 14 个百分点，并且这种解耦设计天然支持边缘-云部署，其通信开销显著低于基线。

## Abstract
World Action Models (WAMs) jointly generate robot actions and predict future world states, transferring priors from video pretraining to robot control. However, future visual prediction is computationally expensive, so existing WAMs often rely on long action chunks to amortize inference cost across control steps, at the cost of closed-loop responsiveness. We present \method, a dual-system WAM that preserves broader-horizon world-action generation while enabling high-frequency closed-loop action updates by decoupling global planning and local refinement. \systwo periodically performs high-noise bidirectional denoising over a broader world-action chunk to establish a global plan, while wrist-only \sysone extracts a temporally aligned short window from the intermediate denoising state and completes low-noise refinement using the latest wrist observations, which provide action-aligned cues about local geometry, motion, and contact during interaction. The two systems operate asynchronously along a shared denoising trajectory: each global plan is reused across multiple local updates, while \sysone repeatedly incorporates fresh interaction feedback. Across zero-shot manipulation tasks on Franka and Galbot, \method improves success over the strongest evaluated baseline by 4.5 percentage points on average, while achieving a 16.6$\times$ critical-path speedup. Further studies show that role-matched egocentric and UMI data improve success by 14 percentage points, and that the decoupled design naturally supports edge--cloud deployment with substantially lower communication overhead than the baseline.

## 1. 核心问题与整体含义

- **研究背景**：世界动作模型（World Action Models, WAMs）将视频预训练中的语义与物理先验迁移到机器人控制，能够联合生成动作并预测未来世界状态，在零样本操作上展现出潜力。
- **核心矛盾**：未来视觉预测计算开销大。现有 WAM 常采用**长动作块**来摊薄推理成本，但动作块越长，模型更新越少，闭环响应越差；动作块越短，又需要频繁生成世界-动作预测，并容易退化为短视的局部预测。
- **已有缓解手段**：减少、压缩或异步解码未来预测，但大多没有在同一个世界-动作生成过程中，联合专门化**去噪阶段、视觉上下文、更新频率**。
- **论文含义**：DualWAM 将世界-动作生成解耦为两个互补角色——低频全局规划与高频局部细化，并让二者沿**共享去噪轨迹**异步运行。其目标是同时保留较长时程的世界-动作生成能力，并实现高频闭环动作更新。

## 2. 方法论

### 2.1 核心思想

- 将一条世界-动作去噪轨迹按噪声区间和语义角色切分：
  - **System 2（全局规划）**：处理高噪声区间，生成较长时间跨度的全局世界-动作状态。
  - **System 1（局部细化）**：处理低噪声区间，仅使用腕部观测，对时间对齐的短窗口进行高频细化。
- 两个系统不是独立模型简单级联，而是共享同一个 rectified-flow 噪声坐标，System 2 输出中间状态，System 1 从该状态继续去噪。

### 2.2 问题形式化

- 控制步 \(t\) 输入包括：语言指令 \(l\)、机器人本体状态 \(q_t\)、全局场景观测 \(o^g_t\)、腕部观测 \(o^w_t\)。
- 干净目标为：
  - \(X_0 = [Z^g_0, Z^w_0, A_0]\)，分别表示未来全局视频潜变量、腕部视频潜变量和动作序列。
  - 加噪状态：\(X_\sigma = (1-\sigma)X_0 + \sigma\epsilon\)，\(\epsilon \sim N(0,I)\)。
  - 目标速度：\(V = \epsilon - X_0\)。
- 推理时选择交接噪声阈值 \(\tau\)：
  - System 2 从 \(\sigma=1\) 去噪到 \(\tau\)。
  - System 1 从 \(\tau\) 继续去噪到 \(0\)。
- 第 \(k\) 个执行窗口的交接为：
  - \(U^k_\tau = C_{s_k}(X_\tau; H_1) = [Z^{w,k}_\tau, A^k_\tau]\)。
  - 其中 \(C_{s_k}\) 根据执行进度，从全局轨迹中选取时间对齐的腕部潜变量和动作窗口。

### 2.3 System 2：全局规划

- 处理完整多视角世界-动作状态，全局视频帧跨度 \(H_2=32\)。
- 在高噪声阶段使用**双向注意力**，让整个预测时域内的变量相互约束，形成整体运动计划。
- 输出中间状态 \(X_\tau\) 是粗略但连贯的联合假设，不直接解码为最终可执行动作。
- 更新频率低，每 32 个控制帧刷新一次全局计划。

### 2.4 System 1：短时程局部细化

- 局部视频帧跨度 \(H_1=8\)，仅使用腕部观测。
- 腕部相机刚性固定在末端执行器上，腕部视频运动与执行动作对齐，能提供局部几何、遮挡和接触线索。
- 每个局部控制更新中，System 1 提取时间对齐窗口，结合最新腕部观测和机器人状态，完成低噪声细化。
- 窗口内使用**因果时间注意力**，每个位置只关注当前及之前时间位置，同时保留窗口内并行去噪。
- 训练时对腕部-动作输入做随机时间偏移增强，偏移概率随执行进度增加，以模拟 System 2 预测轨迹与实际执行状态之间的错位，提高异步执行鲁棒性。

### 2.5 训练目标与噪声区间

- 两个系统分别在不同噪声区间训练：
  - System 2：\(I_2 = [\tau_{\text{train}}, 1]\)，监督全局视频、腕部视频和动作，\(M_2=\{g,w,a\}\)。
  - System 1：\(I_1 = (0, \tau_{\text{train}}]\)，监督腕部视频和动作，\(M_1=\{w,a\}\)。
  - 论文设置 \(\tau_{\text{train}}=0.7\)。
- 损失为加权速度匹配误差：
  - \(L_i = E[\sum_{m\in M_i} \lambda^{(i)}_m \| V^{(i)}_m - \hat V^{(i)}_m(S^{(i)}_\sigma,\sigma,c_i) \|^2_2]\)。
  - 其中 \(c_i\) 为语言、观测和机器人状态条件。

### 2.6 异步闭环执行与工程优化

- System 2 在后台更新部分去噪的全局世界-动作轨迹，System 1 高频提取时间对齐局部窗口并细化，避免高噪声生成阻塞动作执行。
- 每个全局计划可复用多次局部更新；已过期的动作窗口跳过低噪声细化，保证动作与执行时间戳对齐。
