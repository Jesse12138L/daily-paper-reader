## 摘要
视觉-语言-动作（VLA）模型在机器人操作上表现出强劲性能，但往往难以泛化到未见过的任务、配置和长时程场景。一个关键挑战是 VLA 会过拟合训练场景，无法遵循新颖的语言指令。现成的视觉-语言模型（VLM）通常具有更强的泛化能力，但无法直接控制机器人动作。为了将 VLM 的常识与 VLA 控制相结合，我们提出 Guided Trace VLA（GT-VLA），这是一个可引导框架，通过轨迹条件化的动作生成接受来自外部通用 VLM 的引导。GT-VLA 使用通用模型识别当前技能的语义引导，将该引导转换为 2D 视觉轨迹，并以其生成的轨迹渲染观测为条件来调节动作策略。该设计将语义目标获取、轨迹生成和底层动作执行分离，使高层引导能够传播到机器人动作。GT-VLA 采用混合专家架构，具有技能特定的轨迹模块和动作模块，以实现稳健执行。我们在 LIBERO 和真实机器人平台上评估 GT-VLA，表明在两种设置下均比近期 VLA 基线具有更好的泛化能力。代码及更多补充材料见项目网站 https://ivaniz.github.io/gt-vla/。

## Abstract
Vision-Language-Action (VLA) models have shown strong performance on robotic manipulation, but they often struggle to generalize to unseen tasks, configurations, and long-horizon settings. A key challenge is that VLAs overfit to training scenes and fail to follow novel language instructions. Off-the-shelf vision-language models (VLMs) often provide stronger generalization, but cannot directly control robot actions. To combine the common sense of VLMs with VLA control, we propose Guided Trace VLA (GT-VLA), a steerable framework that accepts guidance from an external generalist VLM through trace-conditioned action generation. GT-VLA uses a generalist model to identify semantic guidance for the current skill, converts this guidance into a 2D visual trace, and conditions its action policy on the resulting trace-rendered observation. This design separates semantic target acquisition, trace generation, and low-level action execution, allowing high-level guidance to propagate to robot actions. GT-VLA uses a Mixture-of-Experts architecture with skill-specific trace and action modules for robust execution. We evaluate GT-VLA on LIBERO and a physical robot platform, showing improved generalization over recent VLA baselines in both settings. The code and additional supplemental materials are available on our project website at https://ivaniz.github.io/gt-vla/.

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型将感知、规划与控制统一为单一策略，在分布内操作上表现优异，但普遍存在**场景过拟合**问题——倾向于重复记忆中的行为，而非适应新指令或未见配置。
- **关键矛盾**：现成的通用视觉-语言模型（VLM）具备更强的语义泛化能力与常识，却**无法直接输出机器人动作**；而已有的层次化方案（如子任务分解、查询 VLM 做运行时引导）虽然提升了鲁棒性，但其高层语义信号**往往被底层控制器忽略**，无法真正传导到动作生成层。
- **核心论点**：有效的泛化需要一个**可引导（steerable）的执行管线**，把外部语义引导一路传播到动作生成。论文据此提出 GT-VLA，通过"语义目标 → 2D 视觉轨迹 → 轨迹条件化动作"的中间接口，将 VLM 常识与 VLA 控制能力解耦结合。

## 2. 方法论

- **整体框架**：将任务拆为三个可分离阶段——(a) 语义目标获取（通用 VLM）、(b) 轨迹生成（技能专用轨迹专家）、(c) 底层动作执行（轨迹条件化动作专家）。
- **技能接口与语义目标**：
  - 定义有限技能库 `S`，技能为半结构化算子（如 `PLACE(bowl, table)`）。
  - 用通用 VLM `Φ` 生成技能计划：`P = Φ_plan(ℓ, o_t) = (s(1), …, s(k))`。
  - 每个技能开始时查询语义目标点 `g(i) = Φ_target(ℓ, o_t, s(i)) ∈ [0,1]²`，作为图像坐标中的空间锚点（待抓物体、把手、放置位置等）。
- **目标条件化轨迹生成**：
  - 定义剩余轨迹 `τ*_t = (x_t, x_{t+1}, …, x_{tend})`，即图像空间中完成该技能的未来末端执行器路径，按弧长线性重采样为定长 `H`。
  - 用**条件流匹配（conditional flow-matching）** 建模 `π_τ(τ_t | o_t, x_t, g(i), ℓ(i))`，损失形如 `L_trace = E‖v̂ − (ϵ − τ̄*_t)‖²`，其中 `v̂` 为预测的速度场，`λ` 为流匹配时间，`ϵ` 为噪声。
  - 两条约束：当前末端位置 `x_t` 以 **inpainting 式约束**固定轨迹起点；语义目标 `g(i)` 通过 **AdaRMS 条件化**注入。
- **鲁棒轨迹条件化动作学习**：
  - 动作专家建模 `π_act(A_t | overlay(o_t, τ_t), ℓ(i))`，同样为流匹配模型；轨迹直接渲染叠加到视觉观测上。
  - 三种数据增强（互补设计）：
    - **随机场景丢弃（Random scene drop）**：遮罩场景但保留轨迹，迫使策略依赖轨迹引导，减少对训练场景的视觉过拟合。
    - **随机轨迹丢弃（Random trace drop）**：训练时随机去掉轨迹，保留策略从原始场景与机器人状态推理几何/深度的能力，降低对不准确轨迹的敏感性。
    - **低频轨迹扰动（Low-frequency trace perturbation）**：对训练轨迹施加平滑低频噪声，桥接训练真值轨迹与推理生成轨迹之间的分布差距。
- **TA-MoE 架构**：
  - 基于预训练 **Gemma 2B** 作为共享 VLM 骨干，轨迹专家与动作专家为小型 transformer 专家，通过注意力访问共享骨干。
  - **技能路由的混合专家**：按技能类别确定性路由（推理时仅激活对应专家），以解决 PICK 与 PLACE 轨迹相似但动作不同的歧义。
  - 动作专家每个约 300M 参数；轨迹专家为轻量流匹配 transformer（约 60M）。
  - 附加轻量 MLP 头预测技能进度 `p_c ∈ [0,1]`，当 `p_c ≥ η_c` 时切换到下一技能。
- **推理流程（Algorithm 1）**：输入语言指令、观测、轨迹更新频率 `f_upd`、技能完成阈值 `η_c`；先规划技能序列，逐技能查询语义目标；外层循环每 `f_upd` 个动作块重新生成轨迹，内层先预测进度判断是否切换技能，否则采样并执行动作。当前高层技能计划为**开环执行**（作者指出可扩展为闭环重规划）。

## 3. 实验设计

- **仿真平台与 Benchmark**：
  - 使用 **LIBERO**，且**不做 per-suite 分布内微调**，采用干净的训练-测试划分：训练于 Libero-10 与 Libero-90 演示，评估于 **Libero-Goal、Libero-Spatial、Libero-Object** 三个 OOD 套件。
  - 数据预处理得到任务分解、语义目标与真值轨迹；每类 50 trials × 10 tasks。
- **真实机器人平台**：
  - **YAM 机械臂**，配备侧视与腕部相机；工作区含不同颜色/形状/大小的盘子、篮子与假蔬菜。
  - 任务为长时程 pick-and-place（典型 2–6 个 PICK/PLACE 技能）；训练集 **299 个完整 episode**。
  - 五类评估套件：**composition-4 / composition-6**（技能配置见过但顺序未见）、**OOD-2 / OOD-4 / OOD-6**（技能配置本身未见）；每套件 10 任务 × 5 次试验 = 50 trials，采用 episode 级成功判定。
- **对比方法**：
  - **π0.5**（基础模型）、**AtomicVLA**（技能路由 MoE，无高层引导与轨迹条件化）、**SEAL**（基于外部 VLM 验证器的运行时引导框架）。
  - 仿真中另提供 **LoHo-Manip** 的最佳努力复现（无官方实现）作为补充对比。
  - SEAL 与 GT-VLA 均用 Gemini 3.1 Pro 实现；真实实验因 SEAL 需要高保真世界模型/数字孪生而排除。
- **消融实验**：G-VLA（去轨迹模块、直接注入语义目标）、GT-VLA-single（去 MoE）、以及三个数据增强的 leave-one-out（No S. Drop / No T. Drop / No Perturb.）；另有通用 VLM 替换实验（GPT-5.6、Qwen 3.8、Gemini 3.6）。
- **鲁棒性研究**：对语义目标注入噪声半径 `r ∈ {4, 8, 16, 32, 64}` 像素（输入图像 224×224），每个半径 100 trials。
- **失败分析**：将每个失败 episode 归因于最早偏离的管线阶段（执行失败、高层 VLM 错误、轨迹错误、进度预测器、轨迹未遵循、2D-3D 歧义）。

## 6. 主要结论与发现

- **仿真结果**：GT-VLA 在三个 LIBERO 套件上均最优，平均成功率 **43.8%**，比 π0.5 高 **28.0 个百分点**，比 AtomicVLA 高 **9.9**，比 SEAL 高 **16.5**；在 LIBERO-Object 上优势最突出（41.8%）。
- **引导设计的重要性**：SEAL 与 GT-VLA 都用外部 VLM，但 GT-VLA 显著更优，说明**外部引导本身不足够，VLA 必须被设计成能有效接受引导**。
- **真实世界结果**：GT-VLA 在全部 5 个套件上优于 baseline，且相对 AtomicVLA 的优势随任务时长增加而扩大，支持"复杂操作需要持续语义对齐 + 子任务分解"的假设。
- **消融发现**：
  - 轨迹中间接口显著优于直接注入语义目标（G-VLA），说明目标转为可视觉跟随的轨迹后更有用；
  - MoE 技能专家带来实质提升；GT-VLA-single 略优于 G-VLA，说明轨迹引导层可弥补更少参数量；
  - 三种数据增强**互补而非冗余**，任一缺失导致平均性能下降 **10.5%–13.2%**

- **通用 VLM 可替换性**：将高层规划/目标查询的 VLM 替换为 GPT-5.6、Qwen 3.8、Gemini 3.6 后，性能波动较小，说明方法**不依赖某一特定 VLM 的实现**，语义引导源的升级可近似"即插即用"，进一步支撑"引导接口 + 可引导执行器"的解耦设计。
- **语义目标噪声鲁棒性**：随噪声半径 `r` 从 4 增至 64 像素，性能单调下降但整体退化平缓，且即使在 `r = 64`（约占 224×224 图像宽度的 28.6%）时仍保持可观成功率；这验证了**轨迹中间接口对上游语义误差的缓冲作用**——目标点只需大致正确，轨迹专家与动作专家可通过视觉跟随与闭环校正补偿偏差。
- **失败归因模式**：失败主要集中在**执行失败**与**轨迹未遵循**两类，前者反映底层控制/接触动力学仍是瓶颈，后者说明动作专家对生成轨迹的服从度仍有提升空间；高层 VLM 错误与进度预测器错误占比相对较低，间接印证"高层语义引导不是主要瓶颈，瓶颈在语义到动作的传导质量"这一核心论点；2D-3D 歧义类失败则提示单目图像坐标引导在深度敏感的抓取/放置场景中仍有固有局限。

## 7. 贡献与创新点

- **接口层面的创新**：提出以 **2D 视觉轨迹**作为连接高层语义与底层动作的中间表示，把"该去哪、抓哪"的语义锚点转译为"如何沿图像空间移动"的可视化引导信号，避免了语义目标被底层控制器忽略的问题。
- **可引导性作为一等设计目标**：论文的核心洞见是"**引导能力必须被显式设计进 VLA**"，而非仅靠更强的外部 VLM。SEAL 与 GT-VLA 共享同类外部引导源却差距显著，是该论点的直接证据。
- **鲁棒轨迹条件化训练策略**：随机场景丢弃、随机轨迹丢弃、低频轨迹扰动三种增强互补，分别针对场景过拟合、轨迹依赖过强、训练-推理轨迹分布不匹配三类问题，构成一套完整的"鲁棒接受引导"训练范式。
- **技能路由 MoE**：以技能类别确定性路由专家，缓解 PICK 与 PLACE 轨迹相似但动作空间不同的歧义，且推理时仅激活相关专家，兼顾表达力与效率。

## 8. 局限性与未来方向

- **高层计划开环执行**：当前技能序列一经规划便开环执行，未做闭环重规划；作者指出可扩展为基于执行反馈的在线重规划，以应对计划中途失效的场景。
- **单目 2D 引导的固有歧义**：语义目标与轨迹均在图像空间定义，深度与遮挡信息依赖动作专家隐式推断，在需要精确 3D 关系的任务上存在结构性上限。
- **Benchmark 覆盖有限**：仿真仅限 LIBERO 单一套件，真实平台单一且任务限于 pick-and-place，向更多本体、更多任务族的泛化性尚未验证。
- **对比公平性受限**：LoHo-Manip 为无官方实现的最佳努力复现；SEAL 因依赖高保真世界模型/数字孪生而未参与真实机器人对比，真实场景下与运行时引导方法的直接比较缺失。
- **推理延迟结构**：VLM 调用虽频率低但单次耗时约 5–7 s，在需要快速反应或频繁重规划的场景中可能成为瓶颈。

## 9. 总体评价

- **论证逻辑完整**：论文从"VLA 场景过拟合 → 外部 VLM 有常识但无法直出动作 → 已有层次化方案引导被底层忽略"的问题链出发，推出"需要可引导执行管线"的论点，并以 GT-VLA 的三阶段设计逐项回应，问题—方法—证据闭环清晰。
- **实验证据扎实**：仿真与真实双线验证、干净 train-test split、OOD 评估、5 组消融、VLM 替换、噪声鲁棒性、失败归因等多维度证据相互支撑，主要结论均有对应实验。
- **核心价值**：其最大贡献可能不在于绝对成功率数字，而在于**把"可引导性"确立为 VLA 架构的设计维度**，并给出一个具体、可复用、与 VLM 版本解耦的实现范式；噪声鲁棒性与 VLM 可替换性两项结果对该论点的支撑尤为有力。
- **适用边界**：方法最契合长时程、子任务可自然分解、语义目标可用 2D 空间锚点表达的操作任务；对于强 3D 精度依赖、难以技能化分解或需要高频闭环反应的任务，收益可能受限。
