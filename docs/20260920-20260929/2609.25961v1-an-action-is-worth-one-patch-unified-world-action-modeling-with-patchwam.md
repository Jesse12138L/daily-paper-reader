## 摘要
生成式视觉模型为学习物理动力学的表征提供了基础，但将其扩展到连续控制时引发了一个根本问题：视觉预测与动作生成是否需要分开的计算通路？现有方法通常引入可训练的动作头或独立的动作专家，以桥接低维状态与高维视觉表征。在本工作中，我们探究当动作以兼容的表征表达时，视觉骨干网络的既有能力是否也能支持控制。因此，我们提出 PatchWAM（Patch World-Action Model，图块世界-动作模型），它通过一种称为 Action-as-Patch 的固定映射，将连续动作视为另一类图块。这使得单个模型既能预测机器人应如何运动，也能预测场景随后可能呈现的样子。视觉预测与动作生成成为同一生成过程的一部分，无需专用动作头或独立动作专家。使用子采样训练窗口的实验表明，其相较于匹配的双专家控制取得提升；而在全数据设置并加入额外增强演示的情况下，基准评估在 LIBERO-Plus 上达到 91.8% 的成功率，在 RoboTwin 2.0 上达到 96.12%。更广泛地说，这一结果表明，能力不必在可以继承之处被额外添加：扩展生成式骨干网络的约束在于新信号被写入的接口，而非建模该信号的能力。

## Abstract
Generative visual models offer a foundation for learning representations of physical dynamics, yet their extension to continuous control raises a fundamental question: do visual prediction and action generation require separate computational pathways? Existing approaches usually introduce trainable action heads or separate action experts to bridge low-dimensional states and high-dimensional visual representations. In this work, we explore whether the visual backbone's existing capacity can also support control when actions are expressed in a compatible representation. Thus, we introduce PatchWAM (Patch World-Action Model), which treats continuous actions as another type of patch through a fixed mapping called Action-as-Patch. This allows a single model to predict both how the robot should move and what the scene may look like afterward. Visual prediction and action generation become parts of the same generative process, without a dedicated action head or separate action expert. Experiments with subsampled training windows show gains over a matched dual-expert control, while benchmark evaluations reach 91.8% success rate on LIBERO-Plus and 96.12% on RoboTwin 2.0 in a full-data setting with additional augmented demonstrations. More broadly, the result suggests that capability need not be added where it can be inherited: the constraint on extending a generative backbone is the interface a new signal is written in, not the capacity to model it.

- **核心质疑**：预训练视觉生成骨干网络的既有能力，是否在动作以**兼容表征**表达时，就足以直接支持控制？换言之，额外的动作专用容量是"必需"还是"冗余"？
- **整体含义**：论文提出 PatchWAM，用一个**固定映射**把连续动作写入视觉潜空间的 token 格式，使动作预测成为视觉路径内的 token 预测。其更广泛的主张是：**扩展生成式骨干的约束在于新信号被写入的接口形式，而非建模该信号的能力**——能力可被"继承"，不必"额外添加"。

## 二、方法论

### 核心思想
- **Action-as-Patch（AP）**：通过一个**无参数、固定**的编解码器，将每个动作步映射为一个与视觉 latent patch **同维度（D=128）** 的 token，从而让动作直接复用骨干网络已有的输入/输出投影，无需动作编码器、动作专用输出投影或独立动作专家。
- **联合生成**：单个共享 DiT 同时去噪"未来帧 token"与"动作 token"，视觉预测与动作生成成为**同一生成过程**的两个部分。

### 关键技术细节

- **归一化**：RoboTwin/RoboDojo 用 Z-score，LIBERO 用 min–max；解码后再做逆变换 N⁻¹。
- **编码器（固定）**：设复制因子 r = ⌊D/A⌋，缩放常数 α。将每个动作分量复制 r 次，剩余 D − rA 项零填充。可写成 E(ā_h) = αP ā_h，其中 P 是固定的 0/1 矩阵（含 Kronecker 积结构）。RoboTwin/RoboDojo 的 14 维动作 r=9，LIBERO 的 7 维动作 r=18，两者均使 126 项承载动作值、2 项零填充；α=1。
- **解码器（固定）**：对每个分量的 r 个副本取平均。由于 PᵀP = rI_A，该读出等价于编码器的 **Moore–Penrose 伪逆**，因此：
  - 是编码器的**精确左逆**（D_E(E(ā_h)) = ā_h），无需重建损失；
  - 对落在编码器值域外的预测 token，返回**最小二乘意义下最近**的动作（正交投影 + 精确反演），而非学习式预测头。
- **训练目标**：未来帧 token x⁰ 与动作 token u⁰ 分别加独立高斯噪声，但**共享同一噪声水平 σ**：
  - x_σ = (1−σ)x⁰ + σϵ_x，u_σ = (1−σ)u⁰ + σϵ_u
  - σ 由均匀变量经 shift 函数 ϕ_s(τ) 得到（s=5），使训练集中在高噪声区（仅约 1/6 样本 σ<1/2）。
  - 损失 L = E[w(σ)(λ_x·MSE(v_x, ϵ_x−x⁰) + λ_u·MSE_valid(v_u, ϵ_u−u⁰))]，其中 λ_x=0.5，λ_u=1.0，w(σ) 在 σ=1/2 处峰值、在 0 与 1 处消失。
  - 动作项仅对演示范围内的动作步求平均，排除超出演示末尾的填充步。
- **模型与初始化**：Transformer 初始化自 **FLUX.2 [klein] 4B Base**，基于 ImageWAM 代码库；文本编码器 RoboTwin/LIBERO 用 Qwen3-4B（冻结），RoboDojo 用 Qwen3-VL-4B-Instruct + LoRA（可训练 132.1M 参数）；图像自编码器冻结；编解码器无参数。
- **token 序列与注意力**：前缀（语言 + 状态 token + 当前观测）为干净输入，前缀 token 只关注前缀；未来帧与动作 token 关注前缀及整个噪声块（两者可互相注意）；位置坐标用四轴区分 token 组（当前帧=10、未来帧=0、动作=20 等）。RoboTwin 序列共 721 个 token，动作 token 约占 2%。
- **推理**：两组 token 均从标准高斯噪声出发，用 Euler 法沿与训练一致的 shift 调度联合去噪（默认 K=20 步，评估用 K=10），最终动作 token 经固定解码器还原并映射回物理单位；**未来帧 latent 无需解码成 RGB**，机器人执行动作块后重新规划。

## 六、主要结论与发现

- **架构层面**：在匹配数据与优化设置下，移除独立动作专家后，PatchWAM 达到 **88.0%** 平均成功率，优于双专家对照的 **78.4%**（+9.6 个百分点），且可训练参数更少；学习曲线显示 PatchWAM 收敛更快（30k updates 即达 81.0%，超过对照最终 78.4%）。
- **基准层面**：
  - RoboTwin 2.0 全数据+增强：**96.12%** 平均成功率（干净 96.04%、随机化 96.20%），略高于 MotuBrain 的 95.94%。
  - RoboTwin 2.0 C2R：**79.14%** 平均（干净 91.56%、随机化 66.72%），平均分最高，但随机化场景成功率低于最强基线（67.90%）；干净→随机化仅掉 24.84 个百分点，远小于其他 WAM。
  - LIBERO：**98.4%**，但低于 QuoVLA 的 99.6%，benchmark 接近饱和。
  - LIBERO-Plus：增强训练下 **91.8%**，为所列方法最高；相机与传感器噪声扰动下均达 97.9%；最弱项为机器人初始状态扰动（71.0%）。
  - RoboDojo：Score **29.39**、成功率 **23.60%**，为 2026-09-15 排行榜最高；在泛化（标准/随机化）、精确操作、开放词汇三项成功率最高，长时程略低于 G0.5，记忆任务明显低于 DM0.5。
  - LIBERO-Pro：平均 **57.9%**，对象扰动下最弱（80.8%），位置/任务扰动对所有方法均困难。
- **机制发现**：
  - 固定编解码器与学习式线性接口性能相当（差 0.07 个百分点），说明**接口无需学习**；
  - 动作与未来帧 token 互相可见带来约 0.58 个百分点的小幅

- 动作与未来帧 token 互相可见带来约 **0.58 个百分点**的小幅增益（94.57% vs 93.99%），说明联合注意力对两路生成的协调有正向作用，但它**不是**性能的主要来源——即使阻断双向可见性，模型仍显著高于双专家对照，进一步支持"能力主要来自骨干继承"的解读。
  - 解耦噪声水平（3 个 Self-Flow 变体）结果为 **88.7% / 88.3% / 85.5%**，对照共享噪声水平的 **88.0%**。其中两个变体略优、一个明显更差，差异均在种子噪声量级附近。作者据此认为共享噪声调度**并非性能的必要条件**，性能提升不应归因于该实现细节。
  - **接口面积极小**：动作 token 仅占 RoboTwin 序列 721 个 token 中的约 **2%**，且编解码器零参数、可训练参数总量少于双专家对照，却获得更高成功率。这构成"约束在接口形式而非建模容量"这一主张的最直接证据。
  - **收敛速度**：学习曲线显示 PatchWAM 在 **30k updates** 即达 **81.0%**，超过双专家对照的最终 **78.4%**，表明联合生成不仅上限更高，样本效率也更好。

## 七、局限性与待解决问题

### 论文自述的局限
- **单次运行、无方差**：所有结果均来自单次训练/评估，未报告标准差或多种子结果。作者明确承认这一点，因此 0.07、0.58 个百分点这类量级的差异**无法与随机波动区分**。
- **匹配对照的归因不纯**：PatchWAM 与双专家对照之间同时改变了**参数共享方式、token 可见性与信息处理路径**，因此 +9.6 个百分点**不能被归因于任何单一设计选择**。
- **消融与对照的 regime 不一致**：机制消融（学习式接口、隔离注意力）在全数据协议下进行，而匹配对比使用另一种窗口采样 regime，二者**不能互相拼接**用于分解 9.6 个百分点的来源。
- **基准对比不公平**：与外部基线的比较在演示数量、数据增强、checkpoint 选择上均不匹配，作者声明这些数字**不能用于隔离架构效应**。

### 从总结中可进一步识别的局限
- **算力报告不完整**：仅给出 GPU 数量与 batch size，缺少 GPU 型号、挂钟时长与总 GPU 小时，**能耗与复现成本不可估计**。
- **验证场景集中于仿真**：所覆盖的 benchmark（RoboTwin 2.0、LIBERO、LIBERO-Plus、RoboDojo、LIBERO-Pro）均为仿真环境，**未见大规模真实机器人验证**，因此"视觉预测与动作生成共享通路"在真实感知噪声与执行误差下的鲁棒性仍待确认。
- **接口设计的维度约束**：Action-as-Patch 依赖复制因子 r = ⌊D/A⌋ 与零填充来把动作维度 A 对齐到 latent 维度 D。当动作维度升高（如高自由度灵巧手、更高维双臂）时，r 会下降甚至趋近 1，**复制冗余消失后固定编解码器是否仍具优势**未被考察。

- **LIBERO 接近饱和**：98.4% 已接近上限且低于 QuoVLA 的 99.6%，该 benchmark 对方法区分度有限，**主结论主要由 RoboTwin 与 RoboDojo 支撑**。

## 八、总体评价与启示

### 贡献定位
- **概念贡献 > 数值贡献**：论文最有价值的部分不是某个 SOTA 数字，而是把"生成式骨干能否直接承担控制"这一模糊问题，转化为一个**可检验的接口设计命题**——即动作只需以与视觉 patch 兼容的表征写入，便可复用骨干已有的输入/输出投影。
- **方法极简且可迁移**：固定编解码器无参数、无重建损失、可写成闭式伪逆，几乎不引入超参数，**易于嫁接到任意 patch 式生成骨干**上，工程可迁移性强。

### 证据强度评估
- **较强**：匹配架构对照（同骨干、同数据、同优化）在方向上是干净的，+9.6 个百分点与更快的收敛曲线共同指向"独立动作专家可能是冗余容量"。
- **中等**：机制消融显示接口是否可学习几乎无差别（0.07 个百分点）、注意力隔离仅损失 0.58 个百分点，方向上支持"接口形式而非容量"的论断，但效应量小于种子噪声的常见量级。
- **较弱**：与外部基线的排名比较因数据与 checkpoint 不匹配，只能作为**背景参考**而非结论依据。
- **结论**：论文的主张在**方向上得到支持**，但尚未达到"决定性证明"的程度；其最大价值在于提出了一个清晰、廉价、可复现的替代方案，并把归因边界诚实地标了出来。

### 对后续研究的启示
1. **接口即能力**：扩展生成式骨干的关键可能不在"加多少专用参数"，而在"新模态以什么格式进入潜空间"。
2. **需要多种子实验**：0.07–0.58 个百分点量级的消融结论，必须配合多种子与置信区间才能成立。
3. **需要解耦消融**：应分别单独改变参数共享、token 可见性与处理路径，才能把 +9.6 个百分点拆解为可解释的因子。
4. **需要真机与高维动作验证**：复制因子随动作维度下降的边界行为，以及真实执行误差下的表现，是该方法能否推广的关键检验点。
