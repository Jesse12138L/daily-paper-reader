## 摘要
预测下一状态是世界模型建模物理动力学的核心范式，强调预测保真度。随着世界模型演变为世界动作模型（WAMs），现有方法仍在训练前将下一状态固定为 RGB、单一潜在特征或预定义目标的静态组合，从而将动作学习限制在特定表示所保留的归纳偏置之中。为解决这一局限，我们提出 CF-WAM，一种动态下一状态预测框架，它对同一未来的视觉、语义、几何和交互投影进行采样，将其统一为标准视频形式，并基于这些投影监督一个统一的 WAM。这些投影所暴露的与动作相关的约束在训练步骤中不断累积，迫使 WAM 捕捉支撑同一动作条件下未来多种投影的底层状态转移结构。这种动态机制还为人类与机器人学习提供了自然的跨具身动力学参考框架。通过在不同下一状态参数化之间进行联合学习，异质的人类与机器人经验能够绕过外观差异，直接贡献于共享的状态转移学习，从而提升跨具身泛化能力。实验表明，CF-WAM 同时提升了训练效率和最终控制性能，并能将人类经验有效转化为策略收益。CF-WAM 在 RoboCasa-GR1 上达到最先进性能，平均成功率为 82.50%，同时在 LIBERO-Plus 上达到 82.65%，在真实世界评估中最高达到 84.00%。

## Abstract
Predicting the next state is a core paradigm of World Models for modeling physical dynamics, emphasizing prediction fidelity. As World Models evolve into World-Action Models (WAMs), existing methods still fix the next state before training as RGB, a single latent feature, or a static combination of predefined targets, thereby constraining action learning to the inductive biases preserved by a particular representation. To address this limitation, we propose CF-WAM, a dynamic next-state prediction framework that samples visual, semantic, geometric, and interaction projections of the same future, standardizes them into a common video form, and supervises a unified WAM across these projections. The action-relevant constraints exposed by these projections accumulate across training steps, forcing WAM to capture the underlying state-transition structure that supports multiple projections of the same action-conditioned future. This dynamic mechanism also provides a natural cross-embodiment dynamics reference frame for Human and Robot learning. By jointly learning across different next-state parameterizations, heterogeneous Human and Robot experience can bypass appearance differences and directly contribute to shared state-transition learning, improving cross-embodiment generalization. Experiments show that CF-WAM improves both training efficiency and final control performance, while translating Human experience effectively into policy gains. CF-WAM achieves state-of-the-art performance on RoboCasa-GR1 with an average success rate of 82.50%, while reaching 82.65% on LIBERO-Plus and up to 84.00% in real-world evaluations.

## 1. 核心问题与研究背景

- **范式演进**：世界模型（WM）以预测下一状态为核心来建模物理动力学，强调预测保真度；世界动作模型（WAM）进一步把预测能力与动作生成耦合，使策略能基于"预想的未来"行动。
- **角色变化带来的根本问题**：在 WM 中未来状态服务于"忠实预测"；在 WAM 中它还必须突出可被动作改变、或直接影响动作选择的动态因素。因此"最适合预测的状态"未必是"最适合动作学习的状态"。
- **现有做法的局限**：主流 WAM 在训练前就把下一状态固定为（a）未来 RGB 观测、（b）单一潜在特征、或（c）预定义目标的静态组合。这决定了哪些未来信息被保留、丢弃并最终用于动作学习。
- **不同表示各有盲区**：
  - 视觉状态 → 保留完整可观测结果，但含大量与动作弱相关的视觉细节；
  - 语义状态 → 强调实体与任务结构，但弱化空间关系；
  - 几何状态 → 捕获 3D 布局，但缺失物体身份与交互进度；
  - 交互状态 → 捕获接触与状态变化，但缺失全局上下文。
- **静态多目标组合的代价**：需在每一步维护多个预测空间，增加模型容量与计算，并迫使模态特有特征争夺有限的动作条件注意力，稀释真正与动作相关的状态变化（模态竞争）。
- **人类数据带来的放大效应**：人类操作数据是可扩展经验的重要来源，但人–机在视角、外观、本体、动作空间上差异巨大。固定表示容易被本体特有的外观变化主导，难以暴露可迁移的动作相关动力学，这也是现有方法多依赖"人类预训练+机器人后训练"或配对数据的原因。
- **论文立场**：借助柏拉图表示假说，把视觉/语义/几何/交互状态视为**同一动作条件未来的不同投影**，从而把"表示选择"从固定设计决策转变为动态训练变量。

## 2. 方法论（CF-WAM）

### 2.1 核心思想
- 不预先固定下一状态的表示，而是在训练中动态采样同一底层未来流形 $s_{t+\Delta}\in\mathcal{M}$ 的不同投影 $y^k_{t+\Delta}=\phi_k(s_{t+\Delta})$。
- 原则：**统一"承载多样未来的模型"，而非统一未来状态本身；动态改变未来的表示方式，而非训练前固定单一表示。**
- 三条设计原则：
  1. **动态未来状态参数化**：投影选择本身是动态训练变量（随机多任务采样），每个样本只用一个坐标系监督同一个未来转移，互补约束跨训练步累积。
  2. **生成作为公共建模接口**：所有投影统一为视频形式，共享同一 VAE 与 WAM，无额外预测分支；多样性在监督侧，统一性在生成模型侧。
  3. **无配对人–机世界–动作学习**：以世界状态转移为共享接口，无需 RGB/轨迹级对应或样本级配对。

### 2.2 世界–动作建模（MoT 架构）
- **混合 Transformer（Mixture-of-Transformers）**：世界专家（视频扩散 Transformer，Wan2.2-TI2V-5B 初始化）预测未来状态；动作专家（ActionDiT）预测动作轨迹。两层各自计算 Q/K/V，沿序列维拼接做混合注意力，非对称掩码 $M$ 下：
  $$Q=[Q_w;Q_a],\;K=[K_w;K_a],\;V=[V_w;V_a],\;H=\mathrm{Attn}(Q,K,V;M)$$
  注意力后拆分回各自专家，参数独立、逐层交换信息。
- **非对称注意力拓扑**：视频 query 只关注视频 K/V；动作 query 关注全部视频+动作 K/V；视频流保持首帧条件化的因果约束，噪声动作 token 不干扰视频生成。
- **流匹配目标**：给定当前 RGB 观测 $o_t$、语言指令 $c$、未来目标 $\tilde y=[o^{RGB}_t,y_{t+1:t+H}]$，编码 $z_0=E_{VAE}(\tilde y)$；两条分支独立线性插值路径：
  $$z_\tau=(1-\sigma_\tau)z_0+\sigma_\tau\epsilon_z,\quad a_\tau=(1-\sigma^a_\tau)a_0+\sigma^a_\tau\epsilon_a$$
  速度目标 $v^*_z=\epsilon_z-z_0$、$v^*_a=\epsilon_a-a_0$；总损失 $L_{WAM}=\lambda_w L_{world}+\lambda_a L_{action}$。

### 2.3 动态未来状态预测
- **四类投影**：视觉（RGB 视频）、语义（DINOv3-PCA 视频）、几何（深度视频）、交互（手–物分割视频），记 $R=\{Vis,Sem,Geo,Int\}$，全部统一为视频形式、共享同一 VAE。
- **动态投影采样**：每个训练样本从 $k\sim p_R(k)$ 抽一个投影；所有投影共享当前 RGB 观测，$k\neq Vis$ 时首帧替换为严格时间对齐的 RGB 帧，保证起点世界状态一致、仅"未来表示"变化。
- **投影条件生成**：将投影提示 $c^k_{rep}$（如 "Predict the depth video."）与任务指令拼接 $c^k=c_{task}\oplus c^k_{rep}$，复用既有语言条件通路，无需模态路由或独立分支。
- **动态生成学习目标**：
  $$L_{dyn}=\mathbb{E}_{k\sim p_R(k)}\mathbb{E}_{D_k}\big[\lambda_w L_{world}(E_{VAE}(\tilde y^k),c^k)+\lambda_a L_{action}(a\,|\,o^{RGB}_t,c^k)\big]$$
  关键不是每步加更多预测目标，而是持续改变监督同一未来转移的坐标系；每步仅一个投影，约束跨参数更新累积。

### 2.4 无配对人–机世界–动作学习
- **数据源+投影联合采样**：$(d,k)\sim p_D(d)\,p_R(k|d)$，$d\in\{Human,Robot\}$；人类与机器人数据在 episode、任务、时间层面均无需配对。
- **动作空间分解**：$a=[a_{EE},a_J]$。人类腕部运动与机器人末端执行器共享同一 EE 空间，故人类经验直接监督 $a_{EE}$；$a_J$ 仅由机器人轨迹监督以保留本体特有底层控制。
- **源相关动作掩码**：人类样本缺失的关节维度用 mask 剔除而非置零：
  $$M^d_a=\begin{bmatrix}I_{EE}&0\\0&\mathbb{1}[d=R]I_J\end{bmatrix},\quad L^d_{action}=\mathbb{E}\!\left[\frac{\|M^d_a r^d_a\|_2^2}{\mathrm{tr}(M^d_a)}\right]$$
- **联合目标**：$L_{HR}=\mathbb{E}_{(d,k)}[\lambda_w L_{world}(E_{VAE}(\tilde y^k),c^k)+\lambda_a L^d_{action}]$。

### 2.5 关键实现细节
- 时间窗 0.8 s，20 Hz，17 帧观测/16 步控制；视频取 5 个关键帧（0,4,8,12,16），224×224。
- 冻结 Wan2.2 VAE → 48 通道、2×28×28 潜变量；patchify (1,2,2) → **392 个视频 token**；动作 16 token（16×47）；联合自注意力长度 **408**。
- 语言编码器 umT5-XXL（最多 128 token，4096 维）+ 1 个 47 维本体状态 token，经 cross-attention 注入。
- 每步去噪把当前 RGB 潜变量重新写回第一时序位置，防止条件帧被噪声破坏。
- 时间调度 shift=5：$\sigma(u)=5u/(1+4u)$；1000 个离散时间位置，损失权重 $w(t)\propto\exp[-2((t-500)/1000)^2]$；推理用 20 步 Euler 求解器。
- 专家配置：视频专家 30 层、残差宽 3072、24 头×128、FFN 14336、3D RoPE、约 5.000B 参数；动作专家 30 层、残差宽 1024、FFN 4096、1D RoPE、约 1.021B 参数；注意力空间共享 3072 维，总参数约 6.021B（不含冻结 VAE/文本编码器）。
- **数据构建**：EgoDex 真实第一视角人类操作（27,419 片段过滤后保留 23,849）+ Teleop-GR1 仿真机器人遥操作（24 任务×1000 = 24,000）；共 47,849 物理片段、191,396 模态片段。
  - 深度：仿真用 MuJoCo 度量深度渲染；人类用 Depth Anything 3 估计并按相机内参转度量；统一非线性映射 $u=1-(1+d/3)^{-2}$ 后沿固定 RGB 路径着色，存为无损 RGB 视频。
  - 分割：仿真用 MuJoCo 几何 ID 渲染
