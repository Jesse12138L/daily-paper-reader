## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为底层机器人动作，从而支持跨多种任务的可扩展机器人操作。然而，现有 VLA 模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，降低任务执行成功率。为解决该问题，我们提出一种对称双臂专家（DAE）架构，其构建于共享的视觉-语言模型（VLM）骨干之上，并采用解耦的、臂特定的专家塔。专家选择通过两阶段双臂意图路由方案完成：第一阶段根据显式语言指令路由专家，第二阶段根据隐式视觉语义路由专家。此外，我们引入一个轻量级任务进度预测模块，利用分块前时序特征与本体感觉和视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持协作多机器人任务的协调调度。实验结果表明，我们的模型在双臂意图路由和解耦跨臂干扰方面有效，并进一步提供了从单臂到双臂任务（以及反向）涌现技能泛化的初步证据，以及跨臂运动域技能迁移的证据。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

# TAO-DA 论文总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型将语言、视觉观测与机器人状态统一到动作生成框架中，成为可扩展机器人操作的主流范式。近期工作多采用自回归、扩散或流匹配等动作生成器。
- **核心问题**：现有多数双臂 VLA 设计将两条手臂放入**统一的动作生成器**中，虽简化了动作接口，却导致执行臂与另一条手臂无关的状态/视觉变化相耦合，产生**跨臂干扰（cross-arm interference）**，降低任务成功率。
- **问题重要性**：这种耦合在以下场景尤为关键——① 只需单臂操作时；② 双臂执行顺序子任务时；③ 示教中两臂角色不对称时。
- **整体思路**：双臂策略应**保留共享的任务语义**，同时**有选择地控制臂级动作生成**。TAO-DA 据此提出两大原则：共享多模态表示负责任务级推理，臂专属动作塔负责底层控制；由 DAIR 决定激活臂集合，由 DAE 通过被选中的臂专属通路生成动作。

## 2. 方法论

### 2.1 整体架构（TAO-DA）

- **输入**：多视角视觉观测（1 张自视角 + 左右两个可选的腕部末端视角）、语言指令、本体感觉状态。
- **编码**：每张图像由同一个预训练 **SigLIP** 视觉编码器编码；视觉 token 与语言 token 拼接后送入**冻结的 Eagle-2.5-VL** 骨干，得到融合多模态表示 $E_{VL}$（供 DAIR 使用）。
- **动作条件表示**：路由完成后，**非激活臂的末端视角 token 在 VLM 输入处被掩码**；本体感觉特征单独编码；臂专属状态与动作 token 由对应动作通路处理。
- **训练技巧**：每个任务的指令从语义等价表达池中随机采样，提升语言鲁棒性。

### 2.2 DAIR：双臂意图路由

- **意图表示**：激活臂集合编码为二值向量 $r=[r_L, r_R]\in\{0,1\}^2$，有效类别为左臂、右臂、双臂三类：$\phi(0)=[1,0]$、$\phi(1)=[0,1]$、$\phi(2)=[1,1]$。
- **损失**：三分类交叉熵 $L_{route}=-\log p_c$；三分类接口可避免产生无效的"无臂"向量 $[0,0]$。
- **第一阶段——规则语言解析**：识别 "left arm"、"right arm"、"both arms"、"left/right hand" 等显式表达，映射为 $\hat{r}_{rule}$；同时提及双臂时双臂优先。若无显式表达则返回内部无匹配码 $[0,0]$，触发第二阶段。规则解析不使用空间表达推断臂意图。
- **第二阶段——模型多模态意图预测**：对 $E_{VL}$ 做 LayerNorm，用可学习 query 做多头注意力池化 $f=\mathrm{MHA}(q, E_{norm}, E_{norm})$，经 MLP 输出三个 logits 并取 argmax，映射回二值接口 $\hat{r}_{model}$。
- **进度保持机制**：推理时若任务已推进足够多，可保持先前意图——当规则解析有结果则用 $\hat{r}_{rule}$；否则用 $\hat{r}_{model}$，但当预测进度 $\hat{p}_t>\tau_{hold}$ 时沿用上一时刻意图 $\hat{r}_{t-1}$。该机制仅用于稳定路由，区别于部署级任务调度器。

### 2.3 DAE：三种双臂专家变体

- **Single-Tower（统一）**：两条手臂的状态与动作 token 拼接在同一个 DiT 中。
- **Dual-Mask（弱解耦）**：共享 DiT，但用臂模式注意力掩码限制 token 交互。输入为四组臂专属 token $X_{in}=[X^L_{state}, X^R_{state}, X^L_{action}, X^R_{action}]$，对自注意力施加掩码 $M^{(m)}$：
  $$\mathrm{Attn}(Q,K,V|M^{(m)})=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}+\log M^{(m)}\right)V$$
  左臂模式仅允许左臂状态与动作互注意，右臂对称，双臂模式全通；多模态任务表示在各模式间仍共享。
- **Dual-Tower（强解耦）**：两条结构相同但**参数独立**的分支 $T_L, T_R$，各含独立的状态编码器、动作 tokenizer、DiT 与动作解码器；臂级参数约翻倍，但冻结 VLM 与 DAIR 保持共享。单臂执行时仅被选中的塔参与，双臂执行时两塔共享任务上下文。
- **臂条件视角掩码**：设 $V=[V_{ego}, V_L, V_R]$，非激活臂的末端视角 token 在进入 VLM 前被掩码：$e_V(r)=\mathrm{Mask}(V,r)$，$e_{EVL}(r)=\mathrm{VLM}(e_V(r), E_{lang})$；自视角在所有模式下始终保留。
- **激活臂监督**：$L_{act}=r_L L^L_{FM}+r_R L^R_{FM}$，单臂样本只激活一项，双臂样本两项均用；各变体共用流匹配目标。

### 2.4 任务进度预测模块

- 用 GRU 编码 DiT 时序特征 $H=[h_1,\dots,h_T]$ 得 $S=\mathrm{GRU}(H)$，再与 VLM 表示做交叉注意力 $Z=\mathrm{MHA}(S, E_{VL}, E_{VL})$，回归头输出 $\hat{p}_t$（以归一化轨迹时间为监督目标）。
- 该估计在推理时同时服务于 DAIR 的保持机制与部署级调度器。

## 5. 实验数量与充分性

- **实验规模**：约 9,080 条真实轨迹、31.9 小时数据；单臂 5 任务 × 6 模型、双臂 2 任务 × 3 模型、离线鲁棒性 2 臂 × 3 变体、真实扰动 3 条件 × 2 臂 × 3 变体、路由消融 4 配置 × 3 类、技能复用 3 变体 × 3 模式 × 20 次试验，另有部署级 101 次全流程试验。
- **充分性**：覆盖了真实机器人任务成功率、离线隔离指标、路由精度、消融与部署，实验类型较全面；每条件 20 次试验在真实机器人研究中属常见量级。
- **客观性与公平性**：
  - 所有动作策略变体共用相同训练数据、观测接口与动作执行策略，基线使用对应预训练 checkpoint 并同样微调，具备一定公平性。
  - **作者明确声明**：架构对比**并非参数量匹配**（Dual-Tower 复制了臂级组件），且所有结果被视为"该协议下的观测证据"而非统计显著性结论。
  - DAIR 的下游效果主要以定性图示（Fig. 4）呈现，未做任务成功率层面的路由消融隔离。
  - 技能复用与角色互换实验为定性观察（部分仅 3 次运行），证据强度有限。

## 6. 主要结论与发现

- **跨臂干扰解耦有效**：扰动/干净 MSE 比值在 Single-Tower 下为 1.94（右臂）与 1.60（左臂），Dual-Mask 降至 1.46 与 1.13，**Dual-Tower 为 0.99 与 1.00**（接近完全不受影响）。
- **真实机器人鲁棒性**：随机初始状态与持续扰动下，Dual-Tower 保持 95–100% 成功率，Single-Tower 为 20–60%，Dual-Mask 为 65–85%；持续扰动下 Dual-Tower 左/右臂为 100%/95%，Single-Tower 仅 25%/20%（相差 75 个百分点）。
- **任务成功率**：单臂任务 TAO-DA 平均 88.4%，优于 GR00T N1.5（82.0%）与 π0.5（80.5%）；双臂任务 Collaborative Tea 100%、Desktop Organization 95%（后者超过两个基线）。
- **路由性能**：左臂、右臂、双臂分类精度分别为 85.37%、83.31%、96.13%；**混淆矩阵中无左右侧别错误**，误分类集中在"单臂 vs 双臂"的区分（左臂 14.6%、右臂 16.7% 被误判为双臂）。
- **路由消融**：Multi 设定下移除进度模块使右臂精度从 83.31% 降至 68.48%、双臂从 96.13% 降至 89.22%；保留进度时 Fixed 的右臂精度为 78.66%（低于 Multi 的 83.31%）。
- **技能复用（初步）**：仅用双臂示教训练时，Dual-Tower 在左/右/双臂模式下达 100%/90%/95%，Single-Tower 仅 80%/50%/50%；分别训练的左右臂技能可直接并行执行，角色互换在无示教条件下可执行但精度下降。
- **部署**：自主餐厅系统在 101 次全流程试验中取得 92.08% 端到端成功率（该指标包含感知、操作、调度与系统执行，不能单独归因于 TAO-DA）。

## 7. 优点

- **问题建模清晰**：将"非激活臂干扰"形式化为动作生成问题，并用共享语义 + 臂级解耦的双原则给出统一解释框架。
- **架构对比系统**：从统一（Single-Tower）、弱解耦（Dual-Mask，注意力掩码）到强解耦（Dual-Tower，参数独立）形成递进式消融链条，能较清晰地归因解耦程度与鲁棒性的关系。
- **路由设计务实**：三分类接口规避无效"无臂"状态；规则解析 + 学习式多模态预测的两阶段设计兼顾可解释性与泛化；基于任务进度的保持机制提升推理稳定性。
- **掩码机制细致**：不仅在动作塔层面解耦，还在 VLM 输入处掩码非激活臂腕部视角，形成视觉-动作双层隔离。
- **指标设计合理**：用"扰动/干净 MSE 比值"衡量隔离性，并把绝对干净 MSE 与隔离性分开解读，避免混淆结论。
- **实验贴近真实**：全部在真实人形机器人上评测，含持续扰动、随机初始状态与真实餐厅多机部署，工程落地性较强。
- **学术态度诚实**：明确指出非参数量匹配、无统计显著性主张、定性结果不构成鲁棒迁移证据，局限章节写得较为充分。

## 8. 不足与局限

- **非参数量匹配**：Dual-Tower 复制臂级组件使参数量约翻倍，因此性能优势无法完全排除容量增加的贡献，架构归因不完全干净。
- **DAIR 评估不充分**：主要用路由分类精度评估，下游任务成功率层面缺乏隔离式消融，仅有定性图示（Fig. 4）。
- **扰动覆盖有限**：扰动研究仅针对非激活臂的本体感觉输入，未覆盖物理接触、视觉遮挡/干扰等其他扰动形式。
- **任务进度监督粗糙**：以归一化轨迹时间而非语义完成度作为监督目标，进度信号可能与真实任务完成状态不一致。
- **技能迁移证据薄弱**：单-双臂泛化、跨臂技能复用与角色互换均为定性观察，Collaborative Tea 角色互换仅 3 次运行，作者自己也声明不构成稳健迁移证据。
- **试验规模有限**：每条件 20 次试验、部分结论基于少量运行，缺乏统计显著性与置信区间分析。
- **平台单一**：仅在 AGIBOT G1 一种人形平台上验证，跨平台/跨机器人泛化能力未知。
- **部署指标归属模糊**：92.08% 端到端成功率包含感知、调度等多个子系统，无法单独反映 TAO-DA 的贡献。
- **算力信息缺失**：未报告 GPU 型号、数量、训练时长与推理延迟，难以评估方法的实际训练/部署成本（论文另引用了 VLA-RAIL 实时异步推理工作，但正文未给出本模型的推理时延数据）。
